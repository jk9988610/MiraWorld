## 一、中文名怎么叫

### 1.1 英文名（定）

**MiraWorld** — 仓库、代码、域名、API 不变。

### 1.2 中文名候选

| 名称 | 类型 | 优点 | 注意 |
|------|------|------|------|
| **米拉世界** | 音译 | 与 Mira 一致，好记、不易歧义 | 偏中性，需副标题补意境 |
| **奇迹世界** | 意译 | 好听、有想象力；Mira≈拉丁「奇妙」 | 「奇迹」易联想魔幻/奇迹手游 |
| **觅境世界** | 意译+谐音 | 贴合「探索、异步、文字逛世界」 | 与 Mira 读音略远 |
| **弥境世界** | 意境 | 雾、朦胧，贴潮灯气质 | 较文艺，认知成本高 |

### 1.3 定夺（已确认）

| 用途 | 名称 |
|------|------|
| **正式中文名** | **米拉世界** ✅ |
| **英文** | **MiraWorld** |
| **宣传语 / 副标题** | 「一座城、一些人、一碗面」（见 `welcome.json`） |
| **城内地名** | **潮灯市**（叙事层，与品牌层分开） |

### 1.4 显示示例

```
米拉世界 MiraWorld
潮灯市 · 陈师傅 · 标准汤面 15 点
```

## 三、各版本（四象视角）

### v1.0 — 第一市（当前 · 见 `33`）

| 象 | 内容 |
|----|------|
| 人 | handle + 配置 NPC |
| 地 | 潮灯市 + spot 彩蛋 |
| 事 | visit, order, message, ledger |
| 物 | 1 offer（标准汤面）+ stack |

**不讲：** 开店、配送、私信、auto。

---

### v1.1 — 烟火

| 象 | 补充 |
|----|------|
| 地 | spot 首次到访文案 |
| 事 | message 庆祝模板；order 里程碑文案 |
| 人 | NPC 多一句场景对白 |
| UI | 条件轮询未读；空状态暖文案 |

仍不做玩家挂单、私信。

---

### v1.2 — 开灶

| 象 | 补充 |
|----|------|
| 人 | **player 作 seller** 挂 offer |
| 事 | message 往来（player↔player）；job record 雏形 |
| 物 | 多 offer；简单 recipe |

店 = 人，不单独 shops 表（或 shops 作 player 别名）。

---

### ~~v1.3 — 脚程~~（已取消）

> **2026-09-13：** 不做独立配送版本。商品默认 **下单 → 通知 → 背包**（见 [35](./35-简化原则定稿.md)）。不恢复骑手、运费、子单。

| 旧设想 | 现为 |
|--------|------|
| 骑手 / 配送子单 / ETA | 不收录 |
| 吴跑腿履约 | NPC 仅 lore |
| 运费、区域派单 | 后置或合并进 offer 一口价 |

---

### v1.4 — 当班

| 象 | 补充 |
|----|------|
| 人 | player 日程 profile |
| 事 | auto 代接单/烹饪（order + 日志 message） |

见原 `27`。

---

### v1.5 — 购售委托

| 象 | 补充 |
|----|------|
| 事 | **bounty**（`buy` / `sell`）；通知统一 |
| UI | 悬赏栏；**我的** 入口 |
| 物 | 上架委托 ≤ 10 单/人 |

见 [41-v1.6之后工作安排](./41-v1.6之后工作安排.md)。

---

### v2.0 — 留痕

| 象 | 补充 |
|----|------|
| 事 | **trace** record（粉笔）；job 完整应聘 |
| 人 | 雇员分成（ledger） |

---

### v2.x — 社会

- 势力标签（player.payload，非地址）
- **vote** record
- 律师 **dispute** record（一种案型）

---

### v3.x — 创作

- Blueprint / 模板（仍映射 offer + order）
- 家园 stack 摆放
- T2 词条提请

**准入规则：** 必须先落 [32](./32-四象统一定稿.md) 四象，否则不排期。
