# 现代行政区划世界观定稿

> 状态：**世界观最终方向**  
> 记录时间：2026-09-13（修订：澄清市/区层级）  
> 定夺：**A市、B市、C市 = 城市代称**；其下有 **区、街道、小区…** 完整地址链；货币仍 **credits / 点**（`30`）

---

## 〇、上次误解 vs 本次定夺

| | 错误理解（已废弃） | 正确理解 |
|--|-------------------|----------|
| A、B、C 指什么 | 同一城里的「A区、B区」 | **A市、B市、C市** —— **城市名词代称** |
| 类比 | 园区分区编号 | **北京市朝阳区** —— 市 + 区 |
| 地址 | 只有一层区号 | **省 → 市 → 区 → 街道 → 小区 → 单元 → 门牌** |

**口诀：字母标城市；区名像真区；地址能写到门牌。**

---

## 一、定夺摘要

| 项 | 选择 |
|----|------|
| **地址层级** | 省 · 市 · 区 · 街道 · 小区 · 单元 · 门牌 |
| **城市代称** | **A市、B市、C市…**（全服统一代号，好记） |
| **区内名称** | 真区名风格：**枢纽区、滨湖区、商贸区**（不叫「A区」） |
| **MVP 范围** | 主玩 **A市** 内 6 个 **区**；B市、C市 地图边缘可打卡预览 |
| **NPC** | 职务 + 短名；常驻地址写到 **市+区** |
| **货币** | 不变：**credits / 点** |

## 三、城市代称（A市 / B市 / C市）

| `city_id` | 代称 | 说明 | MVP |
|-----------|------|------|-----|
| `city_a` | **A市** | 主城市，6 区可逛 | ✅ 出生默认 |
| `city_b` | **B市** | 邻市，湖滨方向 | 地图预览 / 1 节点 |
| `city_c` | **C市** | 邻市，商埠方向 | 地图预览 / 1 节点 |

**字母只标「哪座城市」，不标区。** 区用 **枢纽区、滨湖区** 这种真名。
