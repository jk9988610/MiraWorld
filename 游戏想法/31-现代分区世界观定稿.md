# 现代分区世界观定稿

> 状态：**世界观最终方向（取代原文奇幻风）**  
> 记录时间：2026-09-13  
> 定夺：**区域用 A区/B区… 脱口可认**；NPC 用 **职务 + 短名**；货币仍用 **credits / 点**（见 `30`）

---

## 一、定夺摘要

| 项 | 选择 |
|----|------|
| **叙事风格** | **现代分区城** — 像园区/接驳枢纽，不叫奇幻地名 |
| **区域代号** | **A区、B区、C区…**（全服统一，好记好指认） |
| **NPC** | **职务 + 两字名**（陈师傅、小林、周管理） |
| **组织** | **平台** / **管理处**（不说商会、拾遗院） |
| **货币** | 不变：**信用点 / credits / 点**（`30`） |
| **玩法** | 不变：探索 · 点菜 · 系统通知（`29`） |

**口诀：区号一口能说清；人看职务就知道干啥；账上还是 credits。**

## 三、首发 6 区（地图节点）

```
              [ E区 · 档案塔 ]
                    |
    [ D区 · 商业街 ]——[ A区 · 枢纽站 ]——[ B区 · 栈桥廊 ]
                           |                    |
                    （你在这）              [ C区 · 湖滨休息 ]
                                               |
                                        [ F区 · 遗迹长廊 ]
```

### 3.1 节点表（`locations.json`）

| `location_id` | 区号 | 显示名 | 一句话 | MVP |
|---------------|------|--------|--------|-----|
| `zone_a` | **A区** | 枢纽站 | 主入口、A区食堂、前台 | ✅ 出生推荐 |
| `zone_b` | **B区** | 栈桥廊 | 连接廊道，看接驳牌 | ✅ |
| `zone_c` | **C区** | 湖滨休息 | 长椅、湖景、慢节奏 | ✅ |
| `zone_d` | **D区** | 商业街 | 招牌林立（v1.0 只浏览） | ✅ |
| `zone_e` | **E区** | 档案塔 | 管理处、规则公示 | ✅ |
| `zone_f` | **F区** | 遗迹长廊 | 未开放感、远景 | ✅ 可打卡 |

### 3.2 邻接（步行）

| 从 | 可到 |
|----|------|
| A区 | B区、D区 |
| B区 | A区、C区 |
| C区 | B区、F区 |
| D区 | A区、E区 |
| E区 | D区、F区 |
| F区 | C区、E区 |

## 四、NPC 命名规范

**规则：** `职务（玩家一眼懂）` + `两字名（好念）`；代码用 `npc_<姓拼音>`。

| `npc_id` | 玩家看见 | 职务 | 常驻区 | 首发作用 |
|----------|----------|------|--------|----------|
| `npc_xiaolin` | **小林 · 前台** | A区接待 | A区 | 新手引导文案 |
| `npc_chen` | **陈师傅** | A区食堂厨师 | A区 | v1.0 出餐 NPC |
| `npc_xu` | **许店员** | D区便利店 | D区 | 地点氛围 |
| `npc_wu` | **吴跑腿** | B区接驳 | B区 | 配送预告 lore |
| `npc_he` | **何向导** | C区湖滨 | C区 | 休息区对话 |
| `npc_zhou` | **周管理** | E区档案 | E区 | 规则/帮助指向 |

**不说：** 「林溯文书」「柯岚收购」等奇幻头衔 —— 统一成职务。

### 4.1 系统发言口吻

| 场景 | 示例 |
|------|------|
| 下单托管 | 「订单 #1024 已托管 **15 点**，陈师傅开始备餐。」 |
| 出餐通知 | 「A区食堂：标准汤面已出餐，请到订单页取餐。」 |
| 新手礼 | 「欢迎加入。平台赠送 **300 点**。」 |
| 首次打卡 | 「你第一次到 **B区 · 栈桥廊**。接驳牌上写着：→ A区 / → C区。」 |

## 五、与 credits 的统一皮肤

| 现代母概念 | 技术 | 玩家看见（中文） |
|------------|------|------------------|
| 分区 | `location_id: zone_a` | **A区 · 枢纽站** |
| 人物 | `npc_id` | **陈师傅**（A区食堂） |
| 货币 | `wallet_credits` | **128 点** |
| 店铺 | `shop_id: shop_a_canteen` | **A区食堂** |
| 商品 | `sku_standard_noodle` | **标准汤面 · 15 点** |

**叙事不再写：** 雾、灯油、弦断、拾遗 —— **除非** 作为 F区「遗迹」里的彩蛋文案（可选，非主调）。

## 六、首发体验流（现代版）

```
1. 注册 handle → 落在 A区 · 枢纽站
2. 小林前台一句：「没主线。先逛各区，或去 A区食堂。」
3. 地图 6 区打卡变色
4. A区食堂 → 标准汤面 15 点 → 托管
5. 陈师傅出餐 → 背包 +1 → 系统通知
6. 「我的」：余额、足迹（已到访 6 区中的 N 个）
```

**发布会标题建议：** 「MiraWorld · 第一区」—— 能逛、能点、能收通知。
