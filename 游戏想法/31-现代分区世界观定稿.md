# 地（Place）定稿

> 状态：**四象中的「地」** — 全系统规范见 [32-四象统一定稿](./32-四象统一定稿.md)  
> 记录时间：2026-09-13  
> 原则：**地址只有市**；精确定位 **市 + 人**；货币见 `30`

---

## 一、定夺

| 项 | 选择 |
|----|------|
| **地址（一段）** | 只有 **市**，如 `潮灯市` |
| **匹配定位** | **市 + 人** —— NPC 或玩家 handle |
| **不要** | 区、街道、小区、格号、门牌…… |
| **玩法** | 探索 · 点菜 · 通知（`29`） |

**口诀：地址只说市；找谁再加人名。**

---

## 二、唯一标准地址

### 2.1 一段

| 段 | 字段 | 示例 |
|----|------|------|
| 市 | `city` | `潮灯市` |

```json
{ "city": "潮灯市" }
```

### 2.2 市 + 人 = 完整匹配

地址只有市；**要落到具体谁**，加 **人**：

| 类型 | 字段 | 示例 |
|------|------|------|
| NPC | `npc_id` / 显示名 | 潮灯市 · **陈师傅** |
| 玩家 | `handle` | 潮灯市 · **@雾桥阿青** |

```json
{
  "city": "潮灯市",
  "person": { "type": "npc", "id": "npc_chen", "display": "陈师傅" }
}
```

**口语：**

- 「食堂在哪？」→ 「潮灯市，找陈师傅。」  
- 「信发给谁？」→ 「潮灯市 · @雾桥阿青」  
- 「店在哪？」→ 店绑 **负责人 NPC**（陈师傅），不另写区名。

### 2.3 够用在哪

| 场景 | 写法 |
|------|------|
| 你在哪 | `潮灯市`（宏观） |
| 找食堂/下单 | `潮灯市` + 陈师傅 |
| 系统店 | `shop` → `chef_npc_id: npc_chen` |
| 往来信 | 收件人 **handle**（市内/跨市同一套） |
| 打卡 | 到过 **潮灯市**（v1.0 可到市即可） |
| 配送 | ~~独立玩法~~ | **v1.0 不做**；物直收背包（见 `35`） |

### 2.4 不收录

区、街道、小区、户号、格号 —— **都不是地址段**。  
若地图上有「晚霞区」之类，只能是 **市内逛点 / 文案**，不写进 `address`。

## 三、城市与 NPC（首发）

### 3.1 城市

| `city_id` | 显示 | MVP |
|-----------|------|-----|
| `city_chaodeng` | **潮灯市** | ✅ 主城市 |
| `city_b` | **B市** | 预览 |
| `city_c` | **C市** | 预览 |

### 3.2 潮灯市 · NPC 表

| `npc_id` | 显示 | 职务 | 作用 |
|----------|------|------|------|
| `npc_xiaolin` | 小林 · 前台 | 接待 | 新手引导 |
| `npc_chen` | 陈师傅 | 厨师 | **系统食堂、出餐** |
| `npc_wu` | 吴跑腿 | 栈桥区 NPC | lore 露面，无配送玩法 |
| `npc_he` | 何向导 | 向导 | 市内逛点介绍 |
| `npc_xu` | 许店员 | 店员 | 店铺氛围 |
| `npc_zhou` | 周管理 | 管理 | 规则说明 |

**系统食堂：** 潮灯市 · 陈师傅（`shop` → `person: npc_chen`）

### 3.3 市内逛点（可选，非地址）

仅供地图文案/打卡彩蛋，**不进地址表**：

晚霞岸、栈桥、商贸街、文档塔、远郊 —— 玩家说「我去晚霞岸」可以，但系统记账仍只认 `潮灯市`。

## 五、首发体验流

```
1. 注册 → 潮灯市
2. 小林：「没主线。在潮灯市转转，或找陈师傅点碗面。」
3. 打卡潮灯市（或市内逛点作彩蛋，地址仍只是市）
4. 找陈师傅 → 标准汤面 15 点 → 托管 → 出餐
5. 通知：「陈师傅：面好了。」
```

## 六、小结

| 问题 | 答案 |
|------|------|
| 地址几段？ | **1 段：市** |
| 怎么精确定位？ | **市 + 人**（NPC 或 handle） |
| 晚霞区？ | 文案/逛点，**不是地址** |
| 示例？ | 住址 `潮灯市`；找食堂 `潮灯市 · 陈师傅` |
