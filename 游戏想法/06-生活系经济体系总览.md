# 生活系经济体系总览：我们讨论了多少种？

> 状态：体系归纳 + 视角与新奇度讨论  
> 记录时间：2026-09-12  
> 来源：与作者的讨论  

---

## 一、一句话

到目前为止，我们大约讨论了 **六大类、二十余种「生活味」体系**——从买菜做饭、研发生产、分割上架，到跑腿外卖、异步留痕、蓝图分账。  
它们都尽量**从现实生活找原型**，让玩家觉得「懂」；再通过 **点菜、异步、无主线、潮灯包装** 换一层体验，避免变成庸俗刷材料。

---

## 二、你记得的三条链（都在文档里）

| 你描述的链 | 现实类比 | 文档中的名字 | 主要出处 |
|------------|----------|--------------|----------|
| **买材料 → 生产 → 包装 → 销售** | 小餐馆、作坊、食品厂 | **商品单**（商家 B₁ 备料→制作→打包）+ **店铺上架**；可选骑手 B₂ 配送 | `01` §3.5、§12 定制代工 |
| **研发 → 生产 → 销售** | 芯片方案公司→产品公司→商城 | **B₁ 蓝图研发 → B₂ 产品包装 → 全服商城/Steam 式发售** | `01` §十五、§十八、§二十 |
| **获取原材料 → 分割 → 上架** | 屠宰分切、批发拆零、闲鱼卖闲置 | **采集/持有原材料 → 拆分库存 → 二手挂单 / 店铺 SKU**；代工单也可「按图纸分割加工」 | `01` §12 二手、定制；可扩展采集玩法 |

三条链**不互斥**，可以并存：有人当 **原料商**（分割上架），有人当 **作坊**（买料生产），有人当 **方案公司**（研发蓝图卖授权），有人只当 **食客**（点菜吃现成的）。

## 四、用一张表串起「生活链」

```
                    ┌─────────────────────────────────────┐
                    │  L0 系统（厨房 / 芯片 / 馆规）        │
                    └──────────────────┬──────────────────┘
                                       │
     ┌─────────────┬─────────────┬─────┴─────┬─────────────┐
     ▼             ▼             ▼           ▼             ▼
  采集/购买      研发蓝图       点菜我要     探索地图      信箱往来
  原材料        (B₁)          (食客)       打卡留痕      (异步)
     │             │             │           │             │
     ▼             ▼             ▼           │             │
  分割/库存      授权给 B₂      匹配厨师      │             │
     │             │             │           │             │
     ▼             ▼             ▼           │             │
  上架/代工      包装 SKU       服务/商品单 ──┴─────────────┘
     │             │             │
     └──────┬──────┴──────┬──────┘
            ▼             ▼
         托管交易      跑腿配送
            │             │
            ▼             ▼
         买家 C        验收分账
```

**统一底座**（`01`）：订单状态机 + 托管账户 + 服务器验收 + 事件溯源。  
不同生活链 = 不同 **订单类型** + 不同 **参与角色**，不是各写一套经济。

## 五、不局限于「线下」：线上 / 数字同样是一条生活链

很多链在 MiraWorld 里**天然是数字的**，但生活感不变：

| 生活感 | 线下隐喻 | 线上/数字实现 |
|--------|----------|----------------|
| 买一份调查经历 | 买杂志、买地图 | 购买 Blueprint 绑定的 **可玩内容包** |
| 研发方案 | 写菜谱、写剧本 | **Blueprint 编辑器** + 沙盒校验 |
| 包装上架 | 设计封面、定价 | **Product SKU** + 店铺页 |
| 分割出售 | 拆卖合集里的一章 | 捆绑包拆 SKU、二手转卖 **数字权益** |
| 研发生产销售 | 游戏公司发行 | **Studio + Steam 式商城**（`01` §二十） |
| 跑腿 | 送实体货 | 送 **物品数据** 或 **触发某地点事件** |
| 服务 | 上门修东西 | **远程异步服务** + 信箱交付（`04`） |

所以：**不是只做「线下仿真」**；而是 **生活结构的隐喻**（买、做、卖、送、等、信）套在 **文字 + 数字权益** 上。

## 六、采取哪种视角？会不会太平常或太庸俗？

### 6.1 可选视角（可并存，玩家自选主身份）

| 视角 | 日常感 | 新奇感来源 | 风险 |
|------|--------|------------|------|
| **食客**（默认） | 最强：点菜、吃、评价 | 自己点菜定义人生；口味谱 | 若菜单贫乏会像空餐馆 |
| **厨师 / 行者** | 强：接单、出活、赚钱 | 双身份同一天；异步交付 | 易变「打工模拟器」 |
| **店主 / 原料商** | 强：进销存、上架 | 分割上架、二手、代工 | **最易庸俗**：刷材料、盯行情 |
| **方案方 B₁** | 中：像独立开发者 | SDK 编排、不卖代码卖方案 | 门槛高，需编辑器 |
| **产品方 B₂** | 中：像发行商 | 包装别人的蓝图、定价 | 像小型 Steam 店主 |
| **旅人** | 强：走路、打卡、看痕迹 | 异步「有人来过」 | 若地图空则冷清 |
| **车载旁观者** | 中：窗外风景变 | 无首页、壳层随身（`05`） | 需风景层持续有内容 |

**建议默认入口：食客 + 旅人**（点菜 + 地图），经营链 **解锁后再进**，避免新玩家一上来面对进销存报表。

### 6.2 为什么用生活体系？

| 好处 | 说明 |
|------|------|
| **可理解** | 不用解释「什么是 escrow」——说是「托管收货放款」即可 |
| **可迁移** | 玩家自带直觉：买料、生产、上架 |
| **可裁剪** | MVP 只做跑腿+点菜，不强迫全产业链 |
| **可异步** | 外卖、信箱、留痕都天然适合错时 |

### 6.3 怎样避免「太平常 / 太庸俗」？

庸俗感往往来自：**无意义的重复劳动 + 系统催 + 人人相同的最优解**。

| 庸俗陷阱 | 本作的对冲（已讨论过的） |
|----------|--------------------------|
| 每日刷材料 | **无主线、无系统日常派单**（`02`） |
| 必须在线抢单 | **异步信箱、异步痕迹**（`03` `04`） |
| 职业树逼肝 | **口味谱**，身份由你点的单历史形成（`02`） |
| 聊天室喷子 | **往来信箱**，无全服实时公屏（`04`） |
| 假同时在线 | **痕迹与信串**营造「有人」，不造假在线数（`04`） |
| 进销存表格感 | **潮灯叙事包装** + 订单用「委托函/悬赏令」文案（`01`） |
| 创作者剥削感 | **B₁ 蓝图分账**、协议栈明确 royalty（`01` §十八） |

**新奇不在「发明从未见过的产业」**，而在：

1. **你是食客，不是任务机器** — 点菜式成长  
2. **世界是错时的邮局与足迹** — 异步通讯 + 地图痕迹  
3. **产销可以是数字方案链** — 芯片/SDK 隐喻，不是纯砍树挖矿  
4. **界面像坐车窗外换景** — 车载壳层（`05`）  

若某条链玩起来像 **班**：说明该链 **奖励与叙事没绑好**，或 **强迫频率太高**——应减频、加口味选择、或改成纯可选副业。

### 6.4 「现实一点」和「另一层体验」如何同时成立？

```
现实层（结构）          体验层（味道）
─────────────          ─────────────
买料生产卖              → 潮灯港的灯油与护符，不是小麦与木板
外卖跑腿                → 信使穿过雾桥，不是骑电动车
研发生产销售            → Blueprint 与可玩内容包，不是工厂报表
信箱往来                → 委托函与馆方贺信，不是 QQ 闪屏
```

**结构来自生活，皮肤来自世界观，节奏来自异步与自选。**

## 七、分期建议（避免一次做 31 个）

| 阶段 | 体系重点 | 玩家主视角 |
|------|----------|------------|
| **MVP** | 点菜、跑腿、地图打卡、信箱、车载壳层 | 食客 + 旅人 |
| **v2** | 商品单、服务单、店铺、手动领奖成就 | + 厨师 / 行者 |
| **v3** | 二手、悬赏调查、定制代工、采集→分割→上架 | + 店主 / 原料商 |
| **v4** | B₁/B₂ 蓝图链、商城、订阅 | + 创作者 / 发行商 |
| **后期** | 拍卖、期货、租赁、票务… | 按需开放 |

## 九、小结

| 问题 | 答案 |
|------|------|
| 讨论了多少种？ | **六大类、约 31 个命名体系**（含分期项） |
| 你记得的三条链？ | 都在：**产销 / 研产销 / 采分售** |
| 只线下吗？ | **否**；数字 Blueprint、商城、权益交付是主线之一 |
| 什么视角？ | 默认 **食客+旅人**；经营/研发可选深入 |
| 会太庸俗吗？ | 生活结构本身不庸俗；**强迫刷、无选择、假社交**才庸俗——用点菜、异步、无主线对冲 |

> 生活体系是 **熟悉的骨架**；潮灯、点菜、错时留痕是 **陌生的气味**。骨架让人敢进门，气味让人想再来。
