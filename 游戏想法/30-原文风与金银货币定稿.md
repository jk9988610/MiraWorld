## 二、世界观与故事（原文风，简短）

### 2.1 一句话

> **MiraWorld** 是一座有雾的港口世界：潮灯商会管灯火与契约，拾遗院管旧档，你在地图上走过会留下足迹；  
> 花钱用 **金币、银币**，下单走馆规托管，回信进 **系统信箱** —— 不必谁都在线。

### 2.2 首发故事框（帮助页 / 发布会）

你是新来的 **行者**。馆里送你一点 **银币** 当见面礼。  
从 **潮灯港** 能走到旧栈桥、镜湖驿；食堂在港口，点一碗雾港汤面，钱先押在柜上，出餐进背包，信里会告诉你。  
**没有主线** —— 逛、吃、收信，随你。

气质：雾、灯、契约、足迹 —— **不是现代都市 App，不是赛博朋克**。

### 2.3 与 `docs/` 的关系

- **继续用** 现有 `docs/places/`、`docs/factions/` 奇幻设定  
- 游戏地图节点与 lore **slug 对齐**（灰烬港/潮灯港等按你们统一译名）  
- ~~接缝市、Relay~~ **废弃**，不再作为主推

## 三、货币：只改「钱的名字」，不改馆规逻辑

> 技术细节同前定稿：`wallet_silver` 单字段、1:100 显示。  
> 以下继承 `23` 托管分账流程，仅把「灯油」改成「银/金」。

### 3.1 规则

| 项 | 说明 |
|----|------|
| 玩家看见 | **金币、银币** |
| 固定汇率 | **1 金币 = 100 银币** |
| 服务器 | 只存 **`wallet_silver`（整数）** |
| 显示 | `1288` → **12 金 88 银** |
| 兑换按钮 | **无**（一个总数，界面拆分） |

### 3.2 和灯油、和背包物品

| 概念 | 首发 |
|------|------|
| **灯油当钱** | ❌ 废弃；叙事里仍可出现「灯油味」「灯火」作 **场景** |
| **钱包金/银** | ✅ 唯一结账货币 |
| **背包里的金锭/灯油瓶** | v1.0 不做；以后若有是 **L1 物品**，不能当钱 |

**叙事例：** 林溯指尖有灯油味 —— 是 **气味**；付账仍扣 **15 银**。

### 3.3 帮助页

> 馆里用 **金币、银币** 记账，**1 金 = 100 银**，馆规固定。  
> 钱包是一个总数，会显示成金、银；与背包里的东西不是同一种。  
> 不能换现实货币。

## 四、物价锚点（真实体感，整数银）

**内部锚点（不对玩家承诺兑付）：** 1 银 ≈ 一块钱饭的体感；1 金 ≈ 一百块量级。

| 商品 / 费用 | 标价 |
|-------------|------|
| 雾港汤面（首发 SKU） | **15 银** |
| 加料汤面 | **22～28 银** |
| 一盏花茶饮 | **4 银** |
| 配送费（v1.3） | **5 银** |
| 厨师一单分成 | **3～5 银** |
| 开店登记（v1.2） | **50～100 金** |
| **新手礼** | **30 金**（3000 银） |

配置：`newbie_silver: 3000`  
~~100 灯油 / 100 金新手礼~~ 已废止（太多）。

**铜币：** 首发不加；价目全部 ≥1 银。  
**人民币充值：** 首发不做；以后若做仅单向礼包（§3.3 同前）。
