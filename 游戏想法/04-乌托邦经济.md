# 04 · 乌托邦经济

> **内生闭环 + 市民组 + 机构编制 + 最低工资/生活补贴**  
> 上位：[01-设计总纲](./01-设计总纲.md) · [03-玩家操作与分工](./03-玩家操作与分工.md)

---

## 一、一句话

**乌托邦里，城市自己转：机构生产 → 工资与福利 → 市民消费 → 机构营收。**  
玩家是 **带 handle 的经营者**，用资产参与闭环赚收益；**每日投资金** 是单独的外生补贴，不参与市民账本平衡。

**只输出决策与数字**（买卖、编制、扩产、定价），**不输出** 故事、判决、创作、中介撮合。

---

## 二、双账本（必须分账）

| 账本 | 谁 | 钱从哪来 | 用途 |
|------|-----|----------|------|
| **外生 · 玩家投资** | 玩家 | 乌托邦日投（**不计入**城市总账平衡） | 扩店、扩产、冒险资本 |
| **外生 · 城市福利** | 城市 `welfare_fund` | 乌托邦 **城市定额注入** | **仅** 失业市民 **最低生活补贴** |
| **内生 · 机构与市民** | 机构 + 市民组 | 卖货、工资、消费 | 生产 ↔ 消费闭环 |

**纪律：**

- 市民 **不能** 从「消费池」凭空刷钱。  
- **在岗** 市民钱 **只来自机构工资**（≥ **最低工资标准**）。  
- **无岗** 市民钱 **只来自城市最低生活补贴**（温饱线，非富裕）。  
- 玩家经营所得 **只来自内生闭环**（+ 外生日投另计）。

### 配置示例 `economy/utopia.json`

```json
{
  "min_wage_per_capita_per_day": 12,
  "min_living_subsidy_per_capita_per_day": 8,
  "city_welfare_grant_per_day": 120000,
  "min_wage_floor_enabled": true
}
```

| 概念 | 说明 |
|------|------|
| **最低工资** | 机构发给在岗组：`max(约定工资, min_wage) × 本组在岗人数` |
| **最低生活补贴** | 无岗组：`min_living_subsidy × headcount`，由 **城市福利基金** 付 |
| **城市福利基金** | 每日 `city_welfare_grant` 乌托邦注入；**只** 用于补贴 |

**乌托邦自洽：** 就业靠机构内生营收发薪（发不出则欠薪）；失业靠城市福利温饱，不饿死也不富裕。两条底线 **都有账**。

## 三、三类 Actor

| Actor | 说明 |
|-------|------|
| **玩家** | 仅 `handle`；开店 = 多一个 **机构** |
| **机构** | 面坊、医馆、铁匠铺、玩家店…；雇市民组、发工资、挂 offer |
| **市民组** | 1000 人/组；**一组一主雇**；消费用组内 `wallet` |

**机器岗位**（厨师、服务员、医生…）是 **机构编制 slot**，不是玩家职业。

---

## 四、核心循环（无玩家也能跑）

```
机构生产 / 挂 offer
    → 机构发薪（≥ 最低工资）→ 在岗组 wallet
    → 城市发补贴 → 无岗组 wallet（仅温饱）
    → 市民组按 wallet 买 offer
    → 机构 / 玩家店营收
    → 机构付工资、维护（闭环）
```

**cron 日 tick** 执行；与玩家是否在线无关。

### 日 tick 顺序

```
① institution_production
② institution_payroll          → 在岗组 wallet
③ city_welfare_subsidy       → 无岗组 wallet（最低生活补贴）
④ pop_purchase               → orders（buyer_kind=pop_group）
⑤ fulfill + ledger
⑥ spotlight_sample             → 每店 ≤10
```

## 五、市民组（PopGroup）

| 项 | 定稿 |
|----|------|
| 规模 | **1000 人 / 组** |
| 首发 | 潮灯市 **10 组**（1 万人），初始化固定，不日刷 |
| 雇佣 | **一组一主雇机构** + 一个 `job_type` |
| 钱包 | `wallet`：**仅** 工资 + 无岗时 **最低生活补贴** |
| 消费 | 日 tick 内按 `wallet` 与 `pref` 买可见 `offer` |

### 钱从哪来（禁止无中生有）

| 状态 | 收入来源 |
|------|----------|
| **在岗** | 主雇机构 **工资**（≥ 最低工资） |
| **无岗** | 城市 **最低生活补贴** |

**禁止：** 每日向全体市民注入「消费力常数」。

### 偏好默认 `pref_json`

```json
{ "food": 0.45, "consumable": 0.25, "material": 0.15, "tool": 0.10, "other": 0.05 }
```

## 六、机构编制（Institution）

**机构** = 生产与雇佣单元。陈师傅面坊、潮灯医馆、玩家店 **同一模型**（`owner=system|player`）。

| 字段 | 说明 |
|------|------|
| `id`, `city`, `kind` | 如 `noodle_house`, `clinic`, `smithy` |
| `wallet_credits` | **内生** 运营现金 |
| `open` | 是否营业 |

### 编制 slot

```
slot: job_type, job_display, headcount, employed_groups[]
```

**规则：** Spotlight 上的职业名 = `job_display`，且 slot 上必须有在岗组。**机器员工** 由 NPC 逻辑履约（`auto_on`），**不** 招聘玩家。

### 机构钱从哪来

| 来源 | 说明 |
|------|------|
| **开业 seed** | 一次性（仅 NPC 机构，世界初始化） |
| **卖货** | 市民组 / 玩家 `order` 收入 |
| **支出** | 工资、原料、维护 |

**禁止：** 机构每日无来源大额注入。

### 潮灯市首发 seed

| 机构 | kind | 示例 slot | seed_capital |
|------|------|-----------|--------------|
| 陈师傅面坊 | noodle_house | 厨师×2、服务员×1 | 50000 |
| 潮灯医馆 | clinic | 医生×1、账房×1 | 50000 |
| 城东铁匠铺 | smithy | 铁匠×2 | 40000 |

**10 组市民** 分配进上述 slot；未雇满 = 无岗 → 只领补贴。

## 七、聚光灯（Spotlight）

| 项 | 定稿 |
|----|------|
| 条数 | **每店 10 条**，FIFO |
| 性质 | **仅展示**；删了不影响 ledger |
| 触发 | 该店有一笔 `pop_group` 订单 settled |
| 命名 | **姓 + 职业**（一条显示，如 `王厨师`） |

**姓氏池：** 常见单姓 70% + 复姓 30%（王、李、欧阳、司马…）。  
**职业名不得随机** — 必须等于买家组 `job_type` 显示名，且机构存在对应 slot。  
示例：`王厨师`、`欧阳铁匠`（UI 只显示 `display_name`，不重复职业）。

API：`GET /shop/{id}/spotlight` → 最多 10 条。

---

## 八、乌托邦自洽规则

| 规则 | 说明 |
|------|------|
| **职业必有机构** | 无 slot 的医馆 → 不出现该职业 Spotlight |
| **人口不日刷** | 首发 10 组 × 1000 |
| **最低工资** | `payroll ≥ min_wage × 在岗人数` |
| **最低生活补贴** | 无岗组每人每日 `min_living_subsidy` |
| **补贴 ≠ 富裕** | 补贴仅够基础口粮；想多余收入须 **就业** |
| **玩家日投** | `200_000 + rand(5%,10%) × 玩家总资产`（v2.1 ✅ `POST /capital/daily-investment`） |

## 九、与已实现 v1.x 的关系

| 已有 | 在闭环中的位置 |
|------|----------------|
| `shop` / `offer` | 玩家机构的生产出口 |
| `order` | 买家：`player` 或 `pop_group` |
| `auto_on` | 机构产能 / 接单 |
| `bounty` buy/sell | **玩家间** 贸易（与市民消费分开） |
| `message` | 经营结果通知 |

## 十、明确不做

- ❌ 招贤栏、应聘、雇 **玩家** 当员工  
- ❌ 律师、判决、dispute、馆规法庭  
- ❌ 作家、编剧、trace、叙事产出  
- ❌ 中介 / 委托「做某事」  
- ❌ 旅客 segment、Victoria 级 Pop 政治  
- ❌ 骑手 / 配送  

---

## 十一、验收（v2.0）

1. 无岗组只有补贴，消费力低于在岗组。  
2. 无机构支撑的「医生」等职业 **不会** 出现在 Spotlight。  
3. 每店 Spotlight ≤10；`display_name` = 单姓或复姓 + 职业。  
4. cron 一日，机构与市民账平衡可审计（`GET /economy/audit`）。
