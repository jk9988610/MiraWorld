# 开店执照与招贤栏：营业执照、招聘与应聘

> 状态：商家准入 + 人力市场  
> 记录时间：2026-09-12  
> 来源：与作者的讨论  

---

## 一、问题

有人想开餐厅或店铺：

1. **怎么拿「营业执照」？**（平台里的开店资格）  
2. **开店后怎么招人？**——像 58 同城、招聘网站那样把需求写出来，等人来应聘。  
3. **在我们这种异步文字平台上**，这套流程该怎么落地？

---

## 二、现实对照 → 平台映射

| 现实 | 平台 |
|------|------|
| 营业执照 | `shop_license` → 核发后绑定 `shop_id` |
| 工商登记店名 | `display_name`（`19`） |
| 门店地址 | 绑 `home_id` 或 **灯市摊位** `stall_id` |
| 招聘网站发帖 | **招贤栏** `job_posting`（公开列表） |
| 简历投递 | **应聘** `job_application`（异步） |
| 面试 | **试工单** + 往来信箱几封信（非实时） |
| 录用 | `shop_employee` 关系 + 岗位权限 |
| 职业资格证 | `profession` 考证（厨师考、骑手证等，`09` `10`） |

**口诀：执照管开门；招贤栏管找人；信箱管来回；订单管干活。**

## 三、开店：如何获取「营业执照」

### 3.1 准入流程（建议）

```
玩家点「我要开店」
    │
    ▼
① 前置条件（L2 硬校验）
    · 账号无封禁
    · 可选：完成 1 次「我要」点菜体验（熟悉托管）
    · 可选：绑定一处家园或租得灯市摊位
    │
    ▼
② 开店考（`09` 商家轻量考）
    · 10～15 题：托管、库存、SKU 与描述一致、举报后果
    · 通过 → 获得「准商资格」merchant_eligible
    │
    ▼
③ 提交开店申请
    · 店型：食肆 / 杂货 / 作坊 / 数字铺（`06`）
    · 建议店名 display_name（机审）
    · 绑地点：home 某房间 或 stall_id
    │
    ▼
④ 缴纳登记费（灯油，可退规则待定）
    │
    ▼
⑤ 系统核发 shop_license + 分配 shop_id
    · 邮箱收「营业执照」摘要信（可收藏）
    · 店铺页进入「管理视角」（`20`）
```

| 字段 | 说明 |
|------|------|
| `shop_id` | 馆里唯一户口，**不可改** |
| `shop_license` | 证照记录：核发时间、店型、状态（有效/吊销） |
| `display_name` | 招牌，可改（`19`） |
| `owner_id` | 店主 |
| `location_ref` | `home_id` + `room_*` 或 `stall_id` |

### 3.2 店型与最低门槛（MVP 示例）

| 店型 | 最低摆设（`20`） | 最低 SKU |
|------|------------------|----------|
| **食肆** | `room_kitchen` + 堂食/厅 ≥2 家具 | ≥1 餐饮 SKU |
| **杂货** | `room_hall` 或摊位 | ≥1 商品 SKU |
| **作坊** | 工坊锚点 ≥1 | 可只接订制单，暂无上架 |

**营业开关：** 满足门槛 + `shop_license` 有效 → 店主可「开业」→ 出现在灯市列表（`20`）。

### 3.3 执照失效

| 情形 | 处置 |
|------|------|
| 多次货不对板败诉（`09`） | 警告 → 限流 → **吊销执照** |
| 长期无营业（如 90 天） | 下架，执照休眠；重开免考 |
| 店主主动歇业 | 保留 shop_id，仅关营业开关 |
| 冒充官方势力店名 | 机审拒绝或强制改名 |

## 四、招人：招贤栏（像 58 / 招聘网站）

**不单独做一个「招聘 App」**，而是把招聘做成 **招贤栏的一种帖子类型**，与悬赏栏、公告栏并列（`02` `05`）。

### 4.1 入口

| 入口 | 谁看见 |
|------|--------|
| **壳层 · 招贤** | 所有人浏览 |
| **店铺管理 · 发布招聘** | 店主/会长 |
| **公会驻地 · 内部招贤** | 仅成员或对外可选（`11`） |
| **势力公告栏** | 势力官招史官、大使等 |

### 4.2 招聘帖结构（`job_posting`）

```
job_posting
├── posting_id
├── employer_type: shop | guild | faction
├── employer_id: shop_id / guild_id / …
├── employer_display: 「少盐食堂」招厨师
├── role_id: profession_chef | profession_waiter | profession_rider | …
├── headcount: 2                    # 招几人
├── filled: 0                       # 已录用几人
├── compensation_type: per_order | monthly | bounty_split | negotiable
├── compensation_detail: 「每单 3 灯油」 / 「月薪 80 灯油」
├── requirements[]                  # 硬条件 L2
│     · 须通过厨师考
│     · 信誉 ≥ 60
│     · 可选：擅长标签「清淡」「重辣」
├── schedule_hint: 「晚市 18–22」   # L3 文字，不强制在线
├── description: 岗位说明（L3）
├── status: open | paused | closed
└── expires_at: 可选截止
```

**和悬赏的区别：**

| | 悬赏（`01`） | 招聘帖 |
|--|--------------|--------|
| 目的 | 完成**一笔任务** | 建立**长期雇佣关系** |
| 结束 | 任务交付即结 | 录用后持续，直到离职/解雇 |
| 报酬 | 单次托管 | 每单分成 / 月薪 / 混合 |
| 接单 | 抢单执行 | **应聘** → 店主录用 |

### 4.3 店主发帖流程

```
店铺管理 → 招贤 → 新建
    → 选岗位（厨师 / 服务员 / 骑手 / 店员）
    → 填人数、报酬、要求、说明
    → 可选：预存「试工预算」灯油（托管）
    → 发布 → 进入公开招贤栏
```

**零推送：** 帖子上架不通知全服；求职者**自己逛招贤栏**看见。有人应聘才进店主信箱（`04`）。

## 五、应聘：异步，不像实时面试

### 5.1 求职者流程

```
浏览招贤栏（可按店型/岗位/报酬筛选）
    │
    ▼
点开招聘帖 → 看店铺肖像链接（`20`）、要求、报酬
    │
    ▼
点「应聘」
    → 系统校验 requirements（考证、信誉）
    → 可选附求职信（L3，限字数）
    → 可选勾选「愿接试工单」
    │
    ▼
生成 job_application → 店主信箱通知（异步）
```

### 5.2 店主处理（信箱 + 管理页）

| 操作 | 效果 |
|------|------|
| **查看应聘** | 见对方认证职业、信誉、过往完成单数（L2 摘要） |
| **往来信** | 异步问几句（`04`），非聊天室 |
| **发试工单** | 创建一笔小额 `service_order` 或店内试做 SKU，报酬从试工预算扣 |
| **录用** | 建立 `shop_employee`；`filled += 1`；双方邮箱通知 |
| **婉拒** | 应聘关闭；可附一句 L3 |
| **搁置** | 保持 pending，不超时自动录用 |

**不做：** 同步视频面试、在线排队叫号。

### 5.3 试工单（可选但推荐）

像现实「试岗」：

```
店主发试工 → 应聘者接 → 完成一道试菜 / 一单跑腿
    → 系统验收 → 店主点「满意/不满意」
    → 满意：一键转录用；不满意：仅结试工钱
```

试工钱走 **托管**（`01`），防白嫖劳动力。

## 六、录用后：员工能干什么

### 6.1 `shop_employee` 关系

```
shop_employee
├── shop_id
├── user_id
├── role_id: chef | waiter | rider | clerk
├── permissions[]: accept_order | manage_sku | view_stock | …
├── pay_rule: 引用 job_posting 或单独合约
├── status: active | leave | fired
└── since_at
```

| 岗位 | 典型权限 | 典型报酬 |
|------|----------|----------|
| **厨师** | 接店内餐饮单、消耗后厨库存出餐 | 每单分成 / 底薪+分成 |
| **服务员** | 接服务单、代店主回信（模板） | 每单固定 |
| **骑手** | 接本店配送子单（`01` 商品单） | 每配送单 |
| **店员** | 上架 SKU、改价（店主可限幅） | 月薪 |
| **副厨** | 仅备料子单 | 计件 |

**硬规则：** 员工**不能**转让 `shop_license`、不能吊销执照、不能提现店主主账户（除非司库授权）。

### 6.2 订单怎么分流

```
顾客在「少盐食堂」点菜
    → 订单进 shop 队列
    → 店主 或 已授权厨师 可接
    → 厨师出餐 → 骑手子单（本店雇佣骑手优先可见，再溢出公共池）
    → 系统分账：顾客款 → 店主 + 员工分成 + 平台（`01` §3.5.6）
```

### 6.3 离职

| 方式 | 流程 |
|------|------|
| 员工辞职 | 提交 → 店主确认或 7 天自动生效 |
| 店主解雇 | 信箱通知 + 未结单须结清 |
| 店铺吊销 | 雇佣关系批量终止 |

## 七、和公会招人的关系（`11`）

| | 店铺招聘 | 公会招贤 |
|--|----------|----------|
| 雇主 | `shop_id` | `guild_id` |
| 栏位 | 公开招贤栏 + 店铺页 | 公会对外招贤 / **内部栏** |
| 岗位 | 厨师、骑手、店员 | 秘书、司库、编剧、招贤 |
| 关系 | `shop_employee` | `guild_member` + 职位 |
| 报酬 | 订单分成 / 月薪 | 公会司库、内部悬赏 |

**同一套 `job_posting` 模型**，`employer_type` 不同即可；UI 上可筛「店铺在招人」「公会在招人」。

## 八、界面布局（车载 `05`）

### 8.1 招贤栏列表页

```
【招贤栏】
筛选：岗位 · 店型 · 报酬 · 势力/区域

┌─────────────────────────────────────┐
│ 少盐食堂 · 招厨师 ×2                 │
│ 每单 3 灯油 · 须厨师考 · 潮灯港      │
│ [ 查看店铺 ] [ 应聘 ]                │
├─────────────────────────────────────┤
│ 北风商队 · 招行者 ×1                 │
│ 公会 · 按单分成 · 信誉≥50            │
└─────────────────────────────────────┘
```

### 8.2 招聘帖详情

```
抬头：雇主名 + 岗位 + 状态（招聘中 1/2）
专题：岗位说明、要求清单、报酬
链接：→ 店铺地点页（`20`）参观
行动：应聘 / 已应聘待回复
痕迹：无或仅「已有 5 人投递」计数（不公开他人简历）
```

### 8.3 店主管理 · 招聘 Tab

```
进行中招聘帖
待处理应聘（红点进信箱）
在职员工列表
发新招聘 / 暂停 / 关闭
```

## 九、防滥用

| 风险 | 馆规 |
|------|------|
| 假招聘骗简历 | 发帖收小额押金；多次恶意拒付试工 → 限发帖 |
| 试工白嫖 | 试工款托管，完成必结 |
| 员工卷款跑路 | 分账在**订单完成时**自动拆，不经员工手提现全款 |
| 同一账号自聘自干 | 同 `shop_id` 下 owner 与 employee 不可同人（`01` 闭环限制） |
| 招聘帖刷屏 | 每店同时 open 帖上限；冷却时间 |
| 冒充大店招人 | 帖头展示 `shop_id` 认证标 + 链接实地页 |

## 十、MVP 建议

| 做 | 不做 |
|----|------|
| 开店考 + 核发 `shop_id` | 复杂工商年检 |
| 招贤栏 1 个 Tab：`job_posting` | 独立招聘站 |
| 岗位：厨师、骑手（2 种） | 全职业招聘 |
| 应聘 → 信箱 → 录用 / 婉拒 | 实时面试 |
| 可选 1 笔试工单 | 月薪自动发薪（v2） |
| 员工接本店订单 + 简单分成 | 员工改店名、动执照 |

## 十二、小结

| 问题 | 答案 |
|------|------|
| 怎么拿营业执照？ | **开店考 → 申请店型/店名/地点 → 登记费 → 核发 `shop_license` + `shop_id`** |
| 怎么像 58 招人？ | **招贤栏发 `job_posting`**：岗位、人数、报酬、要求、说明 |
| 怎么应聘？ | **浏览栏 → 应聘 → 店主信箱异步处理 → 可选试工单 → 录用** |
| 和悬赏区别？ | 悬赏是**一单**；招聘是**雇佣关系** + 持续接单权限 |
| 异步怎么做？ | **栏上贴榜，信箱来回，试工走托管订单**；不实时聊天面试 |

> 想开店，先考过馆规、领一张馆里的执照；  
> 想用人，把招贤帖贴上栏——  
> 来的人投名帖，你在信箱里慢慢挑，试得一手好菜再留人。
