## 一、机构（Institution）

**机构** = 生产与雇佣单元。陈师傅面坊、潮灯医馆、玩家店 **同一模型**（`owner=system|player`）。

| 字段 | 说明 |
|------|------|
| `id`, `city`, `kind` | 如 `noodle_house`, `clinic`, `smithy` |
| `display_name` | 潮灯面坊 |
| `owner_kind` | `system` \| `player` |
| `owner_id` | NPC id 或 player_id |
| `wallet_credits` | **内生** 运营现金 |
| `open` | 是否营业 |

### 编制 slot

```
slot: job_type, job_display, headcount,
      employed_groups[]   // 指向 pop_group
```

**规则：** Spotlight 上的职业名 = `job_display`，且 slot 上必须有在岗组。

**机器员工：** slot 由 **NPC 逻辑** 履约（`auto_on`、产能），**不** 招聘玩家。

## 二、工资与乌托邦底线

配置 `economy/utopia.json`（示例）：

```json
{
  "min_wage_per_capita_per_day": 12,
  "min_living_subsidy_per_capita_per_day": 8,
  "city_welfare_grant_per_day": 120000,
  "min_wage_floor_enabled": true
}
```

| 概念 | 说明 |
|------|------|
| **最低工资** | 机构发给在岗组：`max(约定工资, min_wage) × 本组在岗人数` |
| **最低生活补贴** | 无岗组：`min_living_subsidy × headcount`，由 **城市福利基金** 付 |
| **城市福利基金** | 每日 `city_welfare_grant` 乌托邦注入 + （后置）机构税；**只** 用于补贴 |

**乌托邦自洽：**

- 就业 → 靠机构 **内生** 营收发薪（发不出则欠薪，机构收缩）。  
- 失业 → 靠 **城市福利** 温饱，不饿死，也不富裕。  
- 两条底线 **都有账**，不是静默改 `wallet`。

## 三、机构钱从哪来

| 来源 | 一次 / 每日 |
|------|-------------|
| **开业 seed** | 一次性 `seed_capital`（世界初始化，仅 NPC 机构） |
| **卖货** | 市民组 / 其他机构 / 玩家 `order` 收入 |
| **支出** | 工资、原料、维护 |

**禁止：** 机构每日无来源大额注入（与玩家日投不同）。

---

## 四、日 tick（机构段）

```
① production     按 slot/offer 补库存或产能
② payroll        机构 wallet → 在岗 pop_group.wallet（≥ min_wage）
                 钱包不足：本 tick 欠薪记录，可减岗/关 offer
③ （市）welfare  welfare_fund → 无岗 pop_group.wallet
```

## 五、潮灯市首发 seed（默认）

| 机构 | kind | 示例 slot | seed_capital |
|------|------|-----------|--------------|
| 陈师傅面坊 | noodle_house | 厨师×2、服务员×1 | 50000 |
| 潮灯医馆 | clinic | 医生×1、账房×1 | 50000 |
| 城东铁匠铺 | smithy | 铁匠×2 | 40000 |

**10 组市民** 分配进上述 slot（未雇满 = 无岗 → 只领补贴）。示例：

| 组 | 主雇 | job_type |
|----|------|----------|
| pg_01～03 | 陈师傅面坊 | 厨师 / 服务员 |
| pg_04～06 | 潮灯医馆 | 医生 / 账房 |
| pg_07～10 | 城东铁匠铺 | 铁匠 |
| （未分配组） | — | 无岗，仅补贴 |

## 六、玩家店 = 机构

| 已有 v1.2 | 对应 |
|-----------|------|
| `shops` + `player_offers` | 玩家机构 + offer |
| `auto_on` | 机构 auto 产能 |
| 登记费 100 点 | 开业成本（内生） |

玩家 **不** 出现在市民 slot 里；玩家雇的是 **NPC slot**（厨师、服务员），不是雇玩家。

开店细则见 [21-开店与机构编制](./21-开店与机构编制.md)（已从旧「招贤栏」文档改写）。

## 七、明确不做

- ❌ 招贤栏、应聘玩家  
- ❌ 机构间「雇玩家当员工」  
- ❌ 无 slot 的职业名
