## 二、地（Place）

**口诀：地址只说市；找谁再加人名。**

| 项 | 定稿 |
|----|------|
| 地址（一段） | 只有 **市**，如 `潮灯市` |
| 精确定位 | **市 + 人** — NPC 或玩家 handle |
| 不要 | 区、街道、小区、格号、门牌 |

```json
{ "city": "潮灯市", "person": { "type": "npc", "id": "npc_chen", "display": "陈师傅" } }
```

**逛点**（晚霞岸、栈桥、文档塔…）仅供地图文案/打卡彩蛋，**不进地址表**。

### 首发 NPC

| npc_id | 显示 | 作用 |
|--------|------|------|
| `npc_xiaolin` | 小林 · 前台 | 新手引导 |
| `npc_chen` | 陈师傅 | **系统食堂、出餐** |
| `npc_wu` | 吴跑腿 | lore 露面，**无配送玩法** |
| `npc_he` | 何向导 | 市内逛点介绍 |

**系统食堂：** 潮灯市 · 陈师傅

### 首发体验流

```
注册 → 潮灯市 → 打卡 → 找陈师傅 → 15 点托管 → 通知「面好了」→ 确认收进背包
```

**没有主线** —— 逛市、吃饭、收通知，随你。

## 三、钱（Credits / 点）

| 层 | 叫什么 | 用在哪 |
|----|--------|--------|
| 叙事（中文） | 信用点 / **点** | 菜单、通知、帮助页 |
| 技术（英文） | **credits** | 库字段 `wallet_credits`、API |
| 玩家体感 | 像平台贡献点 | **不能提现、不能兑人民币** |

**规则：** 单整数、无汇率、无充值按钮。新手礼 **300 点**。

### 物价锚点（内部体感，不对玩家承诺兑付）

| 商品 / 费用 | 标价 |
|-------------|------|
| 标准汤面 | **15 点** |
| 开店登记 | **100 点** |
| 新手礼 | **300 点** |

---

## 四、文风

**讲：** 分区世界 · 地图记得你来过 · 用 **点** 点菜、托管 · 通知异步收  

**不讲：** 奇幻地名、金锭银币、灯油当钱、人民币充值、配送骑手 drama
