# 36 · 玩家操作与用语定稿

> 与 **35**、**42–44** 一致。玩家是 **handle 经营者**；**无市民/旅客标签**；**无招贤、无雇玩家**。

---

## 一、玩家能做什么

| 操作 | 说明 |
|------|------|
| **开店** | 选类型、起名、**handle** |
| **上架/下架** | 商品与 **购/售委托**（各最多 **10** 单 open） |
| **改价** | 本店商品 |
| **接单/拒单** | 订单 |
| **委托** | **购买** / **出售**（`kind` + `item_id` + `qty`） |
| **通知** | 订单与委托 **一律通知**（含 NPC 店） |
| **日投** | 外生注资（规划 v2.0） |

**不做**：招贤、应聘、雇玩家、律师、作家、trace、中介、委托做某事、当面交差。

---

## 二、用语

| 概念 | 用语 |
|------|------|
| 经营者 | **handle**（玩家/NPC 同规则） |
| 市民 | **Lite Pop** 组内匿名统计；Spotlight **姓+职业** |
| 无岗 | **最低生活补贴**（温饱） |
| 在岗 | **最低工资标准** |
| 委托 | **购买委托** / **出售委托** |
