# 线下到线上：国家、小团体与联盟（简化模拟）

> 状态：组织层 + MVP 建议  
> 记录时间：2026-09-12  
> 来源：与作者的讨论  

---

## 一、一句话

把现实里 **国家、国内小团体、国家间联盟** 搬到线上，做**简化模拟**——  
平时 **异步**（往来信箱、公告栏）；只有 **主动开会** 时才同步。  
MVP 不必先做全世界，先做 **几个能代表「我们在交流」的团体名字** 就够。

---

## 二、分层模型（从人到联盟）

```
        ┌─────────────────────────────────────┐
        │  联盟（如「雾桥公约」≈ 欧盟）         │
        │  多国签约、共同公告、盟主轮值         │
        └──────────────────┬──────────────────┘
                           │ 异步信箱 / 偶发会议
        ┌──────────────────┼──────────────────┐
        ▼                  ▼                  ▼
   ┌─────────┐       ┌─────────┐       ┌─────────┐
   │ 国家 A   │       │ 国家 B   │       │ 国家 C   │
   │ 势力/城邦│       │         │       │         │
   └────┬────┘       └────┬────┘       └────┬────┘
        │                  │                  │
   小团体、公会、        商会支部、          …
   店铺联盟、律师协会
        │
        ▼
   ┌─────────┐
   │  玩家个人 │  食客、厨师、律师…（`10`）
   └─────────┘
```

| 层级 | 现实类比 | 线上简化后做什么 |
|------|----------|------------------|
| **个人** | 公民 | 点菜、接单、投票、写信 |
| **小团体** | 公会、公司、俱乐部 | 共享信箱、内部悬赏、共担订单 |
| **国家/势力** | 国家 | 领土（地图区域）、馆规、对外使馆信箱 |
| **联盟** | 欧盟、联合国式松散联盟 | 多国公约、盟主公告、联合悬赏栏 |

**不追求严肃地缘政治仿真**；追求 **「有地方归属、有异步往来」** 的角色扮演与协作。

---

## 三、交互规则：默认异步，会议才同步

| 方式 | 何时用 | 工具 |
|------|--------|------|
| **默认** | 日常交涉、提案、投票、传话 | **组织信箱**（`04` 往来信箱扩展） |
| **公告** | 一国/联盟对外政策 | **公告栏**（`02` 悬赏/公告栏扩展） |
| **同步会议** | 团体**主动开启**会议时段 | 可选文字房间；**不开会就不强制在线** |
| **硬决策** | 签约、宣战、贸易协定（游戏内） | 系统订单/条约记录 + 服务器时间戳 |

> 使馆来信放在信箱里；只有打开「会议厅」才需要同时在线——与全球错时友好（`04`）。

## 四、各层能担任的职位（简短）

### 4.1 小团体（公会 / 商会支部 / 创作社）

| 职位 | 做什么 |
|------|--------|
| **首领 / 会长** | 建团、收人、发内部公告 |
| **秘书** | 管组织信箱、整理议案 |
| **司库** | 团体托管资金（系统子账户） |
| **招贤** | 发内部悬赏、招厨师/编剧 |

### 4.2 国家 / 势力（城邦级即可）

| 职位 | 做什么 |
|------|--------|
| **执政 / 港主** | 对外代言、设势力馆规补充条 |
| **大使** | 用**使馆信箱**对他国/联盟异步交涉 |
| **法官代表** | 派律师参加跨势力案（`09`） |
| **关税吏** | 设本势力店铺税率（系统参数，MVP 可简化） |
| **史官** | 发势力公告、记大事于地点痕迹 |

### 4.3 联盟

| 职位 | 做什么 |
|------|--------|
| **盟主**（可轮值） | 发联盟公告、召集会议 |
| **轮值主席** | 欧盟式：一季一人，信箱署名变 |
| **联盟秘书处** | 汇总各国提案、排投票 |
| **观察员** | 未入盟国家旁听证 |

## 五、国家之间能做什么（简化版）

| 互动 | 异步怎么做 | 同步（开会）可选 |
|------|------------|------------------|
| **外交信** | 使馆信箱 | 会议里公开读信 |
| **贸易协定** | 提案信 + 各国首领点「同意」 | 会议表决 |
| **联合悬赏** | 联盟栏发单，多国玩家可接 | — |
| **引渡/律师协作** | 跨势力案型送评审团（`09`） | — |
| **地点归属** | 地图区域挂势力旗（打卡主题变） | 谈判会议 |
| **制裁** | 系统禁某国店铺在本国栏展示 | 联盟公告 |

**不做**全面战争仿真 MVP；可做 **「关系条 + 信箱 + 公告」** 就够有味道。

## 六、MVP 建议：先做什么「交流代名词」

> 问题：先做哪些团体，能代表「我们在交流」，又不过载？

### 6.1 推荐：**三层只开两层**

| MVP 开 | MVP 不开 | 理由 |
|--------|----------|------|
| **① 小团体（公会）** | 全球多国 | 玩家立刻有归属感 |
| **② 2～3 个官方势力（伪国家）** | 玩家自建国家 | 有地图锚点、有外交信箱 |
| **组织信箱 + 势力公告栏** | 联盟 + 盟主 | 联盟是势力两两玩顺了再加 |
| **异步-only** | 同步会议 | 会议 v2 再加 |

### 6.2 MVP 具体名单（建议）

用 **世界观里已有的名字** 当「国家代名词」，玩家零学习成本：

| 代号 | 扮演什么 | 交流载体 | 玩家能做什么 |
|------|----------|----------|--------------|
| **潮灯港** | 贸易城邦 | `潮灯港公告栏` + `港务信箱` | 看公告、接港内悬赏、外商来信 |
| **拾遗院** | 档案/调查势力 | `院令栏` + `使馆信箱` | 接调查类公告单、跨势力写信 |
| **镜湖驿** | （可选第三势力）休闲/驿站 | `驿帖` | 预约、社交类组织信箱 |

再加 **一个玩家可建的小团体**：

| 代号 | 扮演什么 | 交流载体 |
|------|----------|----------|
| **公会 / 商队 / 创作社** | 5～20 人小团体 | `公会信箱`（仅成员）、内部悬赏 |

**「交流代名词」= 玩家说「去港务信箱看」「院令更新了」—— 像现实里说「看外交部官网」。**

### 6.3 为什么先不开「多国 + 联盟」

| 风险 | 说明 |
|------|------|
| 空转外交 | 国家太多，信箱没人写 |
| 职位虚设 | 盟主、大使全空着 |
| 与点菜核心抢带宽 | MVP 应先证「点菜 + 订单 + 地图」 |

**联盟（雾桥公约）** 建议 **v2**：当潮灯港与拾遗院之间已有跨势力订单与案件后再开。

### 6.4 MVP 最小功能清单

1. **玩家创建公会**（名称、徽章、≤N 人）  
2. **公会信箱**：成员异步发信、秘书可置顶  
3. **2 个官方势力**：各有一个 **对外公告栏** + **使馆信箱**（玩家个人可投信，势力 NPC/执政玩家回）  
4. **地图 3～5 个地点** 挂势力旗（打卡页显示「此地属潮灯港」）  
5. **跨势力往来信** 走 `04` 模板，信头显示「发自拾遗院使馆」  
6. **（不做）** 联盟、盟主、同步会议、战争  

### 6.5 v2 再加

| 功能 | 说明 |
|------|------|
| **雾桥公约**（联盟） | 潮灯港 + 拾遗院签约；盟主轮值一季 |
| **联盟公告栏** | 联合悬赏、共同馆规补充 |
| **同步会议厅** | 预约 1h 文字房；不开则仍信箱 |
| **玩家申请建「准国家」** | 需成就门槛 + 简单考（像律师） |
| **国家间条约** | 系统记录的同意按钮 + 时间戳 |

## 九、小结

| 问题 | MVP 建议 |
|------|----------|
| 线下搬到线上？ | **简化**：信箱 + 公告 + 地图归属，不仿真全套联合国 |
| 异步？ | **默认信箱**；会议 v2 可选同步 |
| 先做什么团体？ | **玩家公会** + **潮灯港 / 拾遗院** 两势力当「国家代名词」 |
| 联盟盟主？ | **v2** 再上「雾桥公约」 |
| 交流代名词？ | **港务信箱、院令栏、公会信箱** —— 玩家一听就知道去哪看消息 |

> 先有两国使馆和一家公会，信就能往来；  
> 等同盟够多了，再签一张「雾桥公约」——不必第一天就造欧盟。
