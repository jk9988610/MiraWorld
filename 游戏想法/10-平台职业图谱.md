# 平台职业图谱：现实、虚拟与幻想并存

> 状态：职业一览（简短举例）  
> 记录时间：2026-09-12  
> 来源：与作者的讨论  
> 说明：同一玩家可兼多职；**硬边界由系统资质控制**，皮肤可用科幻/玄幻包装。

---

## 一、一句话

MiraWorld 里不只有「战士法师」——职业来自 **馆子里的分工**：有人点菜，有人做菜，有人跑腿，有人写方案，有人当律师。  
下面按类别列举 **平台上实际能做什么**（一句话 + 小例子）。

---

## 二、核心消费与探索（人人可做）

| 职业（称呼） | 平台上做什么 | 举例 |
|--------------|--------------|------|
| **食客** | 点「我要」单，定义自己想吃什么口味 | 「我要一份灰烬港调查，重辣少盐」 |
| **旅人** | 逛地图、自动打卡、看前人痕迹 | 旧栈桥留过粉笔字，下次路过能看见 |
| **读者** | 买数字内容、进库游玩、写评价 | 购买「调查委托包 ×5」，玩完评星 |
| **订阅者** | 关注创作者/店铺，收异步更新 | 订阅某 Studio，信箱收新作通知 |

## 三、履约与劳动（现实感强）

| 职业 | 平台上做什么 | 举例 |
|------|--------------|------|
| **厨师** | 接别人点的单，按忌口完成交付 | 接一单「清淡叙事护送」，信箱交付摘要 |
| **服务员** | 接服务单，远程或「上门」地点履约 | 帮调查某 NPC 线索，提交系统验收条目 |
| **行者 / 信使** | 抢跑腿单，取送物品数据 | 把灯油从潮灯港送到镜湖驿 |
| **骑手** | 商品单子环节：商家出餐后的配送 | 取已打包 SKU 权益送到买家指定地点 |
| **保镖** | 护送类订单的高风险分支 | 接「重辣」护送，失败扣信誉 |
| **导游** | 带人「走地图」的软服务（不代打硬进度） | 发信告诉新手哪几条链接已打卡 |

## 四、生产与买卖（产销链）

| 职业 | 平台上做什么 | 举例 |
|------|--------------|------|
| **原料商** | 采集/持有原材料，拆分库存上架 | 把「雾晶」拆成 10 份挂二手 |
| **作坊主 / 商家** | 买料→生产→打包→店铺售卖 | 用 5 份食材做出「暖胃汤」SKU |
| **店主** | 运营店铺页、定价、库存 | 挂「镜湖.skin」主题包 |
| **方案师 B₁** | 用模板/SDK 编排 Blueprint | 做「单地点调查」蓝图授权给发行方 |
| **产品师 B₂** | 包装 SKU、上架商城 | 把蓝图包成「夜雾调查 ×5」卖 80 灯油 |
| **代销商 B₃** | （可选）帮别人挂链接赚佣金 | 在自己的栏位代售他人 SKU |
| **工匠** | 接定制代工单，按图纸消耗材料 | 「按图纸做 3 件护符」 |
| **情报贩子** | 卖系统预定义情报条目（非自由剧透文） | 卖「灰烬港隐藏事件 #7」解锁 |

## 五、创作与内容（线上数字）

| 职业 | 平台上做什么 | 举例 |
|------|--------------|------|
| **编剧** | 写对话树、叙事节点，绑进 Blueprint | 接 Studio 服务单，交付 3 万字支线 |
| **Blueprint 编排师** | 节点图/表单向导拼流程 | 调查链：Visit→Dialogue→Reward |
| **沙盒试玩员** | 帮方案方跑沙盒、找死胡同 | 测 Blueprint v0.9，标红灯节点 |
| **美术/氛围师** | 供 SKU 封面、店铺皮肤方案 | 卖「潮灯港夜景」主题授权 |
| **Studio 主持** | 组团队、发外包、上架整包 Game | 像小发行商运营一款可售内容 |
| **校对人** | 检查 SKU 描述与蓝图是否一致 | 防「口味欺诈」被举报 |

## 六、规则、裁断与信任（馆规线）

| 职业 | 平台上做什么 | 举例 |
|------|--------------|------|
| **注册律师** | 过馆规考，异步评审团投票 | 支持举报方或商家，阅卷结案 |
| **见习律师** | （可选）只读卷宗不投票 | 学习判例 |
| **审计员** | 专精分账/ledger 异议案 | 查 royalty 是否漏分 |
| **馆吏** | （平台/NPC）发公告、馆规更新 | 系统邮箱发版本说明 |
| **仲裁记录员** | 整理卷宗、脱敏公开判例 | 供新人律师学习 |

## 八、幻想 / 科幻皮肤（机制不变，称呼换皮）

> 下列 **平台动作与第三节～第六节相同**，只是世界观包装。

| 幻想称呼 | 对应平台职能 | 举例 |
|----------|--------------|------|
| **潮灯引路人** | 行者 + 导游 | 引旅人穿过「雾桥」打卡点 |
| **拾遗者** | 调查类厨师 / 情报贩子 | 从废墟地点捞「记忆碎片」条目 |
| **计史官** | 说书人 + 留痕 | 在地点刻下「此地曾发生…」 |
| **镜湖驿茶博士** | 商家 + 预约单 | 卖「茶位时段」+ 短篇叙事包 |
| **护符匠人** | 工匠 + 作坊主 | 代工「按图纸铸护符」 |
| **信鸦使** | 行者 | 异步「飞递」物品数据 |
| **档案厅缮写士** | 编剧 + 方案师 | 在 Blueprint 里缮写对话卷 |
| **雾桥守望** | 地图相关服务 | 维护地点邻接、举报滥留痕 |
| **商会清道夫** | 高风险服务单 | 接「重辣」清理类委托 |
| **星港报关员** | （科幻皮）审计 + 验收 | 验货类订单的硬验收节点 |
| **量子信标师** | （科幻皮）Blueprint 编排 | 编排「跨地点链式调查」模板 |
| **灵脉测绘者** | 旅人 + 情报 | 卖「某地打卡路线」情报条目 |
| **判例司判官** | 注册律师 | 评审团投票，称「判例」不称「开庭」 |

## 九、势力 / NPC 与玩家职业交织

| 存在 | 平台上角色 | 举例 |
|------|------------|------|
| **潮灯商会** | NPC 厨房 + 玩家可挂牌加盟 | 卖招牌「商会套餐」SKU |
| **拾遗院** | 官方任务栏 + 可雇玩家服务员 | 院发公告单，玩家自愿接 |
| **势力招牌菜** | 玩家仍须先点菜（`02`） | 点「拾遗院风味调查」，厨师可能是玩家 |

势力提供 **风味与场地**，不剥夺玩家职业空间。

## 十、职业从哪来？（不是设计师表）

```
现实结构（外卖、店铺、版权、律师）
    + 异步世界（信箱、痕迹、错时）
    + 潮灯/科幻/玄幻皮肤
    ────────────────────────
    = 上表这些「能干活的名字」
```

| 原则 | 说明 |
|------|------|
| **先有用，再有皮** | 每个职业对应真实订单类型或馆规职能 |
| **可兼职** | 中午食客、晚上厨师、周末律师 |
| **要资质才碰权** | 律师、商家、服务员等简单考或执照 |
| **幻想不增特权** | 「计史官」不能绕过系统改背包 |

| 职业 | 可能做什么 |

---

## 十三、小结

平台上能「诞生」的职业，本质是 **订单类型 × 馆规角色 × 世界观皮肤**。  
现实职业让玩家秒懂；幻想称呼让同一套按钮有潮灯/科幻/玄幻的味道。

> 同一双手可以点菜、做菜、送信、写蓝图、阅卷。  
> 职业不是等级表上的格子，是你今天选择怎么参与这座馆子。
