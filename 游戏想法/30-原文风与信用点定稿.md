## 二、世界观与故事（原文风，简短）

### 2.1 一句话

> **MiraWorld** 是有雾的港口世界：潮灯商会以灯火契约统度量，馆里交易记 **信用点**；  
> 你走过会留下足迹，下单走馆规托管，回信进系统信箱 —— 不必谁都在线。

### 2.2 信用点 / Credits 怎么说

**三层名字，一回事：**

| 层 | 叫什么 | 用在哪 |
|----|--------|--------|
| **叙事（中文）** | 信用点 / **点** | 菜单、信箱、契约文书 |
| **技术（英文）** | **credits** | 库字段、API、配置、日志 |
| **玩家体感** | 像各平台的 **贡献点 / 信用额度** | 完成馆务入账、花钱托管 —— **不能提现** |

和 GitHub、Steam 那种「credits」一样：**账上数字，不是现实货币**。  
区别只在 **皮肤**：我们讲潮灯馆驿，不讲现代接缝市。

- 全称：**信用点**（帮助页）  
- 日常：**点**（菜单、余额）  
- 代码：**`wallet_credits`**（整数）  
- 与 **灯火、灯油** 的关系：同属潮灯商会 **度量体系**；**灯油是实物/气味**，**credits 是账** —— 不混用  

**叙事例：** 「付十五点，托管在柜上。」 / 林溯指尖仍有灯油味，但账上扣的是 **15 credits**。

### 2.3 首发故事框

你是新来的 **行者**。馆里送你 **300 点** 见面礼。  
从潮灯港能走到旧栈桥、镜湖驿；在 **潮灯驿站食堂** 花 **15 点** 点一碗雾港汤面，钱先押在柜上，出餐进背包，信里会告诉你。  
**没有主线** —— 逛、吃、收信，随你。

## 三、货币规则（技术）

| 项 | 说明 |
|----|------|
| 玩家看见（中文 UI） | **128 点**（或文书写「128 信用点」） |
| 玩家看见（英文 UI） | **128 credits** |
| 服务器字段 | **`wallet_credits`（整数）** |
| 配置键 | `newbie_credits: 300`，SKU 用 `price_credits` |
| 格式化 | `format_credits(n)` → 中文 `"88 点"` / 英文 `"88 credits"` |
| 汇率 | **无** — 只有一种单位，不拆金/银 |
| 兑换按钮 | **无** |
| 现实货币 | **不能提现、不能兑人民币**（首发不接充值） |

### 帮助页

> **信用点（点）** 是馆里统一的记账单位，付餐费、工钱都用它。  
> 与背包里的物品、罐装灯油 **不是同一种**。不能换现实货币。
