## 二、世界观（简述，详见 `31`）

> **MiraWorld** 按 **省市区街道** 组织；城市代称 **A市、B市、C市**。平台统一记 **信用点**；  
> 你走过各区会留下足迹，下单走托管，通知进系统信箱 —— 不必谁都在线。

### 2.1 信用点 / Credits 怎么说

**三层名字，一回事：**

| 层 | 叫什么 | 用在哪 |
|----|--------|--------|
| **叙事（中文）** | 信用点 / **点** | 菜单、通知、帮助页 |
| **技术（英文）** | **credits** | 库字段、API、配置、日志 |
| **玩家体感** | 像各平台的 **贡献点 / 信用额度** | 入账、托管消费 —— **不能提现** |

和 GitHub、Steam 那种「credits」一样：**账上数字，不是现实货币**。

- 全称：**信用点**（帮助页）  
- 日常：**点**（菜单、余额）  
- 代码：**`wallet_credits`**（整数）  

**叙事例：** 「标准汤面 **15 点**，已托管。」 / 陈师傅出餐，账上扣 **15 credits**。

### 2.2 首发故事框

你是新 **成员**。平台送你 **300 点**。  
在 **A市 · 枢纽区** 出生，可逛 A市 内各区；在 **A市枢纽区 · 食堂** 花 **15 点** 点标准汤面，托管后出餐进背包。  
**没有主线** —— 逛区、吃饭、收通知，随你。

## 三、货币规则（技术）

| 项 | 说明 |
|----|------|
| 玩家看见（中文 UI） | **128 点**（或文书写「128 信用点」） |
| 玩家看见（英文 UI） | **128 credits** |
| 服务器字段 | **`wallet_credits`（整数）** |
| 配置键 | `newbie_credits: 300`，SKU 用 `price_credits` |
| 格式化 | `format_credits(n)` → 中文 `"88 点"` / 英文 `"88 credits"` |
| 汇率 | **无** — 只有一种单位，不拆金/银 |
| 兑换按钮 | **无** |
| 现实货币 | **不能提现、不能兑人民币**（首发不接充值） |

### 帮助页

> **信用点（点）** 是平台统一的记账单位，付餐费、工钱都用它。  
> 与背包里的物品 **不是同一种**。不能换现实货币。
