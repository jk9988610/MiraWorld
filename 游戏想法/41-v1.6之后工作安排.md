## 三、v1.6 交割（建议下一版）

**目标：** 购售委托确认交差后，物与点真的对齐——仍无配送链。

### P0 — 定稿

| 任务 | 产出 |
|------|------|
| 购买委托成交 | 接单人交 stack → 发单人确认 → 物进发单人背包、点给接单人 |
| 出售委托成交 | 发单人交 stack → 接单人确认收货逻辑（或合并为一步交差） |
| 失败/纠纷 | v1.6 **不做** dispute；交差仍靠双方确认 |

### P1 — API

| API | 说明 |
|-----|------|
| `POST /bounties/{id}/submit` | 校验接单人 stack（出售单）或记录交付声明（购买单） |
| `POST /bounties/{id}/settle` | 转移 stack + 放款（原子） |
| `ledger` | 增加 `bounty_settle` 与 stack 变更日志 |

### P2 — 前端

- 悬赏栏展示物品图标/标签  
- 交差前提示「背包是否够件数」  
- 通知跳转带委托详情（可选 query `?id=`）

### P3 — 验收

- `smoke:bounty` 扩展：成交后 stack 数量正确  
- 帮助页写清 buy/sell 交割方向
