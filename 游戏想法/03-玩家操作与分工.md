## 一、玩家能做什么

| 操作 | 说明 |
|------|------|
| **开店** | 选类型、起名、**handle**（100 点登记费） |
| **上架/下架** | 商品与 **购/售委托**（open 合计 **≤10** 单） |
| **改价** | 本店商品 |
| **接单/拒单** | 订单 |
| **当班** | 离线自动接单并标记好了 |
| **委托** | **购买** / **出售**（`kind` + `item_id` + `qty`） |
| **通知** | 订单与委托 **一律通知**（含 NPC 店） |
| **日投** | 外生注资（规划 v2.1） |

**不做：** 招贤、应聘、雇玩家、律师、作家、trace、中介、委托做某事、当面交差。

### 玩家用语

| 概念 | 用语 |
|------|------|
| 经营者 | **handle**（玩家/NPC 同规则） |
| 市民 | **Lite Pop** 组内匿名统计；Spotlight **姓+职业** |
| 无岗 | **最低生活补贴**（温饱） |
| 在岗 | **最低工资标准** |
| 委托 | **购买委托** / **出售委托** |

### UI 动词（全站统一）

挂单 · 确认收进背包 · 放入背包 · 食用 · 使用 · 发委托 · 接委托 · 交差 · 确认交差 · 取消

底栏：**地图 · 通知 · 背包 · 我的**

## 二、分工图谱（没有社会职业树）

| 角色 | 是什么 |
|------|--------|
| **玩家** | 经营者（handle） |
| **机构** | 生产与雇佣（面坊、医馆、玩家店…） |
| **市民组** | 消费（1000 人/组） |
| **机构 slot** | 机器岗位（厨师、医生… **NPC**） |

### 玩家做什么

| 做什么 | 系统 |
|--------|------|
| 开店 / 挂 offer / 当班 | `shop` · `order` |
| 购售委托 | `bounty` |
| 扩产、定价、雇 **NPC 岗** | v2 `institution` |
| 逛地图 | `visit`（不贴「旅客」标签） |

**外生：** 日投资金（v2.1）。**内生利润：** 闭环买卖。

### 机构与机器岗位

| 岗位示例 | 所属机构 | 谁拿钱 |
|----------|----------|--------|
| 厨师、服务员 | 面坊 | 市民组工资（≥ 最低工资） |
| 医生、账房 | 医馆 | 同上 |
| 铁匠 | 铁匠铺 | 同上 |

岗位 **必须** 挂在机构 `slot` 上；Spotlight 职业名 **来自 slot**。玩家店 slot 是 **NPC 厨师/服务员**，不是雇玩家。

### 市民组

| 状态 | 收入 | 消费 |
|------|------|------|
| 在岗 | 机构工资 | 用 `wallet` 买 offer |
| 无岗 | **最低生活补贴**（城市福利） | 仅温饱级 |

首发：10 组 × 1000 人，潮灯市。

## 三、开店（v1.2 已实现 · v2 对齐机构）

**玩家开店 = 多一家机构。** 挂 offer、开当班、雇 **NPC 岗位**，不是招玩家。

| 功能 | API |
|------|-----|
| 登记开店 | `POST /shop/apply`（100 点） |
| 挂单 | `POST /shop/offers` |
| 当班 auto | `PATCH /shop/auto` |
| 接单履约 | `order` + `accept` / `ready` |

v2：`shops` → `institution`（`owner=player`）；市民 **不会** 来应聘。

## 四、已取消（旧文档勿引用）

| 旧称呼 | 原因 |
|--------|------|
| 律师 / 审计 / 馆吏 | 无判决玩法 |
| 说书人 / 作家 / 编剧 | 无叙事产出 |
| 招贤 / 招募者 / 应聘 | 不雇玩家 |
| 骑手 / 信使 / 中介 | 无配送、无撮合 |
| 食客 / 旅客（玩家标签） | 玩家仅 handle |
