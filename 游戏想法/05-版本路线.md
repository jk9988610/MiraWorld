## 二、各版本摘要

### v1.0 — 第一市 ✅

探索 · 点菜 · 通知。潮灯市 + 陈师傅 15 点面。无开店、无配送。

### v1.1 — 烟火 ✅

spot 首次到访文案；order 里程碑文案；NPC 场景对白；空状态暖文案。

### v1.2 — 开灶 ✅

玩家 **seller** 挂 offer；100 点登记开店；`shop` + `player_offers`。

### ~~v1.3 — 脚程~~ ❌ 已取消

不做骑手、配送子单、运费。商品 **下单 → 通知 → 背包**。

### v1.4 — 当班 ✅

`auto_on` 离线自动接单并标记好了；买家仍走通知。

### v1.5 / v1.5.1 — 购售委托 ✅

| 项 | 状态 |
|----|------|
| 委托 **购买/出售**（`kind` + `item_id` + `qty`） | ✅ |
| open 委托 **≤10** | ✅ |
| 删除 `in_person`；订单/委托 **一律通知** | ✅ |
| 删除「委托做某事」 | ✅ |
| smoke `--v15` | ✅ |

### v1.6 — 交割（可选）

购售委托确认后 stack 转移。与 v2.0 **无冲突**，可后做。

### v2.0 — 内生经济 ✅

| 象 | 内容 |
|----|------|
| 人 | **机构** + **市民组**；玩家仍为 handle |
| 事 | 日 tick：生产 · 工资 · **最低生活补贴** · 消费 |
| UI | Spotlight 每店 10 条 |

**目标：** 无玩家在线，潮灯市仍 **生产 ↔ 消费** 自闭环。

#### P0 — 定稿 ✅

见 [04-乌托邦经济](./04-乌托邦经济.md)

#### P1 — 数据与 tick ✅

| 任务 | 产出 |
|------|------|
| `institutions` + `slots` | NPC 机构 + 玩家店映射 |
| `pop_groups` | 10 组 × 1000 |
| `city_welfare_fund` | 补贴 + 乌托邦 grant |
| 日 tick | payroll → welfare → purchase → ledger |
| `order.buyer_kind=pop_group` | 市民买单 |

#### P2 — 表现 ✅

| 任务 | 产出 |
|------|------|
| `GET /shop/{id}/spotlight` | 每店 10 条 |
| 经营仪表盘 | 工资、补贴、流失（数字） |

#### P3 — 验收 ✅

- 无岗组仅补贴温饱；在岗组工资 ≥ 最低工资  
- 无机构则无假职业 Spotlight  
- cron 一日，机构与市民账平衡可审计  
- 验收：`npm run smoke:economy` · `GET /economy/audit` · `npm run economy:cron`

### v2.1 — 资本家 ✅

### v2.4 — 门控 · 时间表 · 速度 ← **建议主下一步**

定稿：[07-单多人与主次视角](./07-单多人与主次视角（讨论）.md)

| 象 | 内容 |
|----|------|
| **门控** | **六选一**：新/继续/加载 × 单人/多人 **模式**；无档锁继续+加载；加载 **选档** |
| **存档** | **铁人**：单人新建可选、多人默认；游戏内不手动存，**退出自动存** |
| **速度** | 单人可调+暂停；多人固定中速；快档 **仍允许逐单手动** |
| **focus** | 默认 **时间表** 切换 company/personal；**不做教程解锁** |
| **auto_on** | **下班自动关**；上班不自动重开 |

**原则：** 只改 **实例 / 时钟 / UI 权重**，不改 [06](./06-两层经济（L0 Hub + 成品市场）.md) 经济公式。

#### P0 — 定稿 ✅

见 [07](./07-单多人与主次视角（讨论）.md) §八拍板

#### P1 — 多人 UX（可先上线，不依赖单人实例）

| # | 任务 | API / 数据 | UI |
|---|------|------------|-----|
| 1 | **进门六选一** | `GET /world/gate` → `can_continue_*`, `can_load_*`, `solo_saves[]`, `multi_saves[]`, `last_*_save_id`；`POST /world/new` `{scope, ironman?}`；`POST /world/continue`；`POST /world/load` `{scope, save_id}` | `/play/gate.html`：单人/多人两组各 **新/继续/加载**；无档时 **继续+加载灰显** |
| 2 | **加载选档** | 存档列表含 `save_id`, `display_name`, `world_day`, `last_played_at`, `ironman` | 点「加载」→ 列表 modal → 选一档进入 |
| 3 | **铁人模式** | `world_saves.ironman`；铁人禁 `POST /world/save`；`POST /world/autosave` 于登出/会话结束；**多人新建 force ironman** | 新建单人：勾选铁人；列表 **铁人角标**；设置页无「保存」按钮（铁人时） |
| 4 | **life_schedule** | `player_schedules` + `GET/PATCH /me/schedule` | 上班/下班/节假日编辑 |
| 5 | **focus** | `GET /me/focus` + override | 顶栏上班/下班；底栏随 focus |
| 6 | **下班关 auto_on** | 非 work_window → `auto_on=false` | 我的店提示 |
| 7 | **世界钟（多人）** | `GET /world/clock` | 顶栏第 N 日 · 距 tick |
| 8 | **快档通知** | message + `notify_sound` 偏好 | 设置音效开关 |

**P1 验收：**

- 新号：继续+加载（单/多）均灰显；「新的多人模式」可进  
- 有档后：继续进上次活跃档；加载可换档  
- 单人新建勾选铁人：游戏内无保存，退出后重进进度在  
- 多人档均为铁人  
- schedule / auto_off / gate smoke `--v24-gate`

#### P2 — 单人实例 + 调速

| # | 任务 | API / 数据 | UI |
|---|------|------------|-----|
| 1 | **存档槽** | `world_saves`：`scope`, `ironman`, `display_name`, `world_id`, `clock_json`, `last_played_at`；单人 **10 组 pop** 绑 `world_id` | 加载列表；新建单人 **铁人勾选** |
| 2 | **独立 tick** | 单人实例 scheduler；与多人 cron **隔离** | — |
| 3 | **速度档** | `PATCH /world/speed` → `pause\|slow\|mid\|fast\|fastest`；pause 冻结 tick + auto | 顶栏：暂停/慢/中/快；**暂停内可逐单接单** |
| 4 | **force tick** | 保留运维 secret；单人 UI 可选「推进一日」（极快档） | 生产页调试入口（仅 SP） |

**P2 验收：**

- 新单人档：完整 10 组市民闭环可 smoke  
- 暂停时 tick 与 auto 冻结；恢复后续跑  
- 单人档 **不写入** 多人 shared DB
