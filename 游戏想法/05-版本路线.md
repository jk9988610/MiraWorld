## 二、各版本摘要

### v1.0 — 第一市 ✅

探索 · 点菜 · 通知。潮灯市 + 陈师傅 15 点面。无开店、无配送。

### v1.1 — 烟火 ✅

spot 首次到访文案；order 里程碑文案；NPC 场景对白；空状态暖文案。

### v1.2 — 开灶 ✅

玩家 **seller** 挂 offer；100 点登记开店；`shop` + `player_offers`。

### ~~v1.3 — 脚程~~ ❌ 已取消

不做骑手、配送子单、运费。商品 **下单 → 通知 → 背包**。

### v1.4 — 当班 ✅

`auto_on` 离线自动接单并标记好了；买家仍走通知。

### v1.5 / v1.5.1 — 购售委托 ✅

| 项 | 状态 |
|----|------|
| 委托 **购买/出售**（`kind` + `item_id` + `qty`） | ✅ |
| open 委托 **≤10** | ✅ |
| 删除 `in_person`；订单/委托 **一律通知** | ✅ |
| 删除「委托做某事」 | ✅ |
| smoke `--v15` | ✅ |

### v1.6 — 交割（可选）

购售委托确认后 stack 转移。与 v2.0 **无冲突**，可后做。

### v2.0 — 内生经济 ✅

| 象 | 内容 |
|----|------|
| 人 | **机构** + **市民组**；玩家仍为 handle |
| 事 | 日 tick：生产 · 工资 · **最低生活补贴** · 消费 |
| UI | Spotlight 每店 10 条 |

**目标：** 无玩家在线，潮灯市仍 **生产 ↔ 消费** 自闭环。

#### P0 — 定稿 ✅

见 [04-乌托邦经济](./04-乌托邦经济.md)

#### P1 — 数据与 tick ✅

| 任务 | 产出 |
|------|------|
| `institutions` + `slots` | NPC 机构 + 玩家店映射 |
| `pop_groups` | 10 组 × 1000 |
| `city_welfare_fund` | 补贴 + 乌托邦 grant |
| 日 tick | payroll → welfare → purchase → ledger |
| `order.buyer_kind=pop_group` | 市民买单 |

#### P2 — 表现 ✅

| 任务 | 产出 |
|------|------|
| `GET /shop/{id}/spotlight` | 每店 10 条 |
| 经营仪表盘 | 工资、补贴、流失（数字） |

#### P3 — 验收 ✅

- 无岗组仅补贴温饱；在岗组工资 ≥ 最低工资  
- 无机构则无假职业 Spotlight  
- cron 一日，机构与市民账平衡可审计  
- 验收：`npm run smoke:economy` · `GET /economy/audit` · `npm run economy:cron`

### v2.1 — 资本家 ✅

### v2.4 — 门控 · 时间表 · 速度 ← **建议主下一步**

定稿：[07-单多人与主次视角](./07-单多人与主次视角（讨论）.md)

| 象 | 内容 |
|----|------|
| **门控** | 新/继续 × 单人/多人；未开店继续多人 **经营 UI 锁定** |
| **速度** | 单人可调+暂停；多人固定中速；快档 **仍允许逐单手动** |
| **focus** | 默认 **时间表** 切换 company/personal；**不做教程解锁** |
| **auto_on** | **下班自动关**；上班不自动重开 |

**原则：** 只改 **实例 / 时钟 / UI 权重**，不改 [06](./06-两层经济（L0 Hub + 成品市场）.md) 经济公式。

#### P0 — 定稿 ✅

见 [07](./07-单多人与主次视角（讨论）.md) §八拍板

#### P1 — 多人 UX（可先上线，不依赖单人实例）

| # | 任务 | API / 数据 | UI |
|---|------|------------|-----|
| 1 | **进门四选一** | `GET /world/gate` 返回可选档、当前档；`POST /world/select` body `{mode: new\|continue, scope: solo\|multi}`；多人 `continue` 默认潮灯市 | 登录后 `/play/gate.html`：四按钮；单人 `new` 可先 **敬请期待** 占位 |
| 2 | **未开店 UI 锁定** | `GET /me` 或 gate 增 `shop_required: bool`、`ui_locks: string[]` | 无店时 **灰显/拦截** 资本家、生产、当班设置；保留地图·背包·开店引导 |
| 3 | **life_schedule** | 表 `player_schedules`：`timezone`, `work_windows_json`, `holidays_json`；`GET/PATCH /me/schedule` | 设置页或资本家页：**上班/下班/节假日** 编辑；默认周一至五 09–18 |
| 4 | **focus 计算** | `GET /me/focus` → `{focus, source: schedule\|override, until?}`；`POST /me/focus/override` 临时切换 | 顶栏 **上班/下班** 指示；底栏默认页随 focus 变（见 07 §4.4） |
| 5 | **下班关 auto_on** | tick 前或 `PATCH /shop/auto` 校验：非 work_window → 强制 `auto_on=false` 并写通知摘要 | 我的店页提示「已下班，自动当班已关闭」 |
| 6 | **世界钟（多人）** | `GET /world/clock` → `{world_day, next_tick_at, speed_label: "中"}` | 顶栏只读：**第 N 日 · 距 tick** |
| 7 | **快档通知** | 订单创建仍走现有 `message`；可选 `notify_sound` 用户偏好 | 设置：新订单 **音效开关**（对齐 Vic3 提醒，不 auto-pause tick） |

**P1 验收：**

- 未开店账号选继续多人：能进城、**不能**进生产/资本家后台  
- 改 schedule 后 focus 与底栏默认页切换  
- 模拟下班时刻：`auto_on` 变 false  
- smoke 扩展或 `--v24-gate` 脚本覆盖 gate + schedule + auto_off  

#### P2 — 单人实例 + 调速

| # | 任务 | API / 数据 | UI |
|---|------|------------|-----|
| 1 | **存档槽** | `world_saves`：`player_id`, `slot`, `world_id`, `clock_json`；单人 **10 组 pop** 绑 `world_id` | 门控「新的/继续单人」选槽 |
| 2 | **独立 tick** | 单人实例 scheduler；与多人 cron **隔离** | — |
| 3 | **速度档** | `PATCH /world/speed` → `pause\|slow\|mid\|fast\|fastest`；pause 冻结 tick + auto | 顶栏：暂停/慢/中/快；**暂停内可逐单接单** |
| 4 | **force tick** | 保留运维 secret；单人 UI 可选「推进一日」（极快档） | 生产页调试入口（仅 SP） |

**P2 验收：**

- 新单人档：完整 10 组市民闭环可 smoke  
- 暂停时 tick 与 auto 冻结；恢复后续跑  
- 单人档 **不写入** 多人 shared DB
