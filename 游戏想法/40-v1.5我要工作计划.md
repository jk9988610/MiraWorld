## 二、v1.5 目标一句话

**玩家能主动发「我要」委托（托管点），别人浏览悬赏栏自愿接单、交差结算——仍无主线、无配送。**

不是系统派任务；是 **Player-Initiated Bounty**（见 `02`）。

---

## 三、与现有系统的关系

| 已有 | v1.5 扩展 |
|------|-----------|
| `order` + 陈师傅/玩家店 | **不变**；点面仍是主入口 |
| `message` 通知 / 往来 | 委托里程碑可走通知（异步单） |
| `in_person` | 当面交差不发通知（与 v1.4 一致） |
| `ledger` | 发单托管、交差放款 |

**不做：** `01` 里的子任务拆分、骑手派单、系统托底（`17`）、Blueprint。

---

## 四、最小闭环（MVP 切片）

```
发单人 A：我要「找一份晚霞岸线索」· 托管 50 点
    → 悬赏栏可见
接单人 B：接单 → 做（站外/文字描述即可）→ 交差
发单人 A：确认交差 → B 收 50 点
```

**通过标准：** 两人无口头协助走通；余额与 `ledger` 一致。

## 五、工作包（建议顺序）

### P0 — 定稿与用语

| 任务 | 产出 |
|------|------|
| 玩家动词 | **发委托** / **接委托** / **交差** / **确认交差**（写入 `36`） |
| 与 order 区分 | 帮助页：点面 = `order`；我要 = `bounty` |
| 通知规则 | 当面交差不发通知；异步接/交差可通知 |
| 本文 + `help` 预留一节 | 不在 P0 写完整 UI |

### P1 — 数据与 API

**表 `bounties`（建议）：**

```sql
bounties (
  id TEXT PRIMARY KEY,
  issuer_id INTEGER NOT NULL,
  city TEXT NOT NULL DEFAULT '潮灯市',
  title TEXT NOT NULL,
  body TEXT NOT NULL DEFAULT '',
  price_credits INTEGER NOT NULL,
  status TEXT NOT NULL,  -- open | taken | submitted | settled | cancelled
  worker_id INTEGER,
  created_at TEXT, updated_at TEXT
)
```

| API | 说明 |
|-----|------|
| `POST /bounties` | 发委托（扣托管） |
| `GET /bounties` | 悬赏栏列表（`status=open` + 我接的/我发的） |
| `POST /bounties/{id}/take` | 接单 |
| `POST /bounties/{id}/submit` | 接单人交差 |
| `POST /bounties/{id}/settle` | 发单人确认 → 放款 |
| `POST /bounties/{id}/cancel` | 发单人取消 open 单 → 退托管 |

**状态机：**

```
open → taken → submitted → settled
  └ cancel (仅 open)
```

### P2 — 前端

| 页面 | 路径 | 说明 |
|------|------|------|
| 悬赏栏 | `/play/bounties` | 浏览 open 委托 + 入口发单 |
| 我的委托 | `/play/my-bounties` 或合并在悬赏栏 Tab | 我发的 / 我接的 |
| 壳层 | **暂不增第 5 底栏** | 先从「我的」链入；P2 末再议是否加「我要」 |

### P3 — 通知与往来

| 场景 | 是否通知 |
|------|----------|
| 有人接了我的单 | 发单人 ✅ |
| 接单人交差 | 发单人 ✅ |
| 确认交差放款 | 接单人 ✅ |
| 当面交差（`in_person`） | ❌ |

复用 `messages` + `from_kind=player|system`；`ref_type=bounty`。

### P4 — 验收

| 项 | 产出 |
|----|------|
| `deploy/smoke_demo.py --v15` | 发单 → 接单 → 交差 → 结算 |
| `npm run smoke:bounty` | package.json 脚本 |
| 帮助页 + `36` 勾选 | v1.5 完成标记 |

---

## 六、验收标准（v1.5）

1. 发单人托管扣点正确，取消 open 单可退  
2. 同一委托只能一人 `take`  
3. 交差 → 确认后接单人加点、`ledger` 有记录  
4. 悬赏栏 **只读浏览 + 发单**；无系统派单入口  
5. 帮助页写清：**点面走陈师傅/玩家店，委托走我要**  

---

## 七、不做清单（v1.5 纪律）

- ❌ 子任务拆分、悬赏树（`01` 完整版）  
- ❌ 骑手 / 配送 / 送到家  
- ❌ 系统托底 / 馆驿卒（`17`）  
- ❌ 口味谱周报（可 v1.5.1 或 v2）  
- ❌ 底栏强塞第 5 项（除非 P2 末评估后确认）  
- ❌ 把 bounty 做成 second order 页复制粘贴（独立 record 类型）
