# 开店与机构编制

> 状态：**v1.2 玩家店 + v2 机构模型衔接**  
> 记录时间：2026-09-13  
> 上位：[44-机构编制与工资定稿](./44-机构编制与工资定稿.md) · [42-乌托邦经济与内生闭环定稿](./42-乌托邦经济与内生闭环定稿.md)

---

## 一、一句话

**玩家开店 = 多一家机构。** 挂 offer、开当班、雇 **NPC 岗位**（厨师、服务员），不是招玩家，也没有招贤栏。

---

## 二、已实现（v1.2 / v1.4）

| 功能 | 路径 / API |
|------|------------|
| 登记开店 | **我的店** · 100 点 · `POST /shop/apply` |
| 挂单 | `POST /shop/offers` |
| 当班 auto | `PATCH /shop/auto` |
| 接单履约 | `order` + `accept` / `ready` |

---

## 三、与机构模型对齐（v2 规划）

| v1 实现 | v2 机构字段 |
|---------|-------------|
| `shops` | `institution`（`owner=player`） |
| `player_offers` | 机构 `offer` |
| `auto_on` | 机构产能 / NPC slot 执行 |
| — | 机构 `wallet`、工资、维护（NPC 岗） |

市民 **不会** 来应聘；编制仅 **NPC 机器岗位**。

---

- ❌ 玩家当服务员/厨师被雇
