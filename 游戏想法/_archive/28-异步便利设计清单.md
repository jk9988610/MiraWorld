# 异步便利设计清单：还推荐怎么做？

> 状态：体验原则 + 功能推荐  
> 记录时间：2026-09-12  
> 来源：与作者的讨论  
> 目的：凡能体现 **「不必同时在线也很好」** 的，优先这样设计  

---

## 一、一句话

MiraWorld 的竞争力不是「更像实时 MMO」，而是 **错时也能完整参与**。  
下面列 **已采纳** 与 **仍推荐做** 的玩法；实现时优先选 **信箱、时间窗、队列、日报、到点结算** 一类机制。

**反原则：** 需要全员同时在线才能玩的，一律降级为 **可选 spice** 或 **不做**。

## 三、仍强烈推荐做（体现异步便利）

### 3.1 通讯与社交

| 功能 | 怎么做 | 异步便利 |
|------|--------|----------|
| **委托函模板回复** | 店主/厨师预设 5 句回信，顾客信来了可一键发 | 不必即时客服 |
| **@ 提及进信箱** | 有人点名你 → 未读角标，不弹窗 | 错时看见 |
| **线程续聊** | 订单绑 `thread_id`，半年后还能翻记录 | 纠纷有据 |
| **势力周报** | 每周一封馆报汇总公告/战况 | 代替刷频道 |
| **订阅_digest** | 关注的店/作者 **每周一信** 新作摘要 | 代替推送轰炸 |

### 3.2 订单与经济

| 功能 | 怎么做 | 异步便利 |
|------|--------|----------|
| **我要 · 排队意向** | 同时挂 3 条「想要」，系统慢慢匹配厨师 | 不用蹲单 |
| **预约单 / 时段槽** | 「下周六晚市要一桌宴」占坑 | 提前规划 |
| **缓释到货** | 订购材料 `deliver_at` 次日到家园邮箱 | 像网购，不必守着 |
| **冷静期成交** | 大额二手 `24h` 内可反悔 | 不必当场决断 |
| **拼单截止** | 5 人成团，**截止时间** 前各自异步付款 | 不用同时点 |
| **反向拍卖** | 多人 **密封报价**，截止后开标 | 投标人各投各的 |
| **限价求购** | 「80 灯油收雾纹砖」挂栏，有人卖自动成交 | 挂着就走 |
| **订单草稿** | 点菜写一半存盘，下周再提交 | 碎片时间 |

### 3.3 工作与成长

| 功能 | 怎么做 | 异步便利 |
|------|--------|----------|
| **当班日报** | 离线 auto 汇总（已有 `27`） | 上线一次看懂 |
| **口味谱周报** | 「你这周偏辣」一封信 | 成长感不逼肝 |
| **成就庆祝信** | 门槛到了才发，**不挡路** | 惊喜错时到达 |
| **考证随时考** | 律师/开店题 **无时限**，关页下次继续 | 碎片学习 |
| **见习旁观** | 见习律师只看卷宗不投票 | 错时学习 |
| **作业/交付窗** | 教师课：`72h` 内交 item 即可 | 不必同步上课 |
| **调查 **慢任务**** | 「派遣 4h」→ 到点信箱发报告 | 像挂机但无实时画面 |
| **店铺定时上架** | SKU `publish_at` 到时自动亮栏 | 店主不用准点蹲 |

### 3.4 世界与探索

| 功能 | 怎么做 | 异步便利 |
|------|--------|----------|
| **首次到访信** | 新地点打卡 → 专属一句进邮箱 | 探索奖励可稍后读 |
| **足迹图鉴** | 地图变色慢慢填，无截止时间 | 反清图强迫症可选 |
| **异步寻宝** | 前人藏线索，后人按信找地点 | 解谜跨天 |
| **世界季阶段条** | 全服 7 天累计，个人贡献异步加 | 战争不必同步 |
| **地点状态延迟** | 「门三日后开」服务器时间 | 期待感 |
| **回放票** | 演出结束卖 transcript，异步看 | 赶不上直播 |

### 3.5 组织与治理

| 功能 | 怎么做 | 异步便利 |
|------|--------|----------|
| **公会议案** | 提案 → `72h` 成员点同意 | 不用开会 |
| **使馆回函 SLA** | 「三日内答复」显示在信头 | 设预期不逼即时 |
| **轮值主席** | 一季一人，公告署名自动变 | 组织慢节奏 |
| **投票券攒着用** | 活动期获得，窗结束前投 | 不必活动当天在线 |
| **申诉期** | 举报成立后商家 `72h` 申诉 | 律师错时阅卷 |

### 3.6 界面与产品

| 功能 | 怎么做 | 异步便利 |
|------|--------|----------|
| **壳层未读汇总** | 一个角标，进信箱才拉全文 | 省流量省心 |
| **「稍后提醒」** | 仅书签订单/信，**不推送** | 自己记事 |
| **离线快照** | PWA 缓存上次地图/地点文 | 地铁读 |
| **空状态暖文案** | 「今日风静，无信」 | 无单不焦虑 |
| **Deep link** | 邮件里链到订单/地点 | 隔天一点即达 |

## 四、推荐的产品句式（文案层）

写功能说明时，用这些句式强化异步心智：

| 推荐 | 避免 |
|------|------|
| 「何时方便，何时打开信箱」 | 「立即参与限时活动」 |
| 「截止前投一票即可」 | 「今晚 8 点准时开战」 |
| 「对方睡醒后会看见」 | 「对方正在输入…」 |
| 「进度已记在订单上」 | 「请保持在线」 |
| 「离线也会按日程推进」 | 「离线将错过奖励」 |
| 「没赶上现场，可读实录」 | 「仅此一场，错过无」 |

## 五、刻意不做 / 弱做（破坏异步便利）

| 不建议 | 理由 |
|--------|------|
| 全服同时在线活动领奖 | 错时玩家永久吃亏 |
| 实时竞价最后一秒狙击 | 逼盯盘；可改为密封投标 |
| 强制同步 PvP | 与 `12` 世界季哲学冲突 |
| 未读推送轰炸 | 违反 `02` |
| 「在线越久奖励越多」 | 逼挂机 |
| 聊天室当主沟通 | `04` 已否 |
| 订单只有 60s 接单否则失败 | 逼蹲池；改为长窗或 auto |
| 必须同步会议才能推进主线 | **无主线**（`02`） |

**同步厅 / 直播峰值**（`25`）：限人数、短窗、**必有归档** — 是香料，不是主菜。

## 七、自检表（新功能上线前问 5 句）

1. **不在线能否完成 80%？** — 否则改  
2. **是否依赖「同时在线」？** — 是则改可选或归档  
3. **结果是否进信箱/订单可查证？** — 否则补  
4. **是否有明确时间窗而非秒级？** — 无则加  
5. **错时参与是否吃亏？** — 是则补异步补偿（回放票、累计条）

## 八、小结

| 问题 | 答案 |
|------|------|
| 还有哪些体现异步便利？ | **信箱、时间窗、队列、日报、到点结算、归档回放** |
| 总原则？ | **错时也能完整参与；同步是例外** |
| 最该先做？ | 日报、里程碑、预约/排队、周报、模板回信 |
| 最该避免？ | 推送、秒级抢单、唯同步奖励 |

> 好的异步设计，像留信、留单、留窗——  
> 你什么时候来，事情都还在；  
> 不必和谁对齐表，馆子在，账在，信在。
