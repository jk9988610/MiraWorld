# 乌托邦经济与内生闭环定稿

> 状态：**顶层经济规范**（取代旧「留痕 / 招贤 / 律师 / 叙事产出」路线）  
> 记录时间：2026-09-13

> 细则：[43-市民组与聚光灯定稿](./43-市民组与聚光灯定稿.md) · [44-机构编制与工资定稿](./44-机构编制与工资定稿.md)

## 一、一句话

**乌托邦里，城市自己转：机构生产 → 工资与福利 → 市民消费 → 机构营收。**  
玩家是 **带 handle 的经营者**，用资产参与闭环赚收益；**每日投资金** 是单独的外生补贴，不参与市民账本平衡。

**只输出决策与数字**（买卖、编制、扩产、定价），**不输出** 故事、判决、创作、中介撮合。

---

## 二、双账本（必须分账）

| 账本 | 谁 | 钱从哪来 | 用途 |
|------|-----|----------|------|
| **外生 · 玩家投资** | 玩家 | 乌托邦日投（可视为无中生有，**不计入**城市总账平衡） | 玩家扩店、扩产、冒险资本 |
| **外生 · 城市福利** | 城市 `welfare_fund` | 乌托邦 **城市定额注入**（配置常数，有账） | **仅** 失业市民 **最低生活补贴** |
| **内生 · 机构与市民** | 机构 + 市民组 | 卖货、工资、消费 | 生产 ↔ 消费闭环 |

**纪律：**

- 市民 **不能** 从「消费池」凭空刷钱。  
- **在岗** 市民钱 **只来自机构工资**（不得低于 **最低工资标准**）。  
- **无岗** 市民钱 **只来自城市最低生活补贴**（温饱线，非富裕）。  
- 玩家经营所得 **只来自内生闭环**（+ 外生日投另计）。

---

## 三、三类 Actor

| Actor | 说明 |
|-------|------|
| **玩家** | 仅 `handle`；开店 = 多一个 **机构**；无「市民/旅客/律师」等标签 |
| **机构**（Institution） | 面坊、医馆、铁匠铺、玩家店…；雇市民组、发工资、挂 offer、生产 |
| **市民组**（PopGroup） | 1000 人/组；**一组一主雇**；消费用组内 `wallet` |

**机器岗位**（厨师、服务员、医生…）是 **机构编制 slot**，不是玩家职业。见 `44`。

---

## 四、核心循环（无玩家也能跑）

```
机构生产 / 挂 offer
    → 机构发薪（≥ 最低工资）→ 在岗组 wallet
    → 城市发补贴 → 无岗组 wallet（仅温饱）
    → 市民组按 wallet 买 offer
    → 机构 / 玩家店营收
    → 机构付工资、维护（闭环）
```

**cron 日 tick** 执行；与玩家是否在线无关。

---

## 五、乌托邦自洽规则

| 规则 | 说明 |
|------|------|
| **职业必有机构** | 无「医生」岗的医馆 → 不出现「欧阳医生」类名 |
| **人口不日刷** | 首发 10 组 × 1000；增减走机构扩编（后置） |
| **最低工资** | `payroll ≥ min_wage × 在岗人数`（机构发得出才发，见 `44`） |
| **最低生活补贴** | 无岗组每人每日 `min_living_subsidy`（城市福利基金出） |
| **补贴 ≠ 富裕** | 补贴仅够基础口粮级消费，想多余收入须 **就业** |
| **玩家日投** | 公式：`200_000 + rand(5%,10%) × 玩家总资产`（规划；实现后置） |

## 六、与已实现 v1.x 的关系

| 已有 | 在闭环中的位置 |
|------|----------------|
| `shop` / `offer` | 玩家机构的生产出口 |
| `order` | 买家：`player` 或 `pop_group` |
| `auto_on` | 机构产能 / 接单 |
| `bounty` buy/sell | **玩家间** 贸易决策（可选）；与市民消费 **分开** |
| `visit` | 地图；**不** 驱动市民 segment |
| `message` | 经营结果通知；非故事输出 |
