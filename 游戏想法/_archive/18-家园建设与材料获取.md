# 家园建设与材料获取

> 状态：家园玩法 + 材料供需  
> 记录时间：2026-09-12  
> 来源：与作者的讨论  

---

## 一、问题

很多玩家想 **建设自己的家园**，但：

- 官方不可能事先做好每一套「家装模板」  
- 玩家想要的可能是 **一把特定椅子、一块窗板、一种砖**——和 `16` 厨具问题一样  

**文本游戏里的家园** 不是 3D 盖房，而是：

> **一个属于你的地点槽 + 房间结构 + 从背包「摆放」带标签的建材与家具。**

材料从哪来？——复用 **词条存在 → 搜/买/订/铸 → 进背包 → 摆放**（`16`），再加 **探索、拆解、世界季** 等来源。

---

## 二、家园在系统里是什么（不必先有大模板）

```
【家园】= home_id（绑玩家）
    ├── 地点槽（地图上一个入口，如「某某的屋舍」）
    ├── 房间列表 room[]（官方只给空壳：厅、厨、院）
    └── 每房间内 placed_items[]：item_id + 格子/描述位
```

| 需要模板吗？ | 说明 |
|--------------|------|
| **整屋精装模板** | 可选 DLC/SKU，**非必须** |
| **房间空壳** | 官方 T0：`room_hall` `room_kitchen` `room_yard` |
| **家具 / 建材** | **逐件获取**，靠标签 `build_material` `furniture` |
| **涌现式样** | 玩家摆什么，家就是什么——**组合即设计** |

**没有「地中海风整套」模板，也能有家园：** 先有一间空厅，再一件一件往里填。

## 三、材料与家具：玩家怎么获取？

与 `16` 同一套 **五路来源**，针对家园标签扩展：

### 3.1 五路来源（总表）

| 来源 | 适合 | 例子 | 文档 |
|------|------|------|------|
| **① 探索 / 采集** | 基础建材 | 打卡林地 → `item_wood`；旧栈桥 → `item_driftwood` | `03` |
| **② 商城 / 店铺** | 已有 SKU 的家具 | 买「镜湖木椅」SKU | `01` `07` |
| **③ 工匠订制** | 无货但要指定词条 | 「做一扇雕花窗」代工单 | `16` `17` |
| **④ 系统铸造** | 标准建材、通用家具 | 花灯油铸 `item_brick` ×10 | `16` |
| **⑤ 提请新词条（T2）** | 百科都没有 | 「想要弯铁烛台」→ 入库再订做 | `16` |
| **⑥ 订单 / 悬赏** | 让别人帮你凑料 | 「收 20 木板」悬赏 | `01` |
| **⑦ 拆解 / 回收** | 二手流转 | 拆掉旧家具 → 部分材料 | `01` 二手 |
| **⑧ 世界季 / 邮箱奖励** | 稀有装饰 | 终战谢礼 `item_war_banner` | `12` `14` |
| **⑨ 系统托底** | 标准件长期无人接 | 馆驿铸一捆普通砖（贵） | `17` |

**没有模板 ≠ 不能建；缺的是 `item_id`，不是缺「整套蓝图」。**

### 3.2 玩家端标准流程（缺一件建材时）

```
打开家园编辑 → 想摆「雕花窗」→ 背包没有
        │
        ▼
百科搜「窗」 / 商城搜「furniture_window」
        │
   ┌────┴────────────┬─────────────────┐
   │ 有卖            │ 有词条无货      │ 无词条
   ▼                 ▼                 ▼
  购买              订制 / 求购 /       提请新词条
                    系统铸标准窗       → 铸造或派单
        │
        ▼
  进背包 → 家园界面「摆放」→ placed_items 写入
        │
        ▼
  服务器验收：该 item 标签含 furniture 且 room 允许 → 成功
```

与厨房缺勺 **同一套 UI**，只是标签换成 `build_material` / `furniture`。

## 四、没有模板时，「建造」怎么做？

### 4.1 模块化三步（MVP 友好）

| 步 | 玩家做什么 | 系统做什么 |
|----|------------|------------|
| **1. 解锁房间空壳** | 花灯油扩一间厅/厨/院 | 扣费，`home.rooms += 1` |
| **2. 凑材料** | 五路来源（§3） | 背包增减 |
| **3. 摆放** | 从背包选物品放到房间格 | 校验 tag + 格位上限 |

**高级（后期）：**  
- 「配方」：`item_brick×10 + item_mortar×2` → 合成 `item_wall_section`  
- B₁ 卖「小院精装 Blueprint」——整包摆放方案，仍逐件验材料  

### 4.2 标签体系（比模板更重要）

| 标签 | 用途 |
|------|------|
| `build_material` | 木、砖、灰、钉——可合成或直摆 |
| `furniture` | 椅、桌、床、柜 |
| `fixture` | 窗、门、灯——常需 `room` 墙位 |
| `decor` | 画、盆栽、旗——纯装饰 |
| `kitchen_utensil` | 厨房间专用（`16`） |

创作者只需声明 **房间允许哪些 tag**，不必列出每一件家具。

### 4.3 家园是否分享、别人能否参观

| 功能 | 实现 |
|------|------|
| **参观** | 家园入口 = 地图节点；他人打卡、留痕（`03`） |
| **抄样板间** | 卖 Blueprint「摆放方案」；买家仍须自己有材料 |
| **公会合建** | 公会家园 `guild_home_id`，材料从公会司库扣 |

## 五、哪些必须玩家做、哪些系统能帮（家园版）

沿用 `17` 标准：

| 系统可托底 | 必须玩家 / 工匠 |
|------------|-----------------|
| 标准砖木铸造 | 定制雕花门窗叙事 |
| 馆驿送一捆材料到家园（跑腿） | 「按我画的图」全定制家装 |
| 数字家具 SKU 发货 | 玩家厨师来你家「办宴」服务单 |
| 超时标准建材订制单 | 指定「要某玩家工匠打的家具」 |

## 七、MVP 建议

| 做 | 不做 |
|----|------|
| 1 个 `home` 绑玩家：1 厅 + 5 格摆放 | 整屋精装商城 |
| T0 建材 5 种：木、砖、钉、灯、布 | 无限 T2 无审核 |
| 探索 2 地点掉木/旧木 | 3D 地形编辑 |
| 缺物链到 **订制 / 系统铸**（`16`） | 复杂合成树 |
| 参观 = 地图节点 + 打卡 | 公会合建 |

## 九、小结

| 问题 | 答案 |
|------|------|
| 没有家装模板怎么办？ | **房间空壳 + 逐件摆放**；组合即设计 |
| 材料哪来？ | **探索、商城、订制、系统铸、提请词条、悬赏、拆解、活动奖** |
| 和厨具问题一样吗？ | 是，同一套 `16` **词条驱动** |
| 系统托底？ | 仅 **标准建材**（`17`） |

> 家园不是买一套样板间，  
> 是慢慢把木、窗、灯一件一件领进空屋——  
> 馆里认每一件的词条，不认「设计师有没有想到这一款」。
