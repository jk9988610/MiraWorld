# 自定义命名与馆规：建筑、地点、职业怎么起名？

> 状态：命名权 + 显示名机制  
> 记录时间：2026-09-12  
> 来源：与作者的讨论  

---

## 一、现实里怎么处理？

| 现实对象 | 谁命名 | 怎么处理重名 / 乱名 |
|----------|--------|-------------------|
| **地名（国家）** | 政府 / 国际公约 | 官方地名库；外交承认 |
| **店铺招牌** | 老板 | 工商登记；侵权可诉 |
| **职业称呼** | 行业 + 自称 | 「律师」需考证；「大师」可自称但不可欺诈 |
| **建筑** | 业主 / 开发商 | 产权证地址固定；绰号民间流传 |
| **商品** | 厂商 | 商标；SKU 与货架名可不同 |

**现实共性：**

1. **底层有一个不变的编号/登记**（地址、执照号、SKU）  
2. **对外可以有一个好听的名字**（招牌、绰号）  
3. **涉及他人权益或欺诈时，馆规（法律）介入**

## 二、平台上对应：双名制

```
┌─────────────────────────────────────────┐
│  canonical_id（馆里唯一，几乎不改）       │
│  例：location_old_pier / item_ladle      │
│  例：profession_runner / building_room_hall │
└──────────────────┬──────────────────────┘
                   │ 绑定
┌──────────────────▼──────────────────────┐
│  display_name（显示名，可自定义范围内改） │
│  例：「旧栈桥」 / 「弯柄汤勺」              │
│  例：玩家家：「雾边小筑」                   │
└─────────────────────────────────────────┘
```

| 层 | 谁定 `id` | 谁定 `display_name` | 例子 |
|----|-----------|---------------------|------|
| **世界官方** | 设计方 | 设计方（百科主名） | 潮灯港、拾遗院 |
| **玩家组织** | 系统分配 `guild_id` | **会长可起名** | 「北风商队」 |
| **家园** | `home_id` | **主人可起名** | 「窗边有猫的小屋」 |
| **店铺** | `shop_id` | **店主可起名** | 「少盐食堂」 |
| **物品 T2** | 提请审核后 `item_id` | **提请者建议名** + 馆规校对 | `item_ladle_curved` 显示「弯柄勺」 |
| **职业皮肤** | `profession_id` 固定 | **玩家绰号**（L3，不改权限） | 自称「雾桥引路人」，系统仍记行者 |
| **地点玩家共建** | 须入百科后 `location_id` | 共建者提案名 → 投票/审核 | 后期 v2 |

**口诀：`id` 管账与验收；`display_name` 管温度与个性。**

与 `13` 一致：硬逻辑只认 `id`；好听的名字大多是 L3，但 **组织/家/店** 的 display_name 也是 L2 登记字段。

## 三、谁能自定义命名？（权限表）

| 对象 | 可自定义？ | 条件 | 审核 |
|------|------------|------|------|
| **官方地点 / 势力** | 仅设计方 | — | 内部 |
| **玩家家园名** | ✅ 主人 | 拥有 `home_id` | 敏感词机审 |
| **公会 / 商队名** | ✅ 会长 | 创建组织 | 机审 + 举报 |
| **店铺名** | ✅ 店主 | 开店资质 | 机审 |
| **SKU 商品名** | ✅ B₂ | 绑 Blueprint | 与交付一致校验（`07`） |
| **新物品名（T2）** | ✅ 提请者建议 | `16` 流程 | 重复合并 / 敏感词 |
| **新地点名** | ⚠️ 提案 | 全服或势力投票（`14`） | 通过后入百科 |
| **新职业类型** | ❌ 玩家不能造 | 只有 `profession_id` 新标签需设计方 | — |
| **职业自称绰号** | ✅ 个人简介 | 不改系统权限 | 仅展示，不骗验收 |
| **建筑房间类型** | ❌ 自定义类型名 | 只能选官方空壳 `room_kitchen` | — |
| **建筑内一格摆放** | 间接 | 摆的是已有 `item` 的 display_name | — |

**职业：** 不能发明新 `profession_id`（不能自创「宇宙执法者」并接律师单），但可以 **皮肤称呼**；接单权限仍看考证（`09` `10`）。

## 四、「想到了更好的名字」——三条路径

### 路径 A：只改自己的招牌（最快）

适用：**家园、公会、店铺、个人绰号**

```
玩家提交 display_name
    → 敏感词 / 长度 / 冒充官方（禁含「拾遗院官方」）
    → 通过即显示；canonical_id 不变
```

**不创造新世界对象**，只改招牌。

### 路径 B：提请新词条入百科（`16` 扩展）

适用：**新物品、新建筑组件、玩家希望「全世界都能搜到」的名字**

```
玩家：「我想要词条：雾纹砖」
    → 系统查重：是否已有 item_brick_fog 只是名字不同？
    → 若是新 id：T2 审核 → item_id 入库
    → display_name 默认用提请名，百科可改简称
```

**全世界共享这一个 id**；不是每人私有的假砖。

### 路径 C：提案新地点 / 建筑名（公共叙事）

适用：**想在地图上多一个「某某遗迹」**

```
玩家 / 势力提案 location 名 + 描述
    → 投票（`14`）或设计方审定
    → 通过：分配 location_id，地图加节点
    → 不通过：仅作为某玩家家园内 display_name（路径 A）
```

**公共地点**不能私占；**私人小屋**可以叫「遗迹风」但不改世界地图 id。

## 五、重名、侵权、冒充怎么处理

| 问题 | 馆规 |
|------|------|
| **两家店同名** | 允许（现实也有）；靠 `shop_id`、信誉、店主区分 |
| **冒充拾遗院** | 禁 display_name 含官方势力 protected 词 |
| **侮辱 / 色情** | 机审 + 举报 → 改名或封禁 |
| **SKU 名不副实** | `09` 货不对板 |
| **item 提请洪水** | 合并同义项；「弯柄勺」与「曲柄勺」→ 一 id 多别名 |
| **职业谎称** | 界面显示须带 **系统认证标**；无标 = 绰号 only |

**别名表（可选）：** 同一 `item_id` 可挂多个搜索别名，减少重复 T2。

## 六、与建筑、地点、职业的布局关系

```
世界地图（官方 location_id + 主 display_name）
    │
    ├── 势力使馆 / 公告（势力可设副标题 slogan，不改 id）
    │
    ├── 玩家家园节点（home_id + 自定义屋名）→ 地图显示「某某的 · 雾边小筑」
    │
    ├── 店铺（shop_id + 店名）→ 灯市列表
    │
    └── 公会驻地（后期：guild_hall_id + 公会名）

职业树（固定 profession_id）
    │
    ├── 考证通过 → 显示「注册律师」+ 认证标
    │
    └── 个人绰号「判例司判官」→ 仅名片 / 粉笔字（L3）
```

**布局原则：**

- **地图骨架** = 设计方 `location_id`（少而稳）  
- **丰富度** = 玩家 **display_name** 挂在家园 / 店 / 公会 / 物品上  
- **新公共地点** = 提案 + 投票，不私自加 id

## 七、现实 → 平台对照（一句话）

| 现实 | 平台 |
|------|------|
| 营业执照 | `shop_id` / `guild_id` |
| 招牌 | `display_name` |
| 商标注册 | protected 词列表 + `09` |
| 职业资格证 | `profession` 考证 + 认证标 |
| 地名普查 | 世界百科 `location_id` |
| 民间绰号 | 个人简介 / 粉笔字 L3 |

## 八、MVP 建议

| 做 | 不做 |
|----|------|
| `id` + `display_name` 双字段 | 玩家自创 profession_id |
| 家园 / 店铺可起名 + 敏感词 | 玩家私改官方地点名 |
| 物品 T2 提请时带 **建议显示名** | 无审核全开地图命名 |
| 职业界面：**认证名 + 绰号** 分行显示 | 绰号冒充认证 |

## 十、小结

| 问题 | 答案 |
|------|------|
| 想自定义建筑 / 地点 / 职业名？ | **分对象**：家/店/公会改招牌；公共物提请百科；职业只能绰号不能新 id |
| 现实怎么处理？ | **登记号不变 + 招牌可起 + 侵权馆规** |
| 平台核心布局？ | **canonical_id 管硬逻辑；display_name 管个性** |
| 更好的名字？ | 私用 → 路径 A；全服要用 → B 或 C |

> 馆里每样东西都有户口（id）；  
> 门口挂什么招牌，可以是你起的好名字——  
> 只要不改户口，不冒充官府，不拿空话骗验收。
