## 一、先回答：那些「专业词」用大白话怎么说？

设计文档里有些词来自电商、外卖、游戏行业。下面用 **现实类比** 说明，玩家帮助页也可直接复用。

| 文档里的词 | 四象 | 大白话 | 在游戏里指什么 |
|------------|------|--------|----------------|
| **挂单 / offer**（原 SKU） | 物 | 菜单上一行可买的 | 陈师傅的「标准汤面 · 15 点」 |
| **item / 物** | 物 | 一样东西 | 配置里的 `item_id`，如一碗面 |
| **SKU**（旧） | → offer | 见上 | **请改用「挂单」** |
| **Blueprint** | **做菜方案 / 剧本** | 菜谱或游戏关卡设计稿 | 背后「怎么玩、怎么交付」的**方案文件**；顾客一般看不见 |
| **display_name** | **招牌名 / 外号** | 店招「少盐食堂」 | 给人看的**好听名字**；系统内部还有不变的编号 |
| **canonical_id / id** | **户口号** | 营业执照号、条码 | 系统认账用的**唯一编号**，几乎不改 |
| **托管** | **钱先放柜台** | 外卖平台代收钱，完成了再分 | 下单时点先锁在系统，完成再分给厨师/店主 |
| **订单** | **一张单** | 外卖单、服务单 | 你点的「我要」、买的挂单、接的悬赏，都是订单 |
| **悬赏 / 招贤帖** | **栏上贴的招人/办事启事** | 58 招聘、贴吧悬赏 | 公开列表里的一条需求 |
| **执照 / 考证** | **上岗证** | 律师证、骑手证 | 通过简单考后，系统给你**认证标**，才能接某类活 |
| **信誉** | **口碑分** | 骑手星级、淘宝信誉 | 完成单、被举报会影响的数字；影响抢单优先级 |
| **口味谱** | **你常吃什么口味的画像** | 饮食偏好档案 | 根据你**历史点的单**生成：爱调查、爱辣、爱经营… |
| **L1 / L2 / L3** | **三层真话** | 见下表 | 见 §二 |

### 1.1 SKU 再讲细一点

很多人第一次听 SKU 会懵。可以这样说：

> **SKU = 店里货架上的「一行商品」。**  
> 不是泛指「所有东西」，而是 **已经包好、标价、能下单的那一款**。

例子：

| 层次 | 例子 |
|------|------|
| 物品（item） | `item_noodle_bowl` — 世界里存在「一碗面」这种东西 |
| 商品（挂单，旧称 SKU） | `offer_noodle_mist` — 少盐食堂卖的「雾港汤面 · 12 点 · 含一次游玩」 |
| 同一 item 可有多个挂单 | A 店卖「雾港汤面」，B 店卖「加辣雾港汤面」，价不同 |

**玩家日常只需要记：进店看菜单 = 看挂单列表；背包里 = 你真正持有的 item。**

### 1.2 三层真话（L1 / L2 / L3）白话版

| 层 | 白话 | 例子 |
|----|------|------|
| **L1 百科** | 馆里登记在册的「官方说法」 | 雾晶盐产地：潮灯港 |
| **L2 馆规** | **算数的硬记录** | 订单完成、背包 +1、考证通过 |
| **L3 叙事** | **嘴上说的、好看的、可吹的** | 「这盐从美国进口」——好听，但不一定罚 |

**玩家面板上的分工：** 认证、订单、装备槽 = L2；个人简介、绰号、状态心情句 = L3。

## 二、玩家有没有「自己的面板」？

**有。** 建议壳层常驻入口 **「我的」**，分 **自己看全版** 与 **别人看名片版**。

```
┌─────────────────────────────────────────┐
│  车载壳层：地图 · 通知 · 背包 · 我的  │
└─────────────────────────────────────────┘
                    │
        ┌───────────┴───────────┐
        ▼                       ▼
   【我的 · 全版】          【他人名片 · 简版】
   自己管理用               点别人名字时看见
```

## 三、玩家身上显示什么？（总表）

| 信息块 | 自己看见 | 别人看见 | 层 | 说明 |
|--------|----------|----------|-----|------|
| **昵称 / 行者名** | ✅ | ✅ | L2 | 注册名或 `display_name` |
| **个人简介** | ✅ 可编辑 | ✅ | L3 | 自我介绍，机审 |
| **职业认证** | ✅ | ✅ | L2 | 「注册厨师」「注册律师」+ 认证标 |
| **职业绰号** | ✅ | ✅ | L3 | 「雾桥引路人」；**无认证标** |
| **当前所在** | ✅ | ⚠️ 可选隐私 | L2 | 「旧栈桥」；可关「对他人隐藏」 |
| **状态一句** | ✅ 可编辑 | ✅ 可选 | L3 | 「今日接少盐单」 |
| **口味谱摘要** | ✅ 全文 | ⚠️ 摘要或关 | L2 软 | 「常点辣、偏调查」 |
| **信誉** | ✅ 数字 | ✅ 星级/区间 | L2 | 如 4.7★ |
| **势力 / 公会** | ✅ | ✅ | L2 | 潮灯港籍、北风商队 |
| **穿戴装备** | ✅ | ✅ | L2 | 见 §五；影响「人物肖像」 |
| **背包全部** | ✅ | ❌ | L2 | 仅自己 |
| **进行中订单** | ✅ | ❌ | L2 | 仅自己 |
| **证照列表** | ✅ | ⚠️ 仅认证标 | L2 | 执照详情自己看 |
| **邮箱** | ✅ | ❌ | L2 | 仅自己 |

**原则：别人看你像看「名片 + 橱窗人偶」；你自己看是「档案 + 仓库 + 后台」。**

## 四、「我的」面板布局（自己看）

建议 Tab 或纵向区块：

### 4.1 抬头区 · 人物肖像（文字视觉）

与 `20` 地点肖像同一套逻辑，换成 **人身锚点**：

```
【人物肖像】（系统根据穿戴自动生成，可折叠）

  一顶潮灯港的软帽压在眉上。
  腰间挂着注册厨师的铜牌——是真的，考证发的。
  右手常握一把弯柄勺，像随时准备进厨房。

  ── 你写的状态 ──
  「晚市接单，少盐照旧。」
```

| 锚点 | 可穿戴类型 | 示例 |
|------|------------|------|
| 头 | `wearable_head` | 帽、巾、面具 |
| 身 | `wearable_body` | 袍、围裙、外套 |
| 腰 | `wearable_belt` | 铜牌、工具袋、腰包 |
| 手 | `wearable_hand` | 勺、杖、信 |
| 饰 | `wearable_decor` | 花、徽章、挂件 |

**不是每件背包物都能穿** —— 须带 `wearable_*` 标签。

### 4.2 身份区

```
昵称：雾桥阿青
认证：注册厨师 · 注册行者        ← L2，系统发证
绰号：「少盐派掌门」               ← L3，自己起，无标
归属：潮灯港 · 北风商队（招贤中）
信誉：4.8 ★ · 完成单 126
口味谱：偏辣 · 爱调查 · 少接护送   ← 来自历史订单，非自填
```

### 4.3 个人简介（L3）

- 玩家自写，限字数，敏感词机审  
- 可写背景故事、接单偏好、不接什么单  
- **不能**写「官方律师」等冒充认证的话（无标则当绰号）

### 4.4 状态区（L2 + L3）

| 字段 | 类型 | 说明 |
|------|------|------|
| **当前所在** | L2 | 地图 `location_id`；隐私可藏 |
| **营业状态** | L2 | 若开店：营业中/打烊；若打工：在某某店当班 |
| **进行中** | L2 | 「1 单烹饪中」— 仅自己见详情 |
| **状态一句** | L3 | 玩家自填：「旅行中，回信慢」 |
| **世界季** | L2 | 可选展示：「潮灯港志愿兵」徽章 |

### 4.5 装备区

```
【穿戴】 头：软帽 │ 身：厨袍 │ 腰：厨师铜牌 │ 手：弯柄勺
【背包】 → 点壳层「背包」进全列表（与面板联动）
```

- **穿戴** = 影响人物肖像 + 名片展示  
- **背包** = 全部持有物；默认 **不** 在名片上展开

### 4.6 证照与订单（仅自己）

- 开店执照、各职业考证通过记录  
- 进行中 / 历史订单摘要（链到订单详情）

## 五、装备：在文字游戏里是什么？

**不是必须做「攻击力 +10」的数值装。**

| 类型 | 作用 | 是否显示给别人 |
|------|------|----------------|
| **穿戴品** | 人物肖像文案、名片装饰 | ✅ |
| **工具** | 接某些单时系统校验「手持合适工具」 | 穿戴了才在肖像里出现 |
| **消耗品** | 在背包用掉 | 不穿戴则不显示 |
| **建材 / 家具** | 摆家里 | 出现在 **家园肖像**，不在身上 |
| **证照铜牌** | 考证后系统发放，可挂腰锚点 | ✅ 带认证标 |

### 5.1 穿戴与背包的关系

```
背包 item
    │
    ├─ tag 含 wearable_* → 可「穿上」→ equipped_slots
    │
    └─ 无 wearable → 只能堆背包或摆家里
```

穿上后：

- `equipped_slots` 写入 L2  
- 人物肖像重新合成（`20` 同款规则）  
- 别人看名片时看见 **穿出来的样子**，看不见背包里还有多少把勺

### 5.2 装备描述从哪来？

| 来源 | 优先级 |
|------|--------|
| 物品百科 `flavor_line` | 高 |
| 物品 `display_name` | 中 |
| 玩家自定义昵称（仅部分 T2 物品） | 低 |
| 系统默认 | 「一件寻常之物」 |

**L3 吹牛** 只能写在 **个人简介**，不能改物品 L1 产地。

## 六、别人看你的「名片」

点聊天、订单、店铺里的「店主」、应聘列表里的名字 → 打开 **名片弹层**：

```
┌─────────────────────────────────┐
│  雾桥阿青                        │
│  注册厨师 · 注册行者  ★4.8       │
│  「少盐派掌门」                  │
├─────────────────────────────────┤
│  【肖像】软帽、厨袍、腰牌、弯柄勺  │
│  「晚市接单，少盐照旧。」         │
├─────────────────────────────────┤
│  口味谱摘要：偏辣 · 爱调查        │
│  归属：北风商队                  │
├─────────────────────────────────┤
│  [ 写信 ] [ 查看店铺 ] [ 举报 ]   │
└─────────────────────────────────┘
```

**不显示：** 背包清单、未公开位置、通知详情、进行中订单细节、原材料库存。

## 七、和消息、订单、地点的联动

| 场景 | 身上带什么信息 |
|------|----------------|
| **通知往来** | 对方头像旁显示 **认证标 + 绰号** |
| **订单详情** | 厨师/店主名片链接；显示当时 **信誉快照** |
| **店铺页** | 店主块链到名片（`20`） |
| **地图痕迹** | 粉笔字可署名；显示 **行者名**，不自动晒背包 |
| **应聘** | 雇主看见认证、信誉、完成单数、肖像 |

## 八、隐私开关（建议）

| 开关 | 默认 |
|------|------|
| 对他人显示当前所在 | 开 |
| 对他人显示口味谱 | 开（仅摘要） |
| 对他人显示状态一句 | 开 |
| 允许陌生人写信 | 开（可关） |

**订阅前零推送**（`02`）：隐私变更不通知任何人。

## 九、MVP 建议

| 做 | 不做 |
|----|------|
| 「我的」页：肖像 + 简介 + 认证 + 信誉 | 复杂捏脸 |
| 4 个穿戴槽：头身腰手 | 全身 12 槽 |
| 人物肖像 = 锚点填空（同 `20`） | 数值战斗力 |
| 他人名片简版 | 公开完整背包 |

## 十一、小结

| 问题 | 答案 |
|------|------|
| 挂单是什么？（旧称 SKU） | **货架上可下单的一件货**；菜单一行 = 一个挂单 |
| 玩家有面板吗？ | **有「我的」全版 + 他人名片简版** |
| 身上显示什么？ | **认证、绰号、肖像、状态、口味谱、信誉、归属** |
| 装备怎么显示？ | **穿戴槽 → 文字人物肖像**；背包仅自己见 |
| 材料和库存？ | **在身上不默认显示**；摆家里进家园肖像，进店进挂单 |

> 别人记住你的，是帽子上有没有厨牌、简介里写的那句话——  
> 不是你背包里还囤了多少斤盐。
