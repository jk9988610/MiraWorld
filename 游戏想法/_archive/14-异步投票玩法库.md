# 异步投票玩法库：多票机制与举一反三

> 状态：活动机制扩展  
> 记录时间：2026-09-12  
> 来源：与作者的讨论  

---

## 一、一句话

战争那种 **多局投票** 可以复用到很多异步活动里；  
玩家在局内 **挣票数、多投几次** 给心仪阵营——像攒券去投偶像，但 **馆规记账、异步开窗、手动领奖**。

---

## 二、多票机制（战争及通用）

### 2.1 基础规则

| 项 | 规则 |
|----|------|
| **底票** | 每账号每局 **至少 1 票**（自愿投） |
| **加票** | 通过 **游戏内行为** 获得 `vote_token`，同一局可投多票给 **同一阵营** |
| **上限** | 每局每账号 **总票上限**（如 10），防刷与土豪碾压 |
| **记录** | `votes(user, round, side, count)` 服务器记，不信客户端 |
| **异步** | 投票窗 48～72h，随时投，可分批投完 |

### 2.2 票数从哪来（建议）

| 来源 | 票数 | 说明 |
|------|------|------|
| 注册 / 每局底票 | 1 | 人人有 |
| 完成战时订单 | +1～2 | 鼓励参与但不强制 |
| 成就 / 世界季参与 | +1 | 曾投过票、曾读战报 |
| 活动物品「投票券」 | +1（消耗型） | 世界季掉落，**不卖真钱** |
| 公会集体任务 | +1 | 公会邮箱领团体券 |
| **不买票** | — | 防 Pay-to-Win |

> **幽默但受馆规约束**：台词说「我有一百票」——L3；背包 `vote_token` 数量才是 L2（`13`）。

### 2.3 多票与胜负

- **当局胜方** = 该局 **总票数**（不是人数）多的一方  
- **战争胜方** = 赢局更多的阵营  
- **奖励**：曾对 **最终胜方** 投过票的玩家（含多票中的一票即可）→ 邮箱谢礼

## 三、举一反三：还有哪些活动适合「异步 + 多票」？

统一模板：

```
开窗 → 挣票（可选）→ 投选项 A/B/C… → 计票 → 公布结果 → 投中/参与者领奖
```

---

### 玩法 1：阵营战争（已有）

| 项 | 内容 |
|----|------|
| **投什么** | 阵营 A vs B |
| **多票** | 战时单、投票券 |
| **结果** | 赢局多者胜；投胜方者得奖 |
| **文档** | `12` §4.5 |

---

### 玩法 2：下一张地图开哪里

| 项 | 内容 |
|----|------|
| **现实类比** | 市民投票修地铁哪条线 |
| **投什么** | 候选地点三选一：`北境哨站` / `沉船湾` / `镜湖深处` |
| **多票** | 探索过相关邻接地点 +1；打卡全图 80% +1 |
| **结果** | 下月世界更新开放最高票地点 |
| **有趣点** | 玩家真的改变地图，但不是个人主线 |

---

### 玩法 3：世界季终局分支

| 项 | 内容 |
|----|------|
| **类比** | 互动剧选结局 |
| **投什么** | 战争季末：`停战条约` vs `反攻到底` |
| **多票** | 本季每参与一局战争投票 +1 |
| **结果** | 胜选项写入 `world_flag`，下季文案分叉 |
| **有趣点** | 全服共创历史，异步揭晓 |

---

### 玩法 4：势力执政选举

| 项 | 内容 |
|----|------|
| **类比** | 城邦选港主（非现实国家仿真） |
| **投什么** | 候选人 A/B（玩家或 NPC） |
| **多票** | 本势力声望达标 +1；完成势力订单 +1 |
| **结果** | 胜者冠名使馆信箱 30 天；可发 1 条公告 |
| **有趣点** | 职位是 **皮肤 + 公告权**，不是 GM 权限 |

---

### 玩法 5：公会 / 联盟内部决议

| 项 | 内容 |
|----|------|
| **类比** | 业委会投票 |
| **投什么** | 「公会金库是否接某联合悬赏」 |
| **多票** | 会长 2 票；成员 1 票；司库 +1 |
| **结果** | 通过则公会订单池出现该单 |
| **有趣点** | 小团体民主；默认仍用 **公会信箱** 异步 |

---

### 玩法 6：雾桥公约 — 是否接纳新成员国

| 项 | 内容 |
|----|------|
| **类比** | 欧盟扩员公投 |
| **投什么** | 接纳 / 不接纳 某势力 |
| **多票** | 联盟成员各 1；完成联盟季任务 +1 |
| **结果** | 通过则新势力挂联盟旗，共享联合栏 |
| **文档** | `11` 联盟 v2 |

---

### 玩法 7：灯市月度 — 最受欢迎 SKU

| 项 | 内容 |
|----|------|
| **类比** | 美食榜 / Steam 大奖玩家票 |
| **投什么** | 候选 SKU 三选一（已购才可投） |
| **多票** | 每买过候选之一 +1；写过评价 +1 |
| **结果** | 胜者店铺角标「本月灯市之选」；作者邮箱奖励 |
| **有趣点** | 商业与社区结合；防刷：须真实 `owns(sku)` |

---

### 玩法 8：下一套官方 Blueprint 模板

| 项 | 内容 |
|----|------|
| **类比** | 开源社区 RFC 投票 |
| **投什么** | 「调查包」vs「护送包」vs「社交包」下季开放哪种模板 |
| **多票** | 方案师资质 +1；沙盒通过 1 次 +1 |
| **结果** | 设计方优先做最高票模板（`07`） |
| **有趣点** | 创作者驱动路线图 |

---

### 玩法 9：地点痕迹 — 保留还是抹去

| 项 | 内容 |
|----|------|
| **类比** | 社区决定涂鸦留不留 |
| **投什么** | 某条争议粉笔：保留 / 删除 |
| **多票** | 曾打卡该地点 +1；律师 +1（若投过馆规考） |
| **结果** | 多票方执行；律师团可申诉二审（`09`） |
| **有趣点** | 地图是活的；异步公共治理 |

---

### 玩法 10：节日皮肤 / 氛围主题

| 项 | 内容 |
|----|------|
| **类比** | 小区挂灯笼还是彩灯 |
| **投什么** | 壳层/UI 主题：`雾夜` / `灯会` / `雪线` |
| **多票** | 登录 3 天 +1；无硬收益，纯氛围 |
| **结果** | 下月全服默认风景皮（可个人关） |
| **有趣点** | 低成本大仪式感 |

---

### 玩法 11：慈善池方向（人道主义）

| 项 | 内容 |
|----|------|
| **类比** | 捐款用途公投 |
| **投什么** | 系统抽成累积池 → 救济新手 / 修复某地点 / 律师基金 |
| **多票** | 本季任意投票参与 +1 |
| **结果** | 最高票方向系统发奖励池 |
| **有趣点** | 战争季的「温柔反面」 |

---

### 玩法 12：下一场世界季母题

| 项 | 内容 |
|----|------|
| **类比** | 剧集下一季拍什么 |
| **投什么** | `贸易冲突` / `瘟疫谣言` / `考古竞赛` |
| **多票** | 上季参与投票 +1；完成上季谢礼领取 +1 |
| **结果** | 设计方按票写下一季（`12`） |
| **有趣点** | 玩家选天气，设计方仍编剧本 |

## 四、哪些不适合投票？

| 不适合 | 为什么 |
|--------|--------|
| 个人订单纠纷胜负 | 靠 `09` 证据与馆规，不是人气 |
| 背包物品归属 | 硬状态，不能公投 |
| 实时 PVP 胜负 | 与异步哲学相反 |
| 封号 / 重罚 | 仅律师团+系统，避免网暴公投 |

## 七、小结

| 问题 | 答案 |
|------|------|
| 多投几次？ | **挣 `vote_token`**，同局投同一阵营，有上限 |
| 还能用在哪？ | 开地图、选结局、选举、公会决议、SKU 榜、模板路线、痕迹治理、节日皮、下季主题… |
| 共同点？ | **异步开窗 + 馆规计票 + 投中/参与者邮箱领奖** |
| 原则？ | 投 **氛围与公共方向**，不投 **个人财产与刑责** |

> 票像馆里发的筹签：做完活、逛过街、肯出面，就多几张；  
> 异步投进箱子里，开窗一数——世界往那边歪一点。
