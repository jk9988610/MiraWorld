## 一、首发只押 **三大支柱**（三选一里的「三」）

从全部设想里，**发布会只承诺这三件事**：

| 支柱 | 玩家一句话 | 对应 Phase | 文档 |
|------|------------|------------|------|
| **① 探索** | 「我来过潮灯市，地图记得我。」 | 打卡市 + spot 彩蛋 | `03` `05` `31` |
| **② 点菜** | 「花点在一碗面，平台托管，真的进背包。」 | 一店 + 一单 + 分账 | `02` `23` `30` |
| **③ 通知** | 「我不在线也行，回来读通知就知道发生了什么。」 | 系统通知 + 订单摘要 | `04` `15` |

**首发不承诺：** 开店、雇人、配送、家园、投票、律师、离线 auto、场次演出、开放造词……  
这些写进 **路线图**，不写进发布会话术。

**发布会标题建议：** 「MiraWorld · 潮灯市」—— 能逛、能点、能收通知。地址见 `31`（市 + 人）。

## 二、首发完整体验流（15～25 分钟，可演示）

一条 **新玩家故事**，发布会按此录屏或现场走：

```
1. 注册 handle → `潮灯市`
2. 小林：「无主线。在潮灯市转转，或找陈师傅点碗面。」
3. 打卡潮灯市（市内逛点如晚霞岸可作彩蛋，见 `31`）
4. 找陈师傅 → 菜单
6. 钱包 **300 点** 新手礼
7. 「标准汤面 · 15 点」→ 托管
8. 陈师傅出餐 → 取餐 → 背包 +1
9. 系统通知 +「我的」看余额与打卡记录
```

**感受目标：**  
异步、有温度、**L2 真扣钱真给物**、不逼在线、不弹窗。

**首发刻意不做的一步：** 送到家、玩家开店、真人厨师、往来私信。

## 三、首发功能清单（IN / OUT）

### 3.1 必须有（v1.0 Launch）

| 模块 | 功能 | 砍到最小 |
|------|------|----------|
| **auth** | 行者名 + 密码注册登录 | email 可选 |
| **world** | 潮灯市打卡 + 可选市内逛点彩蛋 | 地址只到市 |
| **wallet** | credits（`wallet_credits`）、新手 300 点 | 无提现 |
| **catalog** | items + offers（见 `32`） | JSON 配置 |
| **actors** | 陈师傅挂单 | 店=人 |
| **records** | order + message + visit + ledger | 四象「事」 |
| **inventory** | stack | 无穿戴槽 |
| **profile** | /me 余额、足迹数、简介可改 | 无口味谱 |
| **UI** | 壳层：地图·食堂·信箱·背包·我的 | 无「我要」页 |
| **lore** | VitePress 分区页（A～F 区） | 与 `locations.json` 互链 |

### 3.2 首发不做（写进路线图，别偷偷做）

| 不做 | 最早版本 |
|------|----------|
| 玩家开店、招聘、雇员 | v1.2 |
| 配送、家园、距离运费 | v1.3 |
| 离线日程 auto | v1.4 |
| 悬赏栏、我要点菜 | v1.5 |
| 粉笔痕迹 UGC | v2.0 |
| 势力、公会、投票、世界季 | v2.x |
| 律师、举报陪审 | v2.x |

| 开放 T2 造词 | v2.5 |

## 七、发布会怎么讲（话术）

**讲：**  
- 一座可逛的文字世界，来过会记得  
- 真用信用点点一碗面，账在馆里  
- 信箱异步收信，不催你在线  

**不讲：**  
- 外卖、雇人、战争、律师、创作平台、元宇宙  

**演示结尾句：**  
> 「第一盏只照亮门口到食堂这一段路。  
> 开店、送餐、当班，会在后面的版本陆续挂上。」
