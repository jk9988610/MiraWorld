## 一、要定什么

米拉世界已有 **个人钱包 · 公司 · 机构 · 店 · 日 tick**，本稿定三层「入口与节奏」：

| 层 | 定稿方向 |
|----|----------|
| **门控** | 进游戏前 **六选一**：新/继续/加载 × 单人模式/多人模式 |

## 二、进门控：六选一

### 2.1 用语（已定）

全站统一说 **单人模式 / 多人模式**，不说「单人游戏 / 多人游戏」。

| 模式 | 含义 |
|------|------|
| **单人模式** | 私有 `world_id` 实例，独立 tick，**10 组市民** |
| **多人模式** | 共享潮灯市，服务端 cron 中速 |

### 2.2 门控选项

进入游戏前（登录后、进潮灯市前）：

```
┌─────────────────────────────────────┐
│       米拉世界 · 选择模式与存档        │
├─────────────────────────────────────┤
│  单人模式                            │
│    ○ 新的单人模式                    │
│    ○ 继续单人模式                    │
│    ○ 加载单人存档          ← 选档    │
│  多人模式                            │
│    ○ 新的多人模式                    │
│    ○ 继续多人模式                    │
│    ○ 加载多人存档          ← 选档    │
└─────────────────────────────────────┘
```

| 选项 | 含义 |
|------|------|
| **新的单人模式** | 新建私有实例；可选 **是否铁人**（§2.6） |
| **继续单人模式** | 载入 **上次活跃** 的单人档（一键继续） |
| **加载单人存档** | 打开 **存档列表**，玩家 **点选一档** 进入 |
| **新的多人模式** | 首次或新建绑定进入共享潮灯市；**默认铁人** |
| **继续多人模式** | 载入 **上次活跃** 的多人绑定（一键继续） |
| **加载多人存档** | 打开 **多人存档列表**（若账号有多角色/多绑定）， **点选** 进入 |

**继续 vs 加载：**

| | **继续** | **加载** |
|--|----------|----------|
| 操作 | 一键，进 **上次玩的档** | 先 **列表选档**，再进 |
| 无档时 | **灰显锁定** | **灰显锁定** |
| 有多个档 | 仍进上次活跃档 | 可换档 |

### 2.3 与现架构的关系

| 现网 | 门控后 |
|------|--------|
| 一个 DB、一座潮灯市 | **多人** = 现模式；**单人** = 独立 `world_id` / `save_slot` |
| cron 日 tick | 多人：服务端固定中速；单人：玩家可调速（§三） |

**纪律：** 单人 **不得** 污染多人经济；多人 **不得** 因某玩家暂停而全服暂停；**不做** 单人→多人迁档。

### 2.4 单人世界规模（已定）

- **完整 10 组 × 1000 市民**，与 [04-乌托邦经济](./04-乌托邦经济.md) 同规格。

### 2.5 门控页：「继续 / 加载」锁定（已定）

**含义：** 没有可载入存档时，**继续** 与 **加载** 均 **灰显** — 锁在 **门控页**，不是进城后锁经营菜单。

| 选项 | 何时可点 |
|------|----------|
| **继续单人模式** | 存在 **上次活跃** 单人档 |
| **加载单人存档** | 存在 **≥1** 单人档（列表非空） |
| **继续多人模式** | 存在 **上次活跃** 多人绑定 |
| **加载多人存档** | 存在 **≥1** 多人档/绑定 |
| **新的单人 / 新的多人** | 始终可点 |

```
无任何单人档 → 继续单人、加载单人 均锁定
无任何多人档 → 继续多人、加载多人 均锁定
```

**API 草案：** `GET /world/gate`

```json
{
  "can_continue_solo": false,
  "can_load_solo": false,
  "can_continue_multi": false,
  "can_load_multi": false,
  "last_solo_save_id": null,
  "last_multi_save_id": null,
  "solo_saves": [],
  "multi_saves": []
}
```

选 **加载** 时：`POST /world/load` body `{ scope: "solo"|"multi", save_id: "..." }`。

选 **新的单人** 时：`POST /world/new` body `{ scope: "solo", ironman: true|false }`。

**口诀：锁的是门上的「继续/加载」，不是城里的菜单。**

### 2.6 铁人模式（已定）

| | **单人模式** | **多人模式** |
|--|--------------|--------------|
| **铁人** | **新建时可选**（勾选「铁人模式」） | **默认铁人**，不可改 |
| **游戏内存档** | 铁人：**无手动存档按钮** | 同左 |
| **退出时** | **自动存档**（会话结束 / 登出 / 关页） | **自动存档** |
| **非铁人单人** | 可选 **手动存档**（槽位内覆盖） | —（多人无此档） |

**铁人纪律：**

- 不提供 `POST /world/save`（或 UI 隐藏「保存」）  
- 进度仅在 **退出/断线安全点** 写入；防 S/L 刷随机  
- 存档元数据带 `ironman: true` 标记，列表上显示 **铁人** 角标  
- 多人模式新建绑定 **强制** `ironman: true`

**非铁人单人（可选）：** 设置页或暂停菜单可 **手动存盘**；与铁人 **同槽互斥**（建档时定，不可中途改）。

## 三、速度：Victoria 3 式

### 3.1 规则

| 模式 | 速度 |
|------|------|
| **单人模式** | **暂停 · 慢 · 中 · 快 · 极快**（极快仅 SP） |
| **多人模式** | **锁定中间速**；全员同一 `world_clock` |

```
单人（示例）
  暂停   → 不推进 tick；可改价、挂 offer、逐单接单
  慢     → 1 虚拟日 ≈ 30 分钟
  中     → 1 虚拟日 ≈ 10 分钟（默认）
  快     → 1 虚拟日 ≈ 3 分钟
  极快   → smoke / 试链用

多人
  锁定「中」→ 与 cron 对齐
```

### 3.2 快档下能否逐单手动接单？（已定 · 对齐 Vic3）

**Victoria 3 的做法：**

| Vic3 | 含义 |
|------|------|
| **高速不禁止手动** | 5x 时仍可随时 **按空格暂停**，暂停内改法律、点建造、回外交 — 没有「快档锁 UI」 |
| **无原生事件 auto-pause** | 不像 EU4/CK3；重要事项靠 **右侧通知 + 音效**，玩家自己 pause 处理 |
| **常见玩法** | 长期开最高速「挂机推进」，**偶尔 pause** 做精细决策；或 1–2 速边玩边盯 |

**米拉世界映射（已定）：**

| 规则 | 说明 |
|------|------|
| **快档仍允许逐单手动接单** | 订单进通知队列后，玩家可随时打开逐单 **接单 / 拒单 / 标记好了** |
| **不强制快档一律 auto** | `auto_on` 是 opt-in，与速度档 **独立** |
| **单人暂停 = Vic3 pause** | 暂停时 tick 停、可处理积压订单 |
| **单人快档提醒** | 新订单 **通知 + 可选音效**（借鉴 Vic3 outliner 提醒）；**不做** 全服 auto-pause tick |
| **多人** | 无 pause；靠通知 + 下班关 auto（§4.5）；玩家在线时可逐单处理 |

**口诀：速度只推时钟，不剥夺手动权；想细玩就 pause（单人）或降频处理（多人）。**

### 3.3 tick 与 UI

- tick 顺序不变（[06](./06-两层经济（L0 Hub + 成品市场）.md)）。  
- **速度只影响经济 tick**，不影响通知是否送达。  
- 单人暂停时：**该实例 tick 与 auto 代理均冻结**（与 Vic3 一致）。  
- 多人：玩家 UI **无 force tick**。

## 四、主次视角：时间表自然切换

### 4.1 两个维度

同一 `player` 的两副眼镜（**不是两个角色**）：

| | 公司线 `focus=company` | 个人线 `focus=personal` |
|--|------------------------|-------------------------|
| **钱** | 公司账、机构运营账、Hub、生产 | 个人钱包、日投、消费、委托 |
| **操作** | 资本家、生产、挂市场、NPC 岗 | 地图、背包、购 offer、委托 |
| **默认页** | 资本家 · 生产 · 城市经营 | 地图 · 背包 · 我的 |

### 4.2 默认机制：时间表自然切换（已定）

**不做教程/成就解锁主次视角。** 注册即有完整 `life_schedule`，按表自动换 focus：

```text
life_schedule
  timezone
  work_windows[]     # 例：周一至五 09:00–18:00 → company
  holidays[]         # 全天 personal
  default_outside    # work_window 外 → personal
```

| 时段 | 自动 focus | UI |
|------|------------|-----|
| **上班窗口** | `company` | 底栏默认经营向；通知权重偏订单/生产/机构 |
| **下班 / 节假日** | `personal` | 底栏默认地图/背包；经营入口保留为「上班去」 |
| **玩家 override** | 临时切换 | **不改时间表**；下次窗口边界仍按表恢复 |

**可选补充（非默认）：** 设置里可关时间表、改用手动固定 focus — 高级选项，不进新手引导。

### 4.3 与 auto_on 当班绑定（已定）

| 时段 | `auto_on` |
|------|-----------|
| **上班窗口内** | 尊重玩家设置（可开可关） |
| **下班窗口外** | **系统自动关 `auto_on`** |
| **回到上班窗口** | **不自动重开** — 需玩家再次开启（防半夜误接单） |

与 [27 离线日程](./_archive/27-离线日程与自动当班.md) 共用 `timezone` / `windows` 字段；27 管离线代理，本稿管 **focus UI + auto_on 时段纪律**。

### 4.4 页面映射

| 页面 | `focus=company` | `focus=personal` |
|------|-----------------|------------------|
| `/play/capital` | 首页级 | 二级 |
| `/play/production` | 首页级 | 「上班去」 |
| `/play/economy` | 并列 | 并列 |
| `/play/my-shop` | 管理侧 | 顾客/店主 |
| 地图 / 背包 / 委托 | 二级 | 首页级 |

### 4.5 仍待 UI 细节

- [ ] `focus=company` 时个人钱包 **降权展示**（建议：小字可见，不隐藏）  
- [ ] 多人模式下时间表 **仅影响 UI 与 auto_on**，不影响 city tick（已定原则）
