## 二、进门控：四选一

### 2.1 选项

进入游戏前（登录后、进潮灯市前）统一门控：

```
┌─────────────────────────────────────┐
│         米拉世界 · 选择存档          │
├─────────────────────────────────────┤
│  ○ 新的单人游戏                      │
│  ○ 继续单人游戏                      │
│  ○ 新的多人游戏                      │
│  ○ 继续多人游戏                      │
└─────────────────────────────────────┘
```

| 选项 | 含义 |
|------|------|
| **新的单人游戏** | 新建 **私有世界实例**：独立 tick；**完整 10 组市民**（与多人同规模闭环） |
| **继续单人游戏** | 载入上次单人存档 |
| **新的多人游戏** | 进入 **共享潮灯市** |
| **继续多人游戏** | 回到共享城里的 handle / 公司 / 店（见 §2.4） |

### 2.2 与现架构的关系

| 现网 | 门控后 |
|------|--------|
| 一个 DB、一座潮灯市 | **多人** = 现模式；**单人** = 独立 `world_id` / `save_slot` |
| cron 日 tick | 多人：服务端固定中速；单人：玩家可调速（§三） |

**纪律：** 单人 **不得** 污染多人经济；多人 **不得** 因某玩家暂停而全服暂停；**不做** 单人→多人迁档。

### 2.3 单人世界规模（已定）

- **完整 10 组 × 1000 市民**，与 [04-乌托邦经济](./04-乌托邦经济.md) 同规格。  
- 目的：单人也能验收完整 **工资 → 消费 → 生产** 闭环，不是缩略教学沙盒。

### 2.4 「继续多人」与未开店新号（已定）

| 情况 | 行为 |
|------|------|
| 账号在 shared city 有进度 | 正常进入，恢复 handle / 资产 |
| **从未开店** 的新号选「继续多人」 | **仍进同一 shared city**（经济层不变） |
| 同上 · **UI** | **锁定** 经营向入口（资本家 / 生产 / 挂市场 / 当班设置等），只开放 **地图 · 通知 · 背包 · 我的** + **开店引导** |

**口诀：经济不挡路，UI 先引导开店；没店就不给误点经营后台。**

## 三、速度：Victoria 3 式

### 3.1 规则

| 模式 | 速度 |
|------|------|
| **单人** | **暂停 · 慢 · 中 · 快 · 极快**（极快仅 SP） |
| **多人** | **锁定中间速**；全员同一 `world_clock` |

```
单人（示例）
  暂停   → 不推进 tick；可改价、挂 offer、逐单接单
  慢     → 1 虚拟日 ≈ 30 分钟
  中     → 1 虚拟日 ≈ 10 分钟（默认）
  快     → 1 虚拟日 ≈ 3 分钟
  极快   → smoke / 试链用

多人
  锁定「中」→ 与 cron 对齐
```

### 3.2 快档下能否逐单手动接单？（已定 · 对齐 Vic3）

**Victoria 3 的做法：**

| Vic3 | 含义 |
|------|------|
| **高速不禁止手动** | 5x 时仍可随时 **按空格暂停**，暂停内改法律、点建造、回外交 — 没有「快档锁 UI」 |
| **无原生事件 auto-pause** | 不像 EU4/CK3；重要事项靠 **右侧通知 + 音效**，玩家自己 pause 处理 |
| **常见玩法** | 长期开最高速「挂机推进」，**偶尔 pause** 做精细决策；或 1–2 速边玩边盯 |

**米拉世界映射（已定）：**

| 规则 | 说明 |
|------|------|
| **快档仍允许逐单手动接单** | 订单进通知队列后，玩家可随时打开逐单 **接单 / 拒单 / 标记好了** |
| **不强制快档一律 auto** | `auto_on` 是 opt-in，与速度档 **独立** |
| **单人暂停 = Vic3 pause** | 暂停时 tick 停、可处理积压订单 |
| **单人快档提醒** | 新订单 **通知 + 可选音效**（借鉴 Vic3 outliner 提醒）；**不做** 全服 auto-pause tick |
| **多人** | 无 pause；靠通知 + 下班关 auto（§4.5）；玩家在线时可逐单处理 |

**口诀：速度只推时钟，不剥夺手动权；想细玩就 pause（单人）或降频处理（多人）。**

### 3.3 tick 与 UI

- tick 顺序不变（[06](./06-两层经济（L0 Hub + 成品市场）.md)）。  
- **速度只影响经济 tick**，不影响通知是否送达。  
- 单人暂停时：**该实例 tick 与 auto 代理均冻结**（与 Vic3 一致）。  
- 多人：玩家 UI **无 force tick**。

## 四、主次视角：时间表自然切换

### 4.1 两个维度

同一 `player` 的两副眼镜（**不是两个角色**）：

| | 公司线 `focus=company` | 个人线 `focus=personal` |
|--|------------------------|-------------------------|
| **钱** | 公司账、机构运营账、Hub、生产 | 个人钱包、日投、消费、委托 |
| **操作** | 资本家、生产、挂市场、NPC 岗 | 地图、背包、购 offer、委托 |
| **默认页** | 资本家 · 生产 · 城市经营 | 地图 · 背包 · 我的 |

### 4.2 默认机制：时间表自然切换（已定）

**不做教程/成就解锁主次视角。** 注册即有完整 `life_schedule`，按表自动换 focus：

```text
life_schedule
  timezone
  work_windows[]     # 例：周一至五 09:00–18:00 → company
  holidays[]         # 全天 personal
  default_outside    # work_window 外 → personal
```

| 时段 | 自动 focus | UI |
|------|------------|-----|
| **上班窗口** | `company` | 底栏默认经营向；通知权重偏订单/生产/机构 |
| **下班 / 节假日** | `personal` | 底栏默认地图/背包；经营入口保留为「上班去」 |
| **玩家 override** | 临时切换 | **不改时间表**；下次窗口边界仍按表恢复 |

**可选补充（非默认）：** 设置里可关时间表、改用手动固定 focus — 高级选项，不进新手引导。

### 4.3 与 auto_on 当班绑定（已定）

| 时段 | `auto_on` |
|------|-----------|
| **上班窗口内** | 尊重玩家设置（可开可关） |
| **下班窗口外** | **系统自动关 `auto_on`** |
| **回到上班窗口** | **不自动重开** — 需玩家再次开启（防半夜误接单） |

与 [27 离线日程](./_archive/27-离线日程与自动当班.md) 共用 `timezone` / `windows` 字段；27 管离线代理，本稿管 **focus UI + auto_on 时段纪律**。

### 4.4 页面映射

| 页面 | `focus=company` | `focus=personal` |
|------|-----------------|------------------|
| `/play/capital` | 首页级 | 二级 |
| `/play/production` | 首页级 | 「上班去」 |
| `/play/economy` | 并列 | 并列 |
| `/play/my-shop` | 管理侧 | 顾客/店主 |
| 地图 / 背包 / 委托 | 二级 | 首页级 |

### 4.5 仍待 UI 细节

- [ ] `focus=company` 时个人钱包 **降权展示**（建议：小字可见，不隐藏）  
- [ ] 多人模式下时间表 **仅影响 UI 与 auto_on**，不影响 city tick（已定原则）
