# 地点页与空间肖像：进入某地该看见什么？

> 状态：风景层内容 + 文字场景合成  
> 记录时间：2026-09-12  
> 来源：与作者的讨论  

---

## 一、问题

玩家进入 **官方地点、阵营使馆、公会驻地、家园、店铺/餐厅** 时，风景层（`05`）该显示什么？

- 材料要不要露出来？  
- 厨房、餐厅没有画面，**「视觉」全靠文字**——怎么让人「看见」一间馆子？  
- 私密与公共，看见的内容差多少？

---

## 二、总原则：三层内容 + 两种视角

### 2.1 和 `13` 对齐

| 层 | 页面上放什么 | 访客默认看见？ |
|----|--------------|----------------|
| **L1 百科** | 地点/房间/物品 `id`、类型标、认证标 | 折叠在「详情」；主文不堆 id |
| **L2 馆规** | 营业状态、菜单 SKU、已摆放物、打卡、可接订单 | **是**（硬状态） |
| **L3 叙事** | 场景肖像、店主台词、粉笔字、氛围句 | **是**（主阅读体验） |

### 2.2 两种视角

| 视角 | 谁 | 多看见什么 |
|------|-----|------------|
| **参观视角** | 路人、顾客、打卡者 | 场景肖像 + 公开栏 + 痕迹；**不见**主人仓库 |
| **管理视角** | 主人、会长、店主 | 编辑入口、背包材料、摆放格、订单后台 |

**口诀：别人看你 **摆出来的样子**；只有你自己看 **还没摆的库存**。**

---

## 三、通用地点页骨架（风景层）

任意「地点类」页面可共用同一套 **区块顺序**（车载壳层 `05` 不变）：

```
┌─────────────────────────────────────────────┐
│ ① 抬头：display_name + 类型标 + 归属         │
│    例：「少盐食堂」· 店铺 · 潮灯港           │
├─────────────────────────────────────────────┤
│ ② 场景肖像（Scene Portrait）— 文字「视觉」   │
│    2～5 段短 prose，由房间+摆放物合成         │
├─────────────────────────────────────────────┤
│ ③ 此刻状态条（L2 一行）                      │
│    营业中 / 打烊 / 仅成员 / 今日已有 12 人到访 │
├─────────────────────────────────────────────┤
│ ④ 可做的事（行动区）                         │
│    打卡 · 留痕 · 进店 · 写信 · 投票 · 我要…   │
├─────────────────────────────────────────────┤
│ ⑤ 专题区（按类型切换，见 §四）               │
│    菜单 / 公告 / 成员 / 邻接地图…             │
├─────────────────────────────────────────────┤
│ ⑥ 异步痕迹（`03`）                           │
├─────────────────────────────────────────────┤
│ ⑦ 邻接与离开                                 │
└─────────────────────────────────────────────┘
```

- **进入时拉一次** 地点状态；纯叙事段可不轮询（`05`）。  
- **材料库存** 不放在默认骨架里；进「管理」子页才见。

## 四、分类型：该显示哪些内容？

### 4.1 官方地点（`location_id`）

例：旧栈桥、潮灯港

| 区块 | 内容 |
|------|------|
| 抬头 | 百科主名 + 区域 + 势力（若有） |
| 场景肖像 | **设计方撰写**固定开篇 + 可选世界季变体（`12`） |
| 状态条 | 到访人数、世界季 flag（「战时灯火减半」） |
| 行动 | 打卡、留痕、邻接移动、相关悬赏入口 |
| 专题 | 百科摘录、此地订单栏、势力公告链接 |
| 痕迹 | 粉笔字、轻标记（`03`） |

**不显示：** 任何玩家材料；此地无「主人仓库」。

---

### 4.2 阵营 / 国家使馆（`faction_id` + 使馆节点）

| 区块 | 内容 |
|------|------|
| 抬头 | 势力名 + 「使馆」+ 驻在地 |
| 场景肖像 | 势力统一文风 + slogan（`19` 副标题） |
| 状态条 | 当前世界季立场、征兵自愿入口（`12`） |
| 行动 | 读公告、往使馆信箱投递、投票入口 |
| 专题 | **对外公告栏**、条约/战争快报摘要、成员榜（公开部分） |
| 痕迹 | 势力事件残留（「昨夜这里贴过动员令」） |

| 公开 | 成员私密 |
|------|----------|
| 公告、立场、使馆风景 | 内部议案、司库明细 → **组织信箱**（`11` `04`） |

---

### 4.3 公会 / 小团体驻地（`guild_hall_id`）

| 区块 | 内容 |
|------|------|
| 抬头 | 公会 `display_name` + 会长 + 人数 |
| 场景肖像 | 公会厅空壳 + 公会旗帜/摆设（`18` 合建后期） |
| 状态条 | 招贤中 / 仅成员可见 |
| 行动 | 申请加入、内部悬赏（成员）、写信给秘书 |
| 专题 | 公开简介、对外招贤栏；**成员**见内部栏 |
| 痕迹 | 成员留言 |

**私密档：** 会长可设「驻地对外关闭」→ 路人只见抬头 +「门内议事，改日再来」+ 申请入口。

---

### 4.4 玩家家园（`home_id`）

| 区块 | 路人（公开参观） | 主人（管理） |
|------|------------------|--------------|
| 抬头 | 「某某的 · 雾边小筑」 | 同左 + 编辑屋名 |
| 场景肖像 | **各房间合成文**（§五） | 同左 + 空槽提示 |
| 状态条 | 开放参观 / 仅好友 / 关闭 | 房间数、格位占用 |
| 行动 | 打卡、留痕、点赞（可选） | 摆放、扩房间、隐私设置 |
| 专题 | 主人留的 **欢迎短句**（L3） | **背包材料**、未摆放列表 |
| 痕迹 | 访客粉笔 | — |

**材料是否显示？**

| 对象 | 参观者 | 主人 |
|------|--------|------|
| 已摆放的家具/建材 | ✅ 进入场景肖像 | ✅ |
| 未摆放的库存（木×20） | ❌ 默认不显示 | ✅ 管理页 |
| 合成配方 / 蓝图 | ❌ | ✅ |
| 可选「工坊展示」 | ⚠️ 主人可开关：「门前挂牌：接木作订制」→ 只露 **服务 SKU**，不露天库存 |

---

### 4.5 店铺 / 餐厅（`shop_id`）

餐厅 = **店铺** + 至少一间 `room_kitchen`（后厨）+ 可选 `room_dining`（堂食）。

| 区块 | 顾客看见 | 店主看见 |
|------|----------|----------|
| 抬头 | 店名 + 店主名 + 认证标 | + 营业开关 |
| 场景肖像 | **堂食区为主**；可选「推开后厨」第二段 | 后厨完整肖像 + 格位 |
| 状态条 | 营业中/打烊、今日已售 | 进行中订单数 |
| 行动 | 浏览菜单、我要点菜、写信 | 上下架 SKU、接单 |
| 专题 | **菜单（SKU 列表）** L2 | 库存原料（仅店主） |
| 痕迹 | 食客粉笔、口味谱摘要（`15`） | — |

**材料是否显示？**

| 显示 | 不显示（给顾客） |
|------|------------------|
| 端上来的菜 = `item_id` 在订单里 | 后厨未用掉的 `item_flour×50` |
| SKU 承诺的 **硬标签**（`13` `07`） | 仓库明细 |
| 场景里 **摆出来的** 锅碗瓢盆 | 除非店主开「透明厨房」装饰位（纯展示，不真扣库存） |

**顾客问「用什么做的？」** → 点 SKU 看百科 `origin`（L1），不是看店主仓库。

## 五、文字「视觉」：场景肖像怎么合成？

### 5.1 不是写死一篇小说，是 **规则拼场景**

```
场景肖像 = 房间空壳文案（T0）
         + 摆放物按锚点插入（L2 placed_items）
         + 物品风味句（L1 百科 optional flavor）
         + 主人氛围句（L3 可选一句）
         + 组合触发氛围标（系统可选）
```

### 5.2 房间空壳（官方 T0）

每种 `room_*` 有一句 **无人时的底稿**：

| room_id | 空壳一句（示例） |
|---------|------------------|
| `room_hall` | 一间空厅，四壁白净，等第一件家具来决定脾气。 |
| `room_kitchen` | 灶台冷着，案板干净，缺一口会响的锅。 |
| `room_dining` | 几张空桌，等第一道热气。 |
| `room_yard` | 院子有风，脚印比人多。 |

### 5.3 锚点（Anchor）

每房间有固定 **描写槽**，摆放物填入槽位生成子句：

```
room_kitchen 锚点：
  [灶台] [案板] [窗边] [角落] [门口]

room_dining 锚点：
  [正中] [窗边桌] [柜台] [墙上] [入口]
```

例：灶台放 `item_wok`，案板放 `item_board` →

> 灶上一口铁锅还留着昨夜的干油香；案板边搁着磨快的刀。窗边空着。角落一盏小灯。

**规则：** 每锚点最多 1 件主物；超出格位的不进肖像（仍在 L2 数据里，可提示「库里还有」仅主人可见）。

### 5.4 物品贡献什么？

| 物品字段 | 进不进肖像 |
|----------|------------|
| `display_name` | 偶尔点名（「弯柄勺」） |
| `flavor_line`（百科） | ✅ 优先用 |
| `tags`（furniture / decor / kitchen_utensil） | 决定可放哪个锚点 |
| `quantity` 库存数 | **不进** 肖像（不是视觉） |

### 5.5 氛围标（可选，后期）

同屋物品组合触发 **一个词 + 一句收束**：

| 组合 | 氛围 | 收束句示例 |
|------|------|------------|
| 灯 + 木桌 + 布 | `cozy` | 光不大，但够把人留住。 |
| 多锅 + 多勺 + 盐罐 | `busy_kitchen` | 这里经常忙到半夜。 |
| 空屋仅 1 椅 | `sparse` | 像刚搬来，或刚走。 |

MVP 可不做自动氛围，只 **空壳 + 锚点填空**。

### 5.6 餐厅对顾客的呈现顺序

```
第一段：堂食（room_dining 肖像）— 「你推门看见什么」
第二段（可折叠）：后厨一瞥 — 仅当店主允许或 SKU 标「明档」
第三段：店主欢迎 L3 — 一句即可
第四段：菜单列表（L2 结构化，不是散文）
```

示例（顾客视角）：

> **少盐食堂**  
>  
> 三张木桌，靠窗那桌常有人坐。墙上挂着菜单牌，字写得克制。  
>  
> *（后厨）灶火温着，一口锅正哼。* — 点击展开  
>  
> 「少盐照旧，汤可以多喝。」— 店主  
>  
> **今日可点**  
> - 雾港汤面 · SKU `sku_noodle_mist` · 12 灯油  
> - …

## 六、私密 vs 公共：一张表

| 空间 | 默认可见性 | 主人可改 | 路人被挡时看见 |
|------|------------|----------|----------------|
| 官方地点 | 公共 | — | — |
| 阵营使馆 | 公共 | 势力官 | — |
| 公会驻地 | 半公开 | 关闭对外 | 抬头 + 闭门说明 |
| 家园 | 可参观 | 公开 / 好友 / 关闭 | 「主人暂不接客」 |
| 店铺 | 营业即公共 | 打烊 | 「今日歇业」+ 可选橱窗肖像 |

**好友档（后期）：** 多看见主人一句私密欢迎或一件未公开装饰；仍 **不见** 原材料库存。

## 七、和建筑流程的衔接（`18`）

```
建家园 → 解锁 room_kitchen
    → 背包凑 item_wok, item_board…
    → 管理页「摆放」到锚点
    → 保存后重新生成场景肖像
    → 若挂店铺：堂食 room + 菜单 SKU → 对外地点页
```

**「建成一家餐厅」在文字上的里程碑：**

1. 有 `shop_id` + 店名（`19`）  
2. 至少 `room_dining` 或 `room_hall` 有 ≥2 件 `furniture`  
3. 上架 ≥1 个餐饮 SKU  
4. 营业开关 = 开 → 地图/灯市列表出现入口  

不必等「精装模板」；**空壳 + 几件物 + 菜单** 就能是一家像模像样的馆子。

## 八、MVP 建议

| 做 | 不做 |
|----|------|
| 统一地点页 7 区块骨架 | 每种类型单独做一套 UI |
| 场景肖像 = 空壳 + 锚点填空 | 全 AI 实时写长篇 |
| 参观不见库存；店主见管理页 | 路人看仓库 |
| 店铺：堂食肖像 + SKU 菜单 | 后厨库存给顾客 |
| 家园隐私三档：公开 / 关闭 | 复杂好友 ACL |
| 1 套厨房 + 1 套厅锚点 | 全房间类型 |

## 十、小结

| 问题 | 答案 |
|------|------|
| 进入某地显示什么？ | **抬头 + 场景肖像 + 状态 + 行动 + 类型专题 + 痕迹 + 邻接** |
| 材料要不要显示？ | **参观：不显示库存，只显示摆出来的样子**；店主在管理页看 |
| 文字怎么做「视觉」？ | **房间空壳 + 锚点摆放 + 物品风味句 + 可选氛围** |
| 餐厅怎么像餐厅？ | **堂食肖像 + 菜单 SKU + 营业状态**；后厨可折叠 |
| 私密公共？ | **隐私档挡管理数据，不挡已公开的摆设与店招** |

> 文字世界里，别人走进你的屋子，  
> 看见的是你挂在锚点上的那盏灯、那把勺、那张桌——  
> 不是你背包里还藏着多少块砖。
