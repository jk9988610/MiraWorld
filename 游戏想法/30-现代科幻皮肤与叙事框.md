# 现代科幻皮肤与叙事框：主题、故事、简单货币

> 状态：世界观换皮方向（机制不变）  
> 记录时间：2026-09-13  
> 来源：与作者的讨论  
> 原则：**现实感 + 轻科幻 + 日常异步**；货币 **简单、少故事负担**  

---

## 一、定夺摘要

| 项 | 建议 |
|----|------|
| **主题方向** | **近未来日常都市**（不是赛博战争、不是太空歌剧） |
| **推荐世界名** | **接缝市 Seam City**（或中文主推：**接缝市**） |
| **核心设定** | 一座普通大城市接入统一的 **「中继网络 Relay」** —— 异步下单、身份、收件箱都走这套公共设施 |
| **玩家身份** | 网络居民 / 注册用户，无天命、无阵营必修 |
| **货币** | **金币 + 银币**（1 金 = 100 银，底层只存银币）—— 普通、少故事感 |
| **与玩法** | 地图节点 = **城区/站点**；点菜 = **节点商户**；信箱 = **中继收件箱**；机制层 **不改**（`29` v1.0 仍成立） |

---

## 二、为什么选「近未来日常」而不是硬科幻

| 方向 | 适合度 | 说明 |
|------|--------|------|
| **近未来都市 + 轻科幻基建** ✅ | 最高 | 外卖、兼职、信箱、打卡 = 现实延伸一层 |
| 太空站 | 中 | 异步好时区天然，但离「点一碗面」略远 |
| 赛博朋克黑暗都市 | 低 | 气质太重，和小团队、温暖异步冲突 |
| 古代/奇幻潮灯港 | 已讨论 | 可保留为 lore 支线，非主推 |

**轻科幻只落在「基础设施」：** 城市有统一数字身份、区块节点、自动撮合订单、延迟送达 ETA —— **不说魔法，不说灯神**。

## 三、推荐主题包：**接缝市 · 中继网络**

### 3.1 一句话世界观

> **接缝市**是普通大城市里最先接满 **中继网络** 的一片城区：  
> 你在 A 区下单，B 区厨房出餐，消息进收件箱，不必谁都在线。  
> 没有拯救世界 —— 只有 **过日子、认路、吃饭、等回信**。

### 3.2 故事框（发布会 / 帮助页用，短）

**背景（硬科幻很轻）：**  
多年前市政与几家生活服务商做了 **Relay 中继协议** —— 统一账号、托管付款、异步通知。接缝市试点最先铺开，所以地图、商户、跑腿都挂在这个网上。

**现在：**  
你是刚注册的一个 **句柄（行者名）**。钱包里有一点市政送的 **试用信用点**。  
城里节点能打卡、有餐饮档口、订单和通知走收件箱。  
**没有主线** —— 你想探索就逛节点，想吃饭就下单。

**不强调：** 战争、企业阴谋、AI 觉醒（以后可当季节活动，非 v1.0）。

### 3.3 气质关键词

现实、干净、略冷、不压抑、**像 2030 年的生活 App 文案**，不是网游公告。

## 四、货币：金币 + 银币（普通、固定汇率）

### 4.1 定夺（替代「点」与「灯油」）

| 项 | 选择 |
|----|------|
| **玩家看见** | **金币**、**银币** — 最常见、少故事负担 |
| **官方固定汇率** | **1 金币 = 100 银币**（全服恒定，玩家不能炒汇） |
| **服务器怎么存** | **只存一个整数：`wallet_silver`（银币）** — 最小单位 |
| **UI 怎么显示** | `1288` 银币 → 显示 **12 金 88 银**（格式化，非第二钱包） |

**为什么仍只存一列：** 小项目避免双余额、套利、转账 bug；金/银是 **显示习惯**，不是两种独立经济。

### 4.2 获取货币时怎么给

所有收入 **先加进 `wallet_silver`**，界面自动拆金银：

| 来源 | 系统记账 | 玩家看见 |
|------|----------|----------|
| 新手礼 | +10000 银 | 100 金 |
| 完成一单 +3 金工资 | +300 银 | +3 金 |
| 掉落「50 银」 | +50 银 | +50 银 |
| 活动奖「2 金」 | +200 银 | +2 金 |

**不需要**「先掉金币再手动换银币」—— 入账一次，显示自动拆。

### 4.3 花钱 / 标价

标价可用银或金，**结账统一扣 `wallet_silver`**：

| 标价写法 | 实际扣款 |
|----------|----------|
| 雾港汤面 **12 银** | −12 |
| 高级套餐 **1 金 20 银** | −120 |
| **2 金** | −200 |

余额不足 → 提示「还差 X 银」。

### 4.4 玩家能自己兑换金↔银吗？

| 方案 | MVP |
|------|-----|
| **A 仅自动显示**（推荐） | 没有兑换按钮；钱就是一个总数，界面拆成金+银 |
| B 显式「拆金/合银」 | v2 可选；**1:100 无手续费**，仍只改 `wallet_silver` |

**不做：** 浮动汇率、玩家摆摊炒币、金银币当背包物品。

### 4.5 和背包「金币道具」分清

| 层 | 是什么 |
|----|--------|
| **L2 钱包** | 金/银 — **抽象货币**（`wallet_silver`） |
| **L1 物品** | 若以后有 `item_gold_coin` 纪念品 — **不能当钱用**（v1.0 不做） |

### 4.6 帮助页

> 接缝市用 **金币和银币** 记账，**1 金币 = 100 银币**，由平台固定。  
> 钱包里是一个总数，界面会帮你拆成金、银；和背包里的东西不是同一种。  
> **银币不是现实货币**，不能提现、不能按汇率兑人民币（见 §4.8）。

### 4.7 物价锚点：「真实一点」怎么定？

**内部设计锚点（不对玩家承诺 1:1 兑付）：**

| 游戏单位 | 设计时心里当作 | 现实参照（中国日常） |
|----------|----------------|----------------------|
| **1 银币** | 约 **1 元** 购买力体感 | 一瓶饮料 / 小配料 |
| **1 金币** | 约 **100 元** 量级 | 一顿像样的聚餐预算 |

据此定 **首发价目表（接缝市 · 默认食堂）**：

| 商品 / 费用 | 建议标价 | 现实体感 |
|-------------|----------|----------|
| 基础汤面 / 饭 | **15 银** | ~15 元快餐 |
| 加料 / 升级套餐 | **22～28 银** | ~20+ 元 |
| 饮料 | **4 银** | ~4 元 |
| 配送费（v1.3） | **5 银** | ~5 元跑腿 |
| 系统标准原料（自动采购） | **2～8 银/单位** | 批发小件 |
| 厨师分成（一单） | **3～5 银** | 几元工钱 |
| 开店登记费（v1.2） | **50～100 金** | 大额一次性 |

**新手礼（调整）：** 若 1 银≈1 元体感，**100 金太多**。建议 **30 金**（3000 银）≈ 够体验 **几十次点餐**；或 **50 金** 偏慷慨。  
**原「100 灯油」配置改为 `newbie_silver: 3000`（显示 30 金）。**

工资与物价比例（防通胀）：  
- 厨师自动做一单净赚 **3～5 银** ≈ 现实几元提成，合理。  
- 平台抽成 **~15%** 留在 `ledger`。

**小数价怎么办？**  
- MVP **全部用整数银**，最低 **1 银**（不出现 0.5 银）。  
- 因此 **首发不加铜币**（见下）。

### 4.8 要不要铜币？要不要现实人民币充值？

#### 铜币

| 方案 | 建议 |
|------|------|
| **MVP 不加铜** ✅ | 价目都 ≥1 银，简单 |
| v2 若需要「45 铜」这种碎价 | 定 **1 银 = 100 铜**，库内改存 `wallet_copper`（1 金 = 10000 铜），仍 **一个整数** |

**不加铜的理由：** 接缝市是 **现代价**，一碗面 15 银已够直观；铜币更像古代奇幻。

#### 现实货币购买（充值）

| 版本 | 建议 |
|------|------|
| **v1.0 首发** | **不做** 人民币充值 — 银币仅游戏内获得 |
| **v3+ 若要做** | 只卖 **固定礼包**（如 6 元 → 60 银），**不能提现、不能玩家兑出** |

**若将来接支付，注意（中国区）：**

- 需支付渠道、可能涉及 ICP / 游戏版号等合规，**小项目成本高**  
- 礼包标价用 **「¥6 得 60 银币」**，**不要**写「1 银 = 1 元法定兑换」  
- 与游戏内锚点可略有偏差（礼包略贵，防刷）

**定夺：**

```
游戏内：金 / 银，1:100，锚定「1 银 ≈ 一块钱饭」的体感
现实充值：首发不做；以后只做单向礼包，不做双向汇率
铜币：首发不做
```

## 九、发布会话术（现代版）

**讲：**  
- 一座接入中继网的城区，可逛、可签到  
- 用 **点** 下单，平台托管，餐进背包  
- 收件箱异步通知，不催在线  

**不讲：** 灯油、馆驿、战争、魔法。

**收尾：**  
> 接缝市的第一版，只保证：**认得路、吃得上饭、信收得到。**  
> 开店、配送、当班，后面再接入网络。

## 十一、小结

| 问题 | 答案 |
|------|------|
| 现代偏科幻主题？ | **近未来都市 + 统一中继网络（Relay）** |
| 故事是什么？ | 试点城区日常生活；无主线；你是新注册用户 |
| 货币？ | **金币 + 银币**，1:100 固定；库内只存银币总数 |
| MVP 要重做吗？ | **不用**，换皮 + 配置 + 文案即可 |

> 科幻放在 **网络和配送怎么组织**；  
> 故事放在 **普通人怎么错时生活**；  
> 钱就叫 **金、银** —— 普通，够用，汇率固定，不抢戏。
