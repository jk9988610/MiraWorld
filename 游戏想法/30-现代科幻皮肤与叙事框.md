# 现代科幻皮肤与叙事框：主题、故事、简单货币

> 状态：世界观换皮方向（机制不变）  
> 记录时间：2026-09-13  
> 来源：与作者的讨论  
> 原则：**现实感 + 轻科幻 + 日常异步**；货币 **简单、少故事负担**  

---

## 一、定夺摘要

| 项 | 建议 |
|----|------|
| **主题方向** | **近未来日常都市**（不是赛博战争、不是太空歌剧） |
| **推荐世界名** | **接缝市 Seam City**（或中文主推：**接缝市**） |
| **核心设定** | 一座普通大城市接入统一的 **「中继网络 Relay」** —— 异步下单、身份、收件箱都走这套公共设施 |
| **玩家身份** | 网络居民 / 注册用户，无天命、无阵营必修 |
| **货币** | **点**（信用点，UI：`128 点`）—— **纯记账单位，不绑灯、不绑宗教隐喻** |
| **与玩法** | 地图节点 = **城区/站点**；点菜 = **节点商户**；信箱 = **中继收件箱**；机制层 **不改**（`29` v1.0 仍成立） |

---

## 二、为什么选「近未来日常」而不是硬科幻

| 方向 | 适合度 | 说明 |
|------|--------|------|
| **近未来都市 + 轻科幻基建** ✅ | 最高 | 外卖、兼职、信箱、打卡 = 现实延伸一层 |
| 太空站 | 中 | 异步好时区天然，但离「点一碗面」略远 |
| 赛博朋克黑暗都市 | 低 | 气质太重，和小团队、温暖异步冲突 |
| 古代/奇幻潮灯港 | 已讨论 | 可保留为 lore 支线，非主推 |

**轻科幻只落在「基础设施」：** 城市有统一数字身份、区块节点、自动撮合订单、延迟送达 ETA —— **不说魔法，不说灯神**。

## 三、推荐主题包：**接缝市 · 中继网络**

### 3.1 一句话世界观

> **接缝市**是普通大城市里最先接满 **中继网络** 的一片城区：  
> 你在 A 区下单，B 区厨房出餐，消息进收件箱，不必谁都在线。  
> 没有拯救世界 —— 只有 **过日子、认路、吃饭、等回信**。

### 3.2 故事框（发布会 / 帮助页用，短）

**背景（硬科幻很轻）：**  
多年前市政与几家生活服务商做了 **Relay 中继协议** —— 统一账号、托管付款、异步通知。接缝市试点最先铺开，所以地图、商户、跑腿都挂在这个网上。

**现在：**  
你是刚注册的一个 **句柄（行者名）**。钱包里有一点市政送的 **试用信用点**。  
城里节点能打卡、有餐饮档口、订单和通知走收件箱。  
**没有主线** —— 你想探索就逛节点，想吃饭就下单。

**不强调：** 战争、企业阴谋、AI 觉醒（以后可当季节活动，非 v1.0）。

### 3.3 气质关键词

现实、干净、略冷、不压抑、**像 2030 年的生活 App 文案**，不是网游公告。

## 四、货币：简单、少故事感

### 4.1 定夺

| 不用 | 改用 | 理由 |
|------|------|------|
| 灯油 | **点**（信用点） | 无实物隐喻；玩家秒懂 |
| 盏、灯、晶 | **点** | 避免和家居点灯物品混淆 |
| 多币种 | **仅点** | `23` 已定 |

**UI 示例：**

- 余额：`88 点`  
- 价格：`雾港汤面 · 12 点`  
- 系统字段仍可用 `wallet_balance` / `credits`，**不必改表名**，只改显示层。

### 4.2 和「物品」的关系（延续 `23` 分层）

| 层 | 名称 | 说明 |
|----|------|------|
| **L2 钱包** | **点** | 结账、工资、分账 —— **抽象货币** |
| **L1 物品** | 食材、餐盒、工具… | 背包里的实物，**不能当钱用**（v1.0） |

以后若有「充电券」「餐补券」= **优惠券道具**，抵部分点，**不是第二货币**。

### 4.3 帮助页一句

> **点**是接缝市中继网上的信用单位，用来付餐费和服务费；和背包里的东西不是同一种。

## 八、三种主题备选（若不想叫接缝市）

| 方案 | 名 | 气质 | 货币 |
|------|-----|------|------|
| **A 推荐** | 接缝市 + Relay | 现实都市、轻科幻基建 | **点** |
| B | 环站生活区 Loop | 略太空站、国际化 | **点** / Credits |
| C | 滨城日常 Bay City | 最现实、科幻最弱 | **元**（像人民币语感） |

**选 A**：科幻够写 Relay/节点/自动配送，又不离「下楼吃碗面」太远。  
**选 C**：若你想几乎当代中国城市，货币直接用 **「元」**，叙事去掉一切科幻词。

## 九、发布会话术（现代版）

**讲：**  
- 一座接入中继网的城区，可逛、可签到  
- 用 **点** 下单，平台托管，餐进背包  
- 收件箱异步通知，不催在线  

**不讲：** 灯油、馆驿、战争、魔法。

**收尾：**  
> 接缝市的第一版，只保证：**认得路、吃得上饭、信收得到。**  
> 开店、配送、当班，后面再接入网络。

## 十一、小结

| 问题 | 答案 |
|------|------|
| 现代偏科幻主题？ | **近未来都市 + 统一中继网络（Relay）** |
| 故事是什么？ | 试点城区日常生活；无主线；你是新注册用户 |
| 货币？ | **点**（信用点），简单抽象，不继承灯油叙事 |
| MVP 要重做吗？ | **不用**，换皮 + 配置 + 文案即可 |

> 科幻放在 **网络和配送怎么组织**；  
> 故事放在 **普通人怎么错时生活**；  
> 钱就叫 **点** —— 简单，够用，不抢戏。
