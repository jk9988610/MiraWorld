# 镜湖驿

内陆湿地中的歇脚处。湖面常无风，像一面放歪的镜子；雾起时，对岸的灯会变成两盏。

## 第一印象

木廊、湿靴印、煮着药草的铜壶。驿站登记簿不写「从何处来」，只写「今晚打算信谁」。这是 [探索法则](/world/exploration) 在现实里的玩笑版——据说某位旧站主开的头。

湖心有一座半沉的石亭，晴天可涉水靠近，雨天严禁。

## 可询问

- **驿丞**：安排床位、转告信件。若你来自 [灰烬港](/places/ashen-harbor) 且持灯火印，房费可赊一日。
- **过路商队**：谈高地天气；有人见过 [断弦塔](/places/broken-string-tower) 顶的残光。
- **[柯岚](/characters/ke-lan)**：拾遗院外勤，常在此等「做过奇怪梦的旅人」。

## 可前往

- 返回潮岸 → [灰烬港](/places/ashen-harbor)
- 高地驿道 → [断弦塔](/places/broken-string-tower)（雨季泥滑，需向导）
- 湖心石亭 → 未完全开放；设定上仅作异梦触发点

## 若你……

| 选择 | 倾向后果 |
|------|----------|
| 在登记簿写实姓名与目的 | 驿丞更愿分享路况；商会耳目也可能读到 |
| 只写代号 | 隐私更好；某些互助被拒 |
| 雨夜涉湖 | 可能触碰与 [残弦](/reference/glossary#残弦) 相关的幻象；也可能只是感冒 |

## 气氛笔记

镜湖驿适合「停下来改主意」。许多文字冒险在这里分叉：继续为商会跑腿，或把自己交给拾遗院的疑问。
