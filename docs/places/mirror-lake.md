# 镜湖驿

内陆湿地边的综合换乘站。长途巴士、共享车辆、临时住宿和二手信息在这里交汇。湖面平静，站房玻璃会把对岸的灯牌映成两份。

## 第一印象

候车廊、湿鞋印、自动售货机和一间营业到凌晨的热饮店。驿站的访客登记不只记录姓名，还会问你“今晚准备联系谁”。这是旧站主留下的社区习惯，也让许多失联的人第一次重新接上关系。

湖心有一座半沉的旧观测平台，晴天可以预约接近，雨天关闭。

## 可询问

- **站务人员**：安排短住、转告留言、查询班次。若你来自 [灰烬港](/places/ashen-harbor) 且有城市通行码，部分费用可延后一日结算。
- **长途乘客**：交换高地路况和旧设施消息；有人说见过 [断弦塔](/places/broken-string-tower) 的维护灯重新亮起。
- **[柯岚](/characters/ke-lan)**：拾遗院外勤，常在这里等愿意分享异常梦境或失真记录的人。

## 可前往

- 返回港区 → [灰烬港](/places/ashen-harbor)
- 高地公路 → [断弦塔](/places/broken-string-tower)（雨季路况不稳，需预约车辆）
- 湖心观测平台 → 暂未完全开放；当前作为异常记录的触发地点

## 若你……

| 选择 | 倾向后果 |
|------|----------|
| 登记真实姓名与目的 | 站务人员更愿分享路况；你的行程也可能进入公共记录 |
| 只登记代号 | 隐私更好；部分互助服务无法核验身份 |
| 雨夜靠近湖心平台 | 可能捕捉到与 [残弦](/reference/glossary#残弦) 有关的异常信号；也可能只是淋雨感冒 |

## 气氛笔记

镜湖驿适合停下来改主意。很多城市故事在这里分叉：继续为商会跑一单，还是把刚得到的线索交给拾遗院。
