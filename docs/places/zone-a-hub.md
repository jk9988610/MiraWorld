# A区 · 枢纽站

全服主入口。接驳牌、前台、**A区食堂** 都在这一区。

## 第一印象

平整的地面、清晰的区号指示牌。墙上贴着：**→ B区栈桥廊**、**→ D区商业街**。  
新成员多半从这里开始。

## 可询问

- **[小林 · 前台](/characters/npc-xiaolin)**：各区怎么走、新手礼多少点。
- **[陈师傅](/characters/npc-chen)**：A区食堂菜单；标准汤面 **15 点**。

## 可前往

- → [B区 · 栈桥廊](/places/zone-b-pier)

## 若你……

| 选择 | 倾向后果 |
|------|----------|
| 去 A区食堂下单 | 托管扣点，出餐进背包，系统通知 |
| 只逛不打卡 | 地图该节点仍显示「未到过」 |
| 问小林「主线在哪」 | 「没有主线。先逛区，或吃碗面。」 |
