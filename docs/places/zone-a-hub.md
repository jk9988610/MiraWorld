# 潮灯市 · 枢纽区

**潮灯市 · 枢纽区**

城市公共服务和日常生活的主入口。市民服务台、社区食堂、公交换乘都集中在这里。

## 第一印象

路牌写着：**潮灯市 枢纽区**。大厅里有实时公交屏、共享充电柜和一面更新很快的城市公告墙。**枢纽区食堂** 在服务台后侧。

## 可询问

- **[小林 · 前台](/characters/npc-xiaolin)**：潮灯市各片区怎么走、哪些服务还在营业。
