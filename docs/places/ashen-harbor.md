# 灰烬港

潮岸最大的活港口。码头木板仍能闻到旧火的味道；入夜后，灯火契约点亮一排排防风灯，商船按编号靠泊。

## 第一印象

盐风、缆绳、叫卖声。墙根贴着褪色的寻人启事，也贴着 [潮灯商会](/factions/tide-lantern) 本周的度量公告。外来者若无灯火印，卸货会被多拦一次。

港湾北侧有一片未重建的焦黑地基——当地人叫它「旧心」，夜里有人在那里低声对海说话。

## 可询问

- **码头守卫**：问班车与通行证。提到 [镜湖驿](/places/mirror-lake) 时，他们会指向内陆驿道。
- **[林溯](/characters/lin-su)**：商会文书，常在灯火厅抄录契约。若你礼貌说明来意，她可能借你一份旧航路抄件。
- **旧心旁的渔人**：只在黄昏出现。谈及「弦断」时会沉默，谈及出海则健谈。

## 可前往

- 内陆驿道 → [镜湖驿](/places/mirror-lake)
- 打听高地残垣 → 得知 [断弦塔](/places/broken-string-tower)（需向导或拾遗院介绍信）
- 商会灯火厅 → 接触 [潮灯商会](/factions/tide-lantern)

## 若你……

| 选择 | 倾向后果 |
|------|----------|
| 购买灯火印 | 潮岸通行更顺；拾遗院成员可能视你为「商会的人」 |
| 拒绝印记，只付现银 | 装卸更慢；某些港内对话更短 |
| 夜探旧心 | 可能听见与 [残弦](/reference/glossary#残弦) 有关的口谣；也可能一无所获 |

## 气氛笔记

灰烬港教给你的第一课：**交易本身就是立场**。你付钱买的不只是灯油，还有别人如何称呼你。
