# 灰烬港

潮灯市最重要的旧港更新区。白天是货运、仓储和餐饮的工作现场，入夜后，夜班配送、临时工和小商户把港区重新点亮。

## 第一印象

海风、集装箱、公交换乘提示音和刚贴上墙的招工启事。沿街公告栏同时发布 [潮灯商会](/factions/tide-lantern) 的服务费率与港区管理通知。没有城市通行码的外来商户，办理卸货和临时经营手续会多一道核验。

港湾北侧保留着一块事故后没有完成重建的焦黑地基，当地人仍叫它「旧心」。有人把这里当作城市记忆公园，也有人把它当成一处不愿面对的空白。

## 可询问

- **港区值班人员**：查询公交、临时通行和货运窗口。提到 [镜湖驿](/places/mirror-lake) 时，他们会给出最新班次。
- **[林溯](/characters/lin-su)**：商会运营文员，常在服务中心整理费率和旧项目档案。说明来意后，她可能提供一份公开的旧港改造记录。
- **旧心旁的摊主**：黄昏后才出摊。谈到“弦断之夜”会谨慎，谈到港区生意则很直接。

## 可前往

- 港区公交站 → [镜湖驿](/places/mirror-lake)
- 查询高地旧设施 → 得知 [断弦塔](/places/broken-string-tower)（需预约或机构介绍）
- 商会城市服务中心 → 接触 [潮灯商会](/factions/tide-lantern)

## 若你……

| 选择 | 倾向后果 |
|------|----------|
| 绑定城市通行码 | 夜间办事更顺；拾遗院成员可能把你视为商会合作方 |
| 不绑定账户，只现场付款 | 装卸和结算更慢；部分港区服务不会向你开放 |
| 深夜调查旧心 | 可能听到与 [残弦](/reference/glossary#残弦) 有关的旧录音；也可能只被保安请离 |

## 气氛笔记

灰烬港教给你的第一课：**每一笔交易都会留下关系记录**。你支付的不只是服务费，也是在告诉别人你愿意进入哪套城市系统。
