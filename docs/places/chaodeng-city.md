# 潮灯市

地址就是这座城：**潮灯市**。系统用城市作为统一入口，具体服务、店铺和人物通过页面与关系网络展开。

## 找谁

| 人 | 工作与位置 |
|----|--------|
| [小林 · 前台](/characters/npc-xiaolin) | 城市服务台接待、指路 |
| [陈师傅](/characters/npc-chen) | 社区食堂、餐品订单 |
| [周管理](/characters/npc-zhou) | 公共事务、平台规则 |

## 城市动线

晚霞岸、栈桥、商贸街、档案街、远郊等区域，是潮灯市的生活场景。它们可以影响你的行动和遭遇，但系统地址仍只认 **潮灯市**。
