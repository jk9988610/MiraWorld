# 断弦塔

高地上的旧信号与数据中继设施。事故后主塔停止运行，只剩一截裸露的结构和一套没有完全注销的维护系统。市民叫它“断弦塔”，因为那场事故像是把城市原本连续的通信线路从中间剪断。

## 第一印象

混凝土台阶、围挡、施工告示和 [拾遗院](/factions/relic-archive) 的档案工作人员。普通访客只能到公共观景平台；进入设备层和旧档案层，需要预约、采访许可或明确的项目授权。

塔底保留着一圈事故标记。游客常把它当作打卡背景，附近工作人员却禁止触摸，因为部分标记仍与未完成的数据迁移有关。

## 可询问

- **值守档案员**：解释参观规则，回避弦断之夜的责任认定细节。
- **[柯岚](/characters/ke-lan)**（若已在此）：愿用一段你亲自核实的城市记录，交换一条公开档案编号。
- **商会观察员**：潮灯商会会记录频繁访问者，担心旧数据影响现行服务协议和商业信任。

## 可前往

- 下山公交 → [镜湖驿](/places/mirror-lake)
- 远眺城市港区 → 想起 [灰烬港](/places/ashen-harbor)
- 设备与档案层 → 需 [拾遗院](/factions/relic-archive) 许可（开篇阶段主要作为叙事门槛）

## 若你……

| 选择 | 倾向后果 |
|------|----------|
| 遵守参观路线 | 获得公开版事故时间线；不会触发额外审核 |
| 追问事故责任 | 可能被记录联系方式；也可能被转介给更深层的档案管理员 |
| 在围挡外停留过久 | 安保介入；商会与拾遗院都可能收到访问记录 |

## 气氛笔记

断弦塔是潮灯市的“深层入口”：它不提供答案，只让你看见城市系统曾经如何失效。细节见 [时间线](/world/timeline)。
