# 断弦塔

高地残垣中最高的断口。塔身齐腰处光滑如切，上层不知去向。风过缺口时会发出细响，像未调完的琴。

## 第一印象

石阶、禁行绳、[拾遗院](/factions/relic-archive) 的灰袍学者。参观者只能到观景台；更深处需介绍信或「被认可的问题」。

塔底有一圈刻痕，像被弦勒过。当地向导禁止游客用手比划那些纹路。

## 可询问

- **值守学者**：解释参观规则，回避弦断之夜的细节。
- **[柯岚](/characters/ke-lan)**（若已在此）：愿交换「你在别处听到的口谣」换取一条档案编号。
- **商会监视员**：潮灯商会派人记录谁频繁造访——他们担心旧知识扰乱灯火契约。

## 可前往

- 下山驿道 → [镜湖驿](/places/mirror-lake)
- 远望潮岸轮廓 → 想起 [灰烬港](/places/ashen-harbor)
- 塔内档案层 → 需 [拾遗院](/factions/relic-archive) 许可（开篇设定中多为叙述性门槛）

## 若你……

| 选择 | 倾向后果 |
|------|----------|
| 遵守参观路线 | 获得公开版时间线；无额外风险 |
| 追问弦断真相 | 可能被记下名字；或被引荐给更深层的管理员 |
| 在禁行绳外停留过久 | 守卫介入；商会与拾遗院都可能收到通报 |

## 气氛笔记

断弦塔是设定的「深层出口」：适合作为第一次旅程的终点，或第二次旅程的起点。细节见 [时间线](/world/timeline)。
