# 如何阅读本站

MiraWorld 是一套**可探索的城市档案**：条目互相链接，像 Wiki 一样跳转；也可以按“文字冒险”的方式，从一个工作、地点或人物开始做选择。

## 侧栏与目录

- **左侧菜单**：按「总览 / 世界 / 地点 / 势力与人物 / 词条」浏览。
- **本页目录**：较长条目右侧（或移动端文首附近）可跳到对应小节。
- **下划线链接**：正文与目录中的链接带下划线，表示可跳转。

## 推荐路径

1. 读 [世界概览](/world/overview)，了解潮灯市的城市结构与历史背景。
2. 读 [探索法则](/world/exploration)，了解「地点 → 选择 → 后果」的阅读约定。
3. 从 [灰烬港](/places/ashen-harbor) 或 [镜湖驿](/places/mirror-lake) 开始，跟随内链进入机构、人物和城市事件。

## 本站不是什么

- 不是可执行的游戏引擎，不会替你掷骰或保存进度。
- 选择与后果写在设定里，供你脑内推演，或日后接入真正的文字游戏。
