# 潮灯商会

潮岸贸易与夜航规则的实际制定者。他们卖的不只是货物，还有**可被验证的信任**：灯火印、度量衡、船次编号。

## 宗旨

「灯不灭，路可计。」商会相信秩序来自可重复的契约，而非神秘的旧弦。弦断之后，他们率先重建港口灯火体系，并以此要求所有靠泊者服从同一套夜航法。

## 据点与影响

- 总部象征物在 [灰烬港](/places/ashen-harbor) 灯火厅。
- 在 [镜湖驿](/places/mirror-lake) 有账房与信使。
- 对 [断弦塔](/places/broken-string-tower) 保持监视，避免「未计价的知识」流入市面。

## 与旅人的关系

持灯火印者在潮岸通行更顺。拒印者仍可交易，但会遇到更多盘问。商会不禁止探访拾遗院，却会记下频繁来往者。

代表人物：[林溯](/characters/lin-su)。

## 若你靠近商会

- 任务口吻偏：护送、核对、清账、平息码头争端。
- 奖励常是印记升级、路引、现金。
- 冲突点：与 [拾遗院](/factions/relic-archive) 的归档权之争。
