## 这不是一张地图

这是潮灯市的城市档案与生活入口。你可以接一份临时工作、在商贸区经营自己的小店、去港口找人，也可以顺着一条异常消息，追到这座城市不愿公开的过去。

这里没有固定主线。城市按自己的节奏运行：订单会过期，店铺会营业，居民会记住你上次说过的话。你每一次选择，都会改变下一次登录时看到的潮灯市。

从 [世界概览](/world/overview) 了解城市，从 [探索法则](/world/exploration) 开始行动，或者直接进入 [潮灯市](/play/city)。
