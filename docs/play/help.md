# 怎么玩

米拉世界 v1.0：**探索 · 点菜 · 通知**。没有主线任务，没有弹窗推送。

## 四象（记这四个就够）

| 象 | 是什么 | v1.0 例子 |
|----|--------|-----------|
| **人** | 你（handle）和 NPC | 你、陈师傅、小林 |
| **地** | 市 + 可选逛点 | 潮灯市、晚霞岸 |
| **事** | 打卡、下单、通知 | 打卡、点面、「面好了」 |
| **物** | 物品和背包 | 一碗面 |

## 「点」是什么

- 注册送 **300 点**，点一碗标准汤面 **15 点**
- 点是游戏内货币，**不能提现、不能兑换现金**
- 余额不足时无法下单

## 三步开始（不绕弯）

1. **注册** → 落在潮灯市  
2. **地图** → 打卡，找陈师傅  
3. **点面** → 通知里提示好了 → **确认收进背包**  

没有快递员、没有「在路上」、没有运费。**通知到了，点一下收进背包。**

地图里的**逛点**第一次打卡会有专属小句子；再访会有不同的回访文案。

底栏：**地图 · 通知 · 背包 · 我的**

## v1.0 暂时没有

开店、私信、**骑手/配送**、家园、雇人——以后版本再说，现在不用找这些入口。
