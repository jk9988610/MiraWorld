# 怎么玩

米拉世界 **v1.5**：**探索 · 点菜 · 通知 · 开店 · 购售委托**。没有主线任务，没有弹窗推送。

## 四象（记这四个就够）

| 象 | 是什么 | 例子 |
|----|--------|------|
| **人** | 你（handle）和 NPC | 你、陈师傅、小林 |
| **地** | 市 + 可选逛点 | 潮灯市、晚霞岸 |
| **事** | 打卡、下单、通知 | 打卡、点面、「面好了」 |
| **物** | 物品和背包 | 一碗面、雾港小食 |

## 玩家用语（全站统一）

同一动作只有一个词，按钮和文档一致：

| 你在做什么 | 按钮/说法 |
|------------|-----------|
| 陈师傅菜单里的一行菜 | **挂单**（口语可说「点一碗」） |
| 订单好了，收进背包 | **确认收进背包** |
| 地上/逛点的物 | **放入背包** |
| 背包里的食物 | **食用** |
| 背包里的工具 | **使用** |
| 系统消息 | **通知**（底栏第二项） |

**不要找这些词：** 取餐、配送、信箱、骑手、在路上、当面交差。

## 「点」是什么

- 注册送 **300 点**，点一碗标准汤面 **15 点**
- 点是游戏内货币，**不能提现、不能兑换现金**
- 余额不足时无法下单

## 四步开始（不绕弯）

1. **注册** → 落在潮灯市  
2. **地图** → 打卡，找陈师傅  
3. **点面** → **通知**里提示好了 → **确认收进背包**  
4. **背包** → 汤面可 **食用**；逛点掉落可 **放入背包** / **食用** / **使用**

**逛点掉落：** 晚霞岸可能有「雾港小食」（食用或放入背包）；文档塔可捡到「潮水小刀」（使用或放入背包）。

没有快递员、没有「在路上」、没有运费。**所有订单相关进展都走通知。**

地图里的**逛点**第一次打卡会有专属小句子；再访会有不同的回访文案。

底栏：**地图 · 通知 · 背包 · 我的** — 通知有未读时会显示红点。

## 开店（v1.2）

1. **我的** → **我的店** → 交 **100 点**登记费 → 挂一碗面  
2. 地图 **玩家店** 列表里会出现你的店  
3. 买家点单 → **通知**告知进展 → **确认收进背包**  
4. 卖家 **接单** → **标记好了**（或开启 **当班** 自动接单）  
5. 可给对方发 **往来** 消息（自愿，非收物必经）

## 当班（v1.4）

**我的店** 里可 **开启当班**：离线时店铺自动接单并标记好了，买家仍会在 **通知** 里收到「好了」。  
仍无配送：物不进「在路上」，只有订单状态与通知。

## 购售委托（v1.5）

**点面**走陈师傅/玩家店（`order`）；**委托**走悬赏栏（`bounty`）。不做「委托做某事」类任务单。

只支持两种：

| 类型 | 含义 |
|------|------|
| **委托购买** | 求购某物，托管点数 |
| **委托出售** | 求售某物，托管点数 |

规则：

- 最多同时 **上架 10 个**委托订单（购买或出售合计）  
- 发委托 → 接委托 → 交差 → **确认交差** → 放款  
- **全程走通知**（接单、交差、放款）  
- 还没人接的可 **取消**，托管退回  

**动词：** 发委托 · 接委托 · 交差 · 确认交差 · 取消  

## 乌托邦经济（设计定稿，v2.0 实现）

米拉世界是 **乌托邦**：城市能自己转，不靠玩家在线撑场面。

| 谁 | 收入 |
|----|------|
| **无岗市民** | **最低生活补贴** — 够基础温饱 |
| **在岗工人** | **最低工资标准** — 机构按编制发薪 |

机构生产 → 工资与福利 → 市民消费 → 机构营收，形成闭环。玩家只是 **带 handle 的经营者**，规则与 NPC 相同。

**永久不做：** 招贤应聘、雇玩家、律师判决、作家/trace、中介、配送骑手。详见设计文档 `04-乌托邦经济`。
