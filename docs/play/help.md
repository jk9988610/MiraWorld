# 怎么玩

米拉世界 **v1.5**：**探索 · 点菜 · 通知 · 开店 · 我要**。没有主线任务，没有弹窗推送。

## 四象（记这四个就够）

| 象 | 是什么 | 例子 |
|----|--------|------|
| **人** | 你（handle）和 NPC | 你、陈师傅、小林 |
| **地** | 市 + 可选逛点 | 潮灯市、晚霞岸 |
| **事** | 打卡、下单、通知 | 打卡、点面、「面好了」 |
| **物** | 物品和背包 | 一碗面、雾港小食 |

## 玩家用语（全站统一）

同一动作只有一个词，按钮和文档一致：

| 你在做什么 | 按钮/说法 |
|------------|-----------|
| 陈师傅菜单里的一行菜 | **挂单**（口语可说「点一碗」） |
| 订单好了，收进背包 | **确认收进背包** |
| 地上/逛点的物 | **放入背包** |
| 背包里的食物 | **食用** |
| 背包里的工具 | **使用** |
| 系统消息 | **通知**（底栏第二项） |

**不要找这些词：** 取餐、配送、信箱、骑手、在路上。

## 「点」是什么

- 注册送 **300 点**，点一碗标准汤面 **15 点**
- 点是游戏内货币，**不能提现、不能兑换现金**
- 余额不足时无法下单

## 四步开始（不绕弯）

1. **注册** → 落在潮灯市  
2. **地图** → 打卡，找陈师傅  
3. **点面** → 通知里提示好了 → **确认收进背包**  
4. **背包** → 汤面可 **食用**；逛点掉落可 **放入背包** / **食用** / **使用**

**逛点掉落：** 晚霞岸可能有「雾港小食」（食用或放入背包）；文档塔可捡到「潮水小刀」（使用或放入背包）。

没有快递员、没有「在路上」、没有运费。**通知到了，点一下收进背包。**

地图里的**逛点**第一次打卡会有专属小句子；再访会有不同的回访文案。

底栏：**地图 · 通知 · 背包 · 我的** — 通知有未读时会显示红点。

## 开店（v1.2）

1. **我的** → **我的店** → 交 **100 点**登记费 → 挂一碗面  
2. 地图 **玩家店** 列表里会出现你的店  
3. 在店里 **当面点单**：**不发通知**，订单页直接 **确认收进背包**  
4. 卖家 **接单** → **标记好了**（或开启 **当班** 自动接单）  
5. 可给对方发 **往来** 消息（自愿，非收物必经）

## 当班（v1.4）

**我的店** 里可 **开启当班**：离线时店铺自动接单并标记好了。  
- **当面** 点单：仍不发通知  
- **异步** 点单（将来）：好了才发通知  

仍无配送：物不进「在路上」，只有订单状态与可选通知。

## 我要（v1.5）

**点面**走陈师傅/玩家店（`order`）；**委托**走悬赏栏（`bounty`）。两者不要混用。

1. **我的** → **悬赏栏** → 填标题、托管点数 → **发委托**（余额立刻扣托管）  
2. 别人在悬赏栏 **接委托** → **交差**  
3. 发单人 **确认交差** → 接单人收托管点数  
4. 还没人接的单可 **取消**，托管退回  

**动词：** 发委托 · 接委托 · 交差 · 确认交差 · 取消  

**通知：** 异步接/交差/放款会发通知；勾选 **当面交差** 则全程不发通知（与 v1.4 一致）。  
仍无配送、无系统派单——只有玩家自愿发单与接单。

## v1.5 暂时没有

**骑手/配送**、厨师 auto、招贤栏、家园必绑——以后版本再说。
