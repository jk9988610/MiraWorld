# 术语表

潮灯市的常用词。正文可用下划线链接跳到此处对应小节。

## 潮余历

弦断之夜后，城市档案部门采用的事故后纪年。市民仍混用旧年份，正式项目和公共记录以潮余历为准。见 [时间线](/world/timeline)。

## 灯火契约

[潮灯商会](/factions/tide-lantern) 推行的夜间服务与城市信用协议，覆盖配送、港区通行、商户结算和服务评级。绑定账户后，潮灯市的大多数合作方都能核验你的身份与履约记录。

## 灯火印

契约的账户凭证，可以表现为会员码、通行码或线下登记号。形式并不重要，商会后台记录才决定它是否有效。

## 残弦

对弦断之夜后遗留异常的统称：重复出现的旧语音、无法对齐的时间戳、未完成的数据迁移，以及据说“把事实说完整”才会恢复的城市入口。[拾遗院](/factions/relic-archive) 为它们编号；商会倾向称之为“未定价风险”。

## 旧心

[灰烬港](/places/ashen-harbor) 事故后未完成重建的焦黑地基。名字来自当地居民对“港区旧核心”的简称。

## 提问许可

拾遗院发给采访者、研究者和外部协作者的临时资格，允许在指定范围内提问或查阅公开编号档案。不等于可以进入所有办公区或设备层。

## 登记簿（镜湖）

[镜湖驿](/places/mirror-lake) 特有的住宿与访客登记：除了姓名，还会记录你今晚准备联系谁。它强调当下的信任关系，而不只是户籍身份，与 [探索法则](/world/exploration) 的“选择可见”相呼应。

## Mira / MiraWorld

米拉世界的名称；本站是潮灯市的城市档案、生活入口与异步文字冒险阅读界面。从 [世界概览](/world/overview) 进入。
