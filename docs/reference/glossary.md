# 术语表

开篇常用词。正文可用下划线链接跳到此处对应小节。

## 潮余历

弦断之夜后通行的纪年。民间仍混用旧称，正式文书以潮余历为准。见 [时间线](/world/timeline)。

## 灯火契约

[潮灯商会](/factions/tide-lantern) 推行的夜航与度量规范。签署或购买灯火印后，潮岸多数关卡承认你的身份编号。

## 灯火印

契约的随身凭证。可以是铜牌、蜡封或登记号——形式次要，商会账本里的记录才是效力来源。

## 残弦

对弦断之夜遗留现象的统称：幻听般的风鸣、未完成的刻痕、据说「说对的话」才会应门的缝隙。 [拾遗院](/factions/relic-archive) 将其编号；商会倾向称之为「未计价风险」。

## 旧心

[灰烬港](/places/ashen-harbor) 未重建的焦黑地基。地名来自「港口的旧心脏」。

## 提问许可

拾遗院发给外访者的临时资格，允许在指定范围内提问或阅览公开编号档案。不等于塔内自由通行。

## 登记簿（镜湖）

[镜湖驿](/places/mirror-lake) 特有的住宿登记：强调今夜信任对象，而非仅户籍姓名。与 [探索法则](/world/exploration) 的「选择可见」相呼应。

## Mira / MiraWorld

大陆边缘世界之名；本站是该世界的设定资料与文字冒险阅读入口。从 [世界概览](/world/overview) 进入。
