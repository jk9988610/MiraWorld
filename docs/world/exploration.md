# 探索法则

本页约定：如何把 MiraWorld 的设定**读成一次文字冒险**。没有程序替你判定——判定在你脑中，或日后接入游戏时再实现。

## 基本循环

1. **进入地点**：阅读场景描写，记下可见的人物、出口、物品。
2. **做出选择**：从文中明示或暗示的选项里选一条（也可自己发明，但后果需自洽）。
3. **承担后果**：根据该地点「若你……」小节，想象世界如何偏移，再沿内链前往下一场景。

## 选择的写法

条目中常见三种提示：

| 标记 | 含义 |
|------|------|
| **可询问** | 与人物对话，换取信息或立场 |
| **可前往** | 明确的地理出口，链到其他地点 |
| **可带走** | 物品或线索，可能改变后续阅读 |

若某处写「未开放」，表示当前开篇设定尚未铺到——你可以当作锁门，或自行脑补。

## 立场与信任

与 [潮灯商会](/factions/tide-lantern) 或 [拾遗院](/factions/relic-archive) 靠近，会改变他人对你的口吻。设定里用简短句提示，例如：

> 若你持有商会灯火印，灰烬港守卫会少问一句来处。

人物条目（如 [林溯](/characters/lin-su)、[柯岚](/characters/ke-lan)）列出他们在意什么；对话选择应尊重这些偏好，故事才显得「世界有反应」。

## 建议的第一次旅程

1. 从 [灰烬港](/places/ashen-harbor) 登岸。
2. 决定先找商会，还是打听去 [镜湖驿](/places/mirror-lake) 的班车。
3. 若你追求旧日真相，终将听到 [断弦塔](/places/broken-string-tower) 的名字。
