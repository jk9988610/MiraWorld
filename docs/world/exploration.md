# 探索法则

本页约定：如何把 MiraWorld 的设定**读成一次城市生活冒险**。没有程序替你判定——判定在你脑中，或日后接入游戏时再实现。

## 基本循环

1. **进入地点**：阅读场景描写，记下可见的人物、入口、服务和未解决的问题。
2. **做出选择**：从文中明示或暗示的选项里选一条，也可以自己提出行动，但后果需要符合城市规则。
3. **承担后果**：根据该地点「若你……」小节，想象你的决定如何影响信用、关系、工作和下一次登录时的城市状态。

## 选择的写法

条目中常见三种提示：

| 标记 | 含义 |
|------|------|
| **可询问** | 与居民、店员或机构工作人员对话，换取信息或建立关系 |
| **可前往** | 明确的城市动线，链到其他地点 |
| **可带走** | 商品、文件、联系方式或线索，可能改变后续阅读 |

若某处写「未开放」，表示当前版本尚未接入该城市服务。你可以把它当作暂时关闭的入口，也可以把它写进自己的想象。

## 立场与信任

与 [潮灯商会](/factions/tide-lantern) 或 [拾遗院](/factions/relic-archive) 靠近，会改变居民对你的称呼和回复速度。设定里用简短句提示，例如：

> 若你的账户持有商会城市通行码，灰烬港的夜班管理员会少问一句来处。

人物条目（如 [林溯](/characters/lin-su)、[柯岚](/characters/ke-lan)）列出他们在意什么；对话选择应尊重这些偏好，潮灯市才会像一座真正会对人产生反馈的城市。

## 建议的第一次行程

1. 从 [灰烬港](/places/ashen-harbor) 进入潮灯市的旧港片区。
2. 决定先找商会办事，还是查询去 [镜湖驿](/places/mirror-lake) 的班车与临时住宿。
3. 如果你想追查城市事故的真相，最终会听到 [断弦塔](/places/broken-string-tower) 的名字。
