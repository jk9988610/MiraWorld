# 时间线

以下时间线记录潮灯市从事故、重建到今天的城市变化。具体细节会随档案开放继续修订。

## 弦断之夜以前

- 潮灯市已经是沿海交通、仓储与夜间服务的重要节点。
- 城市早期使用一套高度集中的通信与调度系统，港口、换乘站和公共档案都依赖它运转。

## 弦断之夜

- 城市核心通信与调度网络突然中断，旧城区、港口和高地设施同时失联。
- 大量纸质档案、服务器记录与个人设备损毁或被封存；官方报告与民间叙述开始分叉。
- 高地旧信号设施停止运行，后来被市民称为 [断弦塔](/places/broken-string-tower)。

## 事故后的重建期

- 幸存的港区在旧码头基础上重新规划，形成今日的 [灰烬港](/places/ashen-harbor)。
- [潮灯商会](/factions/tide-lantern) 以一套夜间服务与城市信用协议重新连接港口、配送和商户。
- [拾遗院](/factions/relic-archive) 成立，负责收集事故前后的档案、设备记录与口述史。

## 近十年

- 内陆 [镜湖驿](/places/mirror-lake) 从临时换乘点发展为长途巴士、共享车辆和短租住客的交汇站。
- 关于“能被说清楚的断联记录”不断流出，拾遗院与商会首次公开争执资料开放和信息定价。
- 潮灯市开始将夜间经济、社区小店和异步公共服务纳入同一套城市平台。

## 当下

你打开本站的时刻，就是潮灯市的现在。城市不会等你准备好：新的订单、消息和临时机会会在你离线时继续发生。从 [探索法则](/world/exploration) 或任一地点开始，留下你的路径。
