# 世界概览

**MiraWorld** 的地址只有 **两段**：

**市 · 区**

例如：**潮灯市 · 晚霞区**

不搞省、街道、小区、格号——宏观说到区就够了。

## 地址怎么用

| 场景 | 例 |
|------|-----|
| 你在哪 | 潮灯市 · 晚霞区 |
| 食堂 | 潮灯市 · 枢纽区 |
| 打卡 | 来过「晚霞区」即记录 |

技术存储：`{ "city": "潮灯市", "district": "晚霞区" }`
