# 世界概览

**米拉世界（MiraWorld）** 是一套关于城市生活、工作与公共记忆的异步文字世界。故事的中心只有一座城：**潮灯市**。

系统在宏观上只记录城市，不把每个居民锁死在街道和门牌里。想找一个人，使用「城市 + 人」：

- 潮灯市 · **陈师傅**（食堂）
- 潮灯市 · **@雾桥阿青**（玩家）

## 这座城市

潮灯市靠海，港口、换乘站、社区商业和旧档案设施共同构成它的日常。白天，货物从港区进入商贸网络；夜里，外卖、维修、临时委托和小店订单继续流转。城市看起来高效，但每套系统都留下了自己的盲区。

十多年前，一场被称为「弦断之夜」的城市级事故造成通信、档案与基础设施的大范围失序。官方记录、幸存者口述和后来重建的城市界面，从此再也没有完全对上。潮灯市就是在这段断裂的记忆上继续运转的。
