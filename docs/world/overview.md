# 世界概览

**MiraWorld** 只用一套能全球统一的地址，**五段**：

**市 → 区 → 街道 → 小区 → 户号**

不要省、国；对不上五段的地点 **不收录**。

## 五段怎么写

| 段 | 例 | 何时必填 |
|----|-----|----------|
| 市 | A市 | 总是 |
| 区 | 枢纽区 | 总是 |
| 街道 | 中心街道 | 店铺、家园 |
| 小区 | 接驳小区 | 店铺、家园 |
| 户号 | `3-502` | 家园、配送（**单元和门牌合成一段**，中间横杠） |

### 显示长度

| 长度 | 示例 | 用途 |
|------|------|------|
| 短 | `A市 · 枢纽区` | 地图、NPC |
| 中 | `A市 枢纽区 中心街道 接驳小区` | 店铺 |
| 全 | `A市 枢纽区 中心街道 接驳小区 3-502` | 配送 |

技术路径（可选）：`A市/枢纽区/中心街道/接驳小区/3-502`
