# 世界概览

**MiraWorld** 按真实行政区划组织：**省 → 市 → 区 → 街道 → 小区 → 单元 → 门牌**。

城市用 **A市、B市、C市** 作代号（像「甲城、乙城」好记）；**区** 用真区名，例如 **A市 · 枢纽区**（类比北京市朝阳区）。

## 地址怎么读

| 层级 | 示例 |
|------|------|
| 省 | 联合省 |
| 市（代号） | **A市** |
| 区 | 枢纽区、滨湖区、商贸区… |
| 街道 | 中心街道、栈桥街道… |
| 小区 | 接驳小区、观湖小区… |
| 单元门牌 | 3单元 502（家园/配送 v1.3+） |

**短地址（地图常用）：** `A市 · 枢纽区`  
**完整地址（配送）：** `联合省 A市 枢纽区 中心街道 接驳小区 3单元 502`

## 平台与货币

- 订单托管、分账由 **平台** 处理。
- 货币：**信用点（credits / 点）**，不能提现。
