# 世界概览

**米拉世界（MiraWorld）** 的地址只有 **一段**：

**市**

例如：**潮灯市**

要找到具体的人或店，用 **市 + 人**：

- 潮灯市 · **陈师傅**（食堂）
- 潮灯市 · **@雾桥阿青**（玩家）

没有区、街道、门牌——宏观到市就够了。

## 技术表示

```json
{ "city": "潮灯市" }
```

匹配某人：

```json
{ "city": "潮灯市", "person": { "type": "npc", "id": "npc_chen", "display": "陈师傅" } }
```
