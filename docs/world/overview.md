# 世界概览

**Mira** 是一片被潮汐与余烬共同塑造的大陆边缘。人们在港口交易、在驿站过夜、在塔影下争论「世界是否还记得自己」。对旅人而言，地图不是画在羊皮纸上的线，而是一连串**可进入的地点**与**不可撤回的选择**。

## 时代

当前纪年称 **潮余历**。上一次大灾被称作「弦断之夜」——天空曾有一道可见的裂痕，随后熄灭。幸存者重建了港口与商路，却把许多知识锁进了 [拾遗院](/factions/relic-archive)。

日常仍在运转：渔船出港、灯火入夜、契约盖印。但每个稍懂旧事的人都会说：弦断之后，有些门只在**说对的话、走对的路**时才会打开。

## 地理骨架

大陆边缘由北向南大致可记为三条「可读路径」：

| 区域 | 代表地点 | 气质 |
|------|----------|------|
| 潮岸 | [灰烬港](/places/ashen-harbor) | 交易、流言、出海 |
| 内陆湿地 | [镜湖驿](/places/mirror-lake) | 歇脚、异梦、渡口 |
| 高地残垣 | [断弦塔](/places/broken-string-tower) | 禁忌、档案、远望 |

道路本身是安全的——至少白天如此。危险往往来自**你选择相信谁**，以及是否踏入标注为「未开放」的侧径。

## 与文字冒险的关系

本站把世界写成资料，同时保留文字游戏的骨架：

- **地点**是场景：描述可见物、可交谈者、可带走之物。
- **势力**提供立场与任务口吻。
- **探索法则**规定如何把设定读成「如果你做 A，则世界倾向 B」。

你不必一次读完。从任一地点点进内链，就等于开始一次短途旅行。
