# 世界概览

**MiraWorld** 是一座按 **区号** 划分的文字可探索空间。没有主线任务——你走过 **A区、B区…** 会留下足迹；在 **A区食堂** 用 **点（credits）** 下单，通知会告诉你发生了什么。

## 分区骨架

首发开放 **六个区**，区号全服统一，脱口能指认：

| 区号 | 名称 | 气质 |
|------|------|------|
| **A区** | [枢纽站](/places/zone-a-hub) | 入口、接驳、系统食堂 |
| **B区** | [栈桥廊](/places/zone-b-pier) | 连接廊道 |
| **C区** | [湖滨休息](/places/zone-c-lakeside) | 歇脚、远景 |
| **D区** | [商业街](/places/zone-d-market) | 招牌与店铺 |
| **E区** | [档案塔](/places/zone-e-archive) | 规则、管理处 |
| **F区** | [遗迹长廊](/places/zone-f-ruins) | 边缘、未开放感 |

```
        [ E区 · 档案塔 ]
              |
  [ D区 ]——[ A区 · 枢纽 ]——[ B区 ]
                |              |
           （常见起点）    [ C区 ]——[ F区 ]
```

## 平台与规则

- **平台运营**：托管订单、分账、发放 credits。
- **E区管理处**：规则公示与档案（对应旧设定中的「管理机构」）。
- **成员**：注册即用 handle（行者名）登录、收通知。

货币是 **信用点（点）** —— 账上整数，不能提现，和背包物品不是一回事。

## 与文字冒险的关系

- **区** = 场景节点：描述、NPC、可前往邻区。
- **打卡** = 来过变色，无强制清图。
- **通知** = 异步收信，不必同时在线。
